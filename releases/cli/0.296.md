  keep new raw Wasm captures under `target/evidence/`; preserve release and

  for unclassified source and diagnostic guidance in help. Preserve JSON
  categories and source totals.
- Restore exported Shared documentation links through the canonical upstream
  repair, without copying central fleet inventories
  ([Shared #355 — Complete exported documentation links](https://github.com/dragginzgame/shared-tooling/issues/355)).
- Adopt Shared Tooling 0.30.0: explicit source categories, plural test directories,
  external test/helper modules and checked lint expectations. Make source scans
  reject missing inputs; retain the independent Canic qualification boundary.
  Refresh all 154 snapshot payloads from the reviewed commit, declare 47 package
  roles, and preserve public package identities and supported behavior. The
  root product/fixture lint selections pass; Canic compilation remains blocked

- Select independently qualified CLI-only release checks on Linux, keeping

### 🧪 Testing

- The controlled CLI presentation fixture passes all 15 full and 11 selected
  stages on the same source/compiler/configuration, with no stage reuse. Shared
  saved proofs and final source/index custody are re-admitted. Both verified
  archives match byte-for-byte; their source matches the admitted Git tree.
- Source-to-release fixtures cover actual metadata preparation, staging,
  commit/tag checks and push admission with retained selected evidence, including
  recovery after cache deletion and rejection of missing or tampered proof.

- Candidate archives retain their declared published database 0.297.0

  retains full validation until its own mapping is qualified.

### ⚠️ Breaking

- Parse diagnostic values and require migration abort/adopt confirmation in Clap
  before execution. Invalid values and missing `--yes` now use usage diagnostics
  and exit 2; payload, domain and execution failures retain exit 1
  ([#627 — Move diagnostic parsing and migration confirmation into Clap](https://github.com/dragginzgame/icydb/issues/627)).

### 🩹 Fixed

- Escape rejected option, subcommand, conflict and trailing-token context before
  Clap renders parse errors, including contexts containing several strings.
  Preformatted tips can retain another raw copy of rejected input, so omit those
  tips when a token requires escaping. Normal tips and Clap's usage/help/version
  rendering remain unchanged. Process controls cover top-level and nested
  subcommands, unknown options, extra positional tokens, Unicode and terminal
  controls, exit 2, empty stdout and no ICP calls
  ([#627 — Terminal-safe Clap parse refusals](https://github.com/dragginzgame/icydb/issues/627)).

### 🧹 Cleanup

- Use published Host Tools for bounded inventory and cycle-balance
  decoding. Remove cycle display-text parsing; retain local funding thresholds,
  unknown-balance handling, sorted inventory and manifest-fallback diagnostics
  ([Tooling #335 — Share bounded ICP inventory and cycle decoding](https://github.com/dragginzgame/ic-tooling/issues/335)).
- Delegate empty/odd-length response checks to Host while preserving response
  normalization and terminal-safe diagnostics. Declare diagnostic environment
  defaults in Clap and pass parsed codes/facts directly to handlers.

### 🧭 Migration Notes

- Compact codes still accept numeric and quoted E-prefixed input, including
  unknown `u16` codes. Facts retain numeric/maintained-label tags, unknown `u8`
  tags and full `u64` values. Aggregate fact limits, schema validation and exact
  deployment/source provenance remain independent domain checks.
- Invalid command-line values and missing destructive-migration confirmation
  are usage errors with exit 2. Scripts must use exit status rather than the
  former `ERROR:` wording. Decoded public-error payloads and execution failures
  retain exit 1. Rejected values remain terminal-escaped in Clap diagnostics.
- Diagnostic environment precedence remains explicit flag, `ICP_ENVIRONMENT`,
  then `local`. Hex labels and Unicode whitespace remain CLI presentation policy;
  the shared decoder owns structural hex validation.
- This line has one accepted landing slice: command/value/error ownership with
  its direct tests, documentation and propagation, tracked by
  [#627](https://github.com/dragginzgame/icydb/issues/627). No schema, protocol or
  retained-data conversion is required. Package versions remain unchanged until
  authorized release preparation.
- Inventory decoding now uses the published Host decoder with the CLI's existing
  capture-byte allowance. Sorting and manifest fallback remain local. Wrong-type,
  null, repeated authority fields, array-shaped envelopes and invalid UTF-8 refuse.
- Fixture funding reads structured status JSON and delegates cycle parsing to
  Host. Plain and correctly grouped decimal strings retain the full `u128` range.
  Missing public-only balances skip funding; malformed supplied balances fail
  before top-up or fixture loading. The existing local-network requirement and
  threshold remain authoritative. The old display-text parser and its test-only
  forwarding helpers are removed, with process tests exercising the consumer flow.
- Host Tools 0.83.0's registry archive matches the lockfile checksum and records
  source commit `094b7787166fd968f512518c1a0722c73cd86122`.
  [IC Tooling #335](https://github.com/dragginzgame/ic-tooling/issues/335) retains
  producer and consumer delivery evidence. No unpublished dependency override is
  needed, and package versions remain unchanged by this adoption.
