# IcyDB CLI 0.295

## [0.295.1]

### 🩹 Fixed

- Admit ICP manifests as regular files before reading inventory fallbacks.
  Direct FIFOs and symlinks to them cannot
  wait for a writer; regular-file symlinks, UTF-8 refusal and existing refresh
  outcomes are preserved. Reuse canonical Host FS admission and Host Process
  test watchdogs ([#615 — Refuse non-regular ICP manifests](https://github.com/dragginzgame/icydb/issues/615)).
- Resolve fixture-funding networks through bounded `icp project show` output
  and the canonical Host Tools effective-project parser. Honor parent-project
  discovery and resolved YAML rather than scanning a raw manifest or assuming
  an environment named `local`. Failed, malformed, oversized, missing or remote
  facts skip automatic top-up while preserving fixture loading, explicit refresh
  authorization and the existing cycles threshold/amount
  ([#616 — Resolve fixture funding from effective ICP facts](https://github.com/dragginzgame/icydb/issues/616)).
- Preserve failed ICP inventory observations across manifest fallback. Successful
  fallback warns with the original command/environment/status/diagnostic; a
  failed fallback reports both causes. Keep existing fallback outcomes, bounded
  capture and terminal escaping. Structured missing-canister guidance also
  retains optional inventory failures without replacing its primary setup
  advice ([#617 — Retain ICP inventory diagnostics during fallback](https://github.com/dragginzgame/icydb/issues/617)).
- Escape canister/environment scalars in CLI-owned inventory, lifecycle,
  fixture, setup/status, SQL/observability and interactive messages with the
  existing Host Text policy. Preserve report-owned newlines, printable Unicode,
  literal backslashes and exact target bytes forwarded to ICP. Apply the same
  policy to known-canister hints and metrics-reset confirmation
  ([#618 — Escape ICP target metadata](https://github.com/dragginzgame/icydb/issues/618)).
- Escape file-path and error-detail scalars in upgrade admission, optional history
  warnings, diagnostic artifact reads/publication, output confirmations and
  temporary-argument failures. Keep original paths for I/O and ICP arguments,
  completed SQL after history failures, create-only publication and payload bytes
  ([#620 — Escape file paths in CLI diagnostics](https://github.com/dragginzgame/icydb/issues/620)).
- Replace the fallback manifest's line/list scanner with the selected Host Text
  YAML decoder. Preserve block/flow lists, inline comments, quoting and exact
  decoded names; refuse malformed documents, duplicate mapping keys and invalid
  inventory shapes before status probes. Keep regular-file admission, existing
  file-size policy, empty selections and ICP's ownership of effective project
  resolution ([#621 — Decode fallback ICP inventories with canonical YAML](https://github.com/dragginzgame/icydb/issues/621)).
- Escape unsupported diagnostic artifact format values with the existing Host
  Text policy in deployment/source lookup and source export errors. Preserve
  exact format/version refusal, printable Unicode and literal backslashes;
  reject before ICP calls or output publication
  ([#623 — Escape unsupported diagnostic artifact formats](https://github.com/dragginzgame/icydb/issues/623)).
- Admit diagnostic error JSON paths through Host FS regular-file opening before
  reading the selected descriptor. Refuse direct and aliased FIFOs without a
  writer while retaining regular-file symlinks, explicit piped stdin and the
  existing 64 KiB limit and public Error decoding
  ([#624 — Refuse non-regular diagnostic error JSON inputs](https://github.com/dragginzgame/icydb/issues/624)).
- Escape diagnostic entity/path and fact-label scalars, rejected code/fact inputs
  and decoder/reader error details through Host Text. Keep report-owned lines,
  printable Unicode, literal backslashes, original artifact bytes and exact
  identity/provenance matching; stale metadata still withholds names
  ([#625 — Escape diagnostic lookup inputs and schema labels](https://github.com/dragginzgame/icydb/issues/625)).
- Correct the transport-failure label for SQL data updates. Keep query and DDL
  labels, endpoint selection, escaped target context, failure status and the
  update-outcome warning unchanged. Failed or malformed replies still dispatch
  exactly one call.
- Match refresh deployment errors to the selected plain-deploy or reinstall
  command. Funding-skip warnings now state that a local network was not confirmed,
  covering unavailable facts as well as remote targets. Keep successful-status
  admission, confirmation, call counts, top-up policy and stop-before-fixtures
  behavior unchanged.

### 🧹 Cleanup

- Scan interactive SQL boundaries directly from a peekable character iterator
  instead of collecting every byte offset first. Preserve doubled quotes,
  ordinary backslashes, Unicode boundaries, pasted statements and unfinished
  suffixes; routing, history and EOF/interruption behavior remain unchanged
  ([#622 — Remove redundant SQL shell offset buffering](https://github.com/dragginzgame/icydb/issues/622)).
- Delegate text/JSON/id-only status syntax and installation-fact decoding to
  the adopted Host Tools owner. Remove the duplicate local selector and JSON
  projection; retain selected environments, inherited/captured output, bounded
  probes, principal checks, fixture funding and failed-probe refusal before
  refresh effects ([#626 — Delegate ICP status mechanics to Host Tools](https://github.com/dragginzgame/icydb/issues/626)).
- Delegate ICP call syntax and binary-argument flags to the existing Host Tools
  builder. Preserve exact query/update arguments, endpoint names, raw target and
  file bytes, selected environment, hex response format and IcyDB's capture and
  uncertain-mutation handling. Private argument-file custody and Wire decoding
  remain at their existing owners.
- Remove the private SQL constraint-finding hex formatter and use IcyDB's
  canonical lowercase encoder for fingerprints and primary keys. Preserve empty
  input, leading zeros and exact lowercase text without changing native findings
  or terminal-report structure.
- Compare borrowed shell input against help/exit spellings with ASCII-insensitive
  equality instead of allocating lowercase copies before SQL dispatch. Preserve
  existing whitespace and semicolon handling for meta commands, unfinished
  statements, history and exact SQL bytes.
- Remove migration adoption's single-use generic confirmation runner. Keep its
  explicit `--yes` check, status query and database/head-bound adoption request
  in one flow; unconfirmed requests still stop before any calls, and failed
  status reads cannot dispatch updates. Abort/run loops and outcome handling
  remain unchanged.
- Validate artifact entity uniqueness with the existing tag set alone, removing
  the duplicate full-identity set. Unique tags already imply unique complete
  identities; repeated tags still refuse, including across fingerprints, and
  lookup still requires an exact method/fingerprint/tag match.

### 🧪 Testing

  ([#599 — Diagnose intermittent canister-ID test failure](https://github.com/dragginzgame/icydb/issues/599)).
