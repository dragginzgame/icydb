# IcyDB CLI 0.295

## [0.295.0] - 2026-11-03

### ⚠️ Breaking

- Adopt the named-allocation diagnostics from the [database Storage adoption](../database/0.295.md).
  Align CLI/native metrics codecs with Wire 0.16 and Metrics 0.28, using
  IcyDB-owned report metadata while retaining canonical numeric validation.
  Storage 0.66 shares the same Wire identity; the root graph drops Wire 0.15.
  CLI releases now have an independent version, ledger and publication selection.

### 🩹 Fixed

- Include the exact input and complete captured process output when the CLI
  canister-ID acceptance control fails
  ([#599](https://github.com/dragginzgame/icydb/issues/599)). The released CI
  failure did not include those diagnostics, and its uploaded artifact omitted
  the fixture directory. Principal validation, budgets and command behavior
  remain unchanged; the intermittent failure is not claimed fixed.
- The full 41-case CLI process target passes locally against the exact released
  graph and the preserved incoming lockfile. Eight further concurrent-target
  reliability runs pass, along with strict selected Clippy. These are local
  Linux results, not a replacement hosted/native-macOS pass. Retain the failing
  release job and keep the investigation open until its cause is established.
  After preserving the concurrent cc update, all 41 controls and strict selected
  CLI lint also pass against that final locked graph.


### 🛠️ Tooling

- Adopt Host Tools 0.79.0 with canonical Platform 0.19 / Types 0.18 alignment.
  The selected interface/response Rust sources match 0.78.1; command behavior
  and process budgets are unchanged. Keep Foundation 0.74.2 and Text 0.74.1.
- Add focused all-target CLI lint and native test commands using the existing
  Cargo environment and test concurrency policy. They include CLI process
  controls without selecting database test suites. Full workspace CI and release
  validation remain unchanged while group-plan qualification is open in
  [#603](https://github.com/dragginzgame/icydb/issues/603).

  Canic composition are not requalified by these Linux checks.
