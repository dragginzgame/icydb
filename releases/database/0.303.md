# IcyDB database 0.303

## [0.303.0] - 2026-11-08

### Added

- For [#323](https://github.com/dragginzgame/icydb/issues/323), add
  `execute_trusted_typed_write_bulk` over the existing atomic typed executor.
  `TypedBulkWriteLimits` bounds each batch's rows, canonical staged bytes and
  encoded results, plus total attempted inputs and successful batches. Charge
  refused attempts; retain a reduced batch size rather than probing the full
  size repeatedly. Only a stage-qualified precommit byte refusal permits a
  smaller attempt. Preserve ordinary typed causes and stop on constraint,
  budget, journal-backlog and publication errors without retrying them.
- Return confirmed original-input positions, commit boundaries, affected-row
  observations and assigned-key results on both completion and failure. The
  existing atomic batch API stays atomic. Applications retain authorization,
  normalization, revisions, public error mapping and cross-message resume.
  This removes the need for consumer Candid sizing and diagnostic-string retry
  classification; it makes no instruction, allocation or Wasm saving claim.

  The inventory binds the exact accepted root. Normal commit preparation and
  retained range verification use accepted SchemaStore root authority and never
  decode or rewrite the candidate bundle. Inventory size remains bounded by the
  existing active/retired-owner ceiling; this is not a per-owner constant-cost
  allocation claim.
- Preflight and encode both publication records before writing either, then apply
  them synchronously under the existing marker-owned fatal-contradiction/IC
  rollback contract. Reopen joins only a matching pair. Preserve exact range
  replay, marker identity, retirement and rebind behavior. Missing or mismatched

  `ICYSCMID`, both version 1. Prior `ICYDBNX\0` images and `ICYSCMAP` control trees

  is introduced. Cursor format is unchanged; current-image interruption recovery
  remains required. This is the source correction for #102; IC instruction/cycle
  and total/code-section Wasm deltas remain unmeasured.
