# IcyDB database 0.309

## [0.309.0] - 2026-11-11

### ⚠️ Breaking

- Adopt Storage 0.73's independently implemented backing, Map/Set/region, Vector
  and Cell engines. Current formats are STORNAM1, STORMAP1, STORVECT and STORCELL,
  version 1. Previous whole-store images are rejected without writes; hosts must
  explicitly provide fresh/reset whole backing. No reset or migration is performed
  by this adoption. Default Storage control reservation grows from 15 to 18 Wasm
  pages. Rebuild consumers against the new public Storage type identity.
- Adopt Wire/Derive 0.21.1 and Testkit 0.100. The schema codec error and Wire
  metadata traits, plus the facade's native testing re-exports, use the new
  supplier identities. Downstream Rust consumers must rebuild together.
  The retained browser contract baseline remains the byte-contract authority.
- Generated TypeScript definition names now derive from their types, replacing
  positional `WireType123` names. Regenerate browser clients and update positional
  imports. Public IcyDB names remain explicitly registered at their existing owner.
  Review of all 228 previous and 285 current definitions preserves the ordered
  layouts and all 111 public names. The refreshed baseline changes names/aliases
  only; endpoint identities, modes, budgets and native vectors are unchanged.
  The later Wire 0.21.1 patch refreshes the shared browser runtime. Maintained
  callers contain no positional type imports.
- `drive_startup` now takes `&PocketIcInstance` from Testkit and a zero-argument
  async observation closure that captures the client. The lifecycle owner keeps
  its managed server alive through polling. `TickUntilError` preserves observation
  failures and exhaustion; upstream PocketIC transport panics propagate.
- Wire 0.20 uses upstream Postcard decoding. Redundant varint groups are admitted
  within primitive/target width bounds; browser lengths use Wasm32 bounds. Maps
  and custom Serde visitors can normalize values. Regenerate browser clients and
  keep original frames for exact retries, raw-byte signatures and hashes. Encoder
  bytes and endpoint identities remain the maintained contract. Schema artifacts
  and durable integrity jobs retain their existing re-encoding identity checks;
  redundant artifact bytes report `NonCanonical` rather than a decode failure.

  Its library sources are unchanged from 0.73.1; this is a producer-tooling update,
  with no additional API or retained-format transition. Qualification retains its
  existing independent compatible selection.

- Update the private SQLite reference adapter to exact rusqlite 0.42.0 with
  libsqlite3-sys 0.40.0, retaining bundled SQLite, scalar-function and
  load-extension features. SQLite remains 3.54.1 with the same checked source ID
  and compile-option set; result mapping and SELECT/mutation contracts are unchanged.
- Select Runtime 0.21.1, Types 0.19, Host Foundation 0.76.4,
  Host Text 0.74.5 and Host Tools 0.90.0 where consumed. Retain compatible
  patch minimums and unrelated incoming lock selections. Runtime owns the
  transitive IC0 bindings; product packages continue to select Platform owners.
- Preserve the incoming product Types 0.19.2 patch during Storage adoption;
  native qualification independently retains compatible Types 0.19.1.

  Its exact thiserror 2.0.18 requirement changes only that graph; qualification

  application startup test uses that narrow edge while Testkit retains all
  server preparation, lifecycle and polling responsibilities. Remove assertions

### 🧹 Cleanup

- Cargo dependency-admission fixtures copy the current Git-visible source once,
  including pending files and excluding deleted paths. Remove archived-HEAD
  overlays and completed workspace-migration exceptions; retain the existing
  grouped, renamed-dependency, graph, source and ordering checks.
- Eleven consumer fixtures use the installed lifecycle helper for physical
  directory allocation, explicit completion, cleanup status and failure retention.
  Custom diagnostic replay and owned-process termination stay in their callers.
  The existing caller-trap matrix also covers function-level nounset and cleanup
  failure, preserving the original failure status and retained evidence.
- Eighteen internal index/page constructors now call their existing canonical
  errors directly, preserving class, origin, detail and facts. Remove the inert
  old/new key-error selector; retain distinct corruption, invariant and internal
  failures plus constructors carrying structured facts or intentional attributes.
- All five primitive visitor implementations use the existing single leaf-type
  inventory. Public traits, covered types and container/hook traversal are unchanged.
- DISTINCT scenarios share fresh-request pagination/retry setup at their existing
  test owner. SQL normalization budget cases share their existing preparation and
  typed-error wrapper. All scenario inputs and assertions remain in their owners.
- The concrete key-stream envelope shares one exhaustive dispatch table across
  polling and its three count/page-bound hints. Expansion preserves all twelve
  original variants and method calls; stream representations and allocation are
  unchanged.
- Same-direction predicate bounds share comparison admission, coercion and
  strictness selection. Lower bounds still keep the greater endpoint, upper
  bounds the lesser endpoint, and equal endpoints preserve stable left selection
  unless only the right endpoint is strict. Opposing bounds keep their own rule.
- Data/index bulk provenance preflight now belongs to the existing positioned
  overlay metadata owner. Both retain sorted/deduplicated targets, their typed
  receipts and backend checks. Exact/superseded retirement and rejection before
  effects remain unchanged; schema-only canonical-key and recovery handling stays
  at its existing owner. New controls cover later-target refusal and mixed receipts.
- Standard-library/Serde derive paths reuse their canonical generated trait
  paths. Custom procedural-macro paths and the derive eligibility set are
  unchanged. Token generation returns its existing result directly. Remove
  three empty inherent impl blocks and an ignored private error-message argument;
  public error constructors and rendered diagnostics retain their contracts.
