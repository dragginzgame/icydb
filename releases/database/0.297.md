# IcyDB 0.297

## [0.297.0]

### ⚠️ Breaking

- Adopt Metrics 0.29 and return IcyDB-owned instruction report values instead of
  recorder types. Preserve report fields, bytes and numeric refusal while keeping
  recording separate from report validation and arithmetic
  ([Observability #130 — Instrumentation-only Metrics](https://github.com/dragginzgame/ic-observability/issues/130)).

- Restore omitted journaled stores from their exact dormant allocation quartets,
  preserving retained bytes after a failed deployment. Refuse topology changes
  while generated applications are pending
  ([#31 — Recover rejected store topology changes](https://github.com/dragginzgame/icydb/issues/31)).

- Replace the earlier database boot identity with `ICYDBRT\0`, retaining the
  sole current version-1 framing. Reject earlier identities before control or
  payload decoding without rewriting retained bytes. Fresh installation is the
  maintained contract; no compatibility reader or automatic reset is added.
  Current-format interrupted commit, replay and fold remain supported.
- Retire earlier-format repair requests for abandoned unique-index generations
  and unknown Unicode transform provenance. Preserve the already-delivered
  exact-generation abort cleanup and Unicode 17 compile-time guard. This is an
  explicit scope disposition, not a repair or conversion of earlier databases
  ([#38 — Retired orphaned index generations](https://github.com/dragginzgame/icydb/issues/38),
  [#111 — Retired Unicode index provenance](https://github.com/dragginzgame/icydb/issues/111)).

- Normalize Account's absent/all-zero subaccount at every constructor,
  deserialization and Platform conversion. Preserve nonzero bytes and canonical
  text; equality/hashing, fixed storage, index keys and uniqueness now share one
  default identity. Keep the deserializer's Account container name aligned with
  serialization and seed nonzero optional subaccounts for native binding
  reflection. Reject explicit-zero flags in stored frames. Existing databases
  require the new installation contract
  ([#70 — Canonical default Account identity](https://github.com/dragginzgame/icydb/issues/70)).
- Derive database target identity from its durable incarnation; retain each
  store's own path/capability/allocation binding without incorporating unrelated
  stores. Generated readiness and explicit application targets share this owner.
  Bind generated readiness to declared entity/store assignments and storage mode, excluding unused stores. Remove registry enumeration/sorting from identity-only reads. Supported heap
  membership changes preserve migrated lineage and pending completion/abort,
  while accepted heads still bind the current complete topology
  ([#32 — Stable identity across store changes](https://github.com/dragginzgame/icydb/issues/32),
  [#90 — Finish pending applications after intervening changes](https://github.com/dragginzgame/icydb/issues/90)).

### 🩹 Fixed

- Allow generated migrations to retry corrected source data after abort through
  an explicit declared attempt number, preserving exact-attempt replay and
  bounded retained rejection findings
  ([#96 — Retry an aborted migration](https://github.com/dragginzgame/icydb/issues/96)).

- Add explicit administrative retirement for abandoned or corrupt shared progress
  records, using exact observed evidence and completed recovery; preserve normal
  receipt acknowledgement and already committed effects
  ([#169 — Recover abandoned progress capacity](https://github.com/dragginzgame/icydb/issues/169)).

- Retain admitted source lineage with pending generated validation and publish it
  atomically on completion after restart or unrelated schema changes; abort
  preserves the prior digest
  ([#94 — Maintain pending source lineage](https://github.com/dragginzgame/icydb/issues/94)).

- Extend row-local sibling selection to nonconsecutive columns and paths inside
  arithmetic and CASE expressions. Inspect compiled syntax without executing
  future branches; retain raw leaf bytes or owned-parent positions until each
  authored read. Share first-match selection for raw, borrowed and synthesized
  roots; admit cache backing before allocation and retain typed budget facts.
  Compare with the maintained uncached path reader and preserve cached ordering
  values, complete-root corruption rejection and missing/null semantics
  ([#400 — Reuse nested map selection across projections](https://github.com/dragginzgame/icydb/issues/400)).

- Keep frozen row authority, admitted envelope offsets, validated scalar views
  and already-materialized values with an accepted filtered row through kernel
  and direct cursor-page projection. Move owned values; reconstruct borrows only
  from the same immutable row and reject a different accepted contract. Untouched
  fields remain lazy, and rejected rows acquire no handoff state. Charge sparse
  saved state and restored cache backing before allocation, include retained
  backing in window accounting, and preserve full-row/key refusal order. Direct
  projection now moves an already-materialized catalog scalar before considering
  its raw scalar shortcut. Filter-to-order reuse remains with its existing owner
  ([#410 — Reuse filtered rows through projection](https://github.com/dragginzgame/icydb/issues/410)).

- Budget canonical child ordering through the existing construction authority.
  Reuse the shared sort allowance and raw-key admission for repeated encoding,
  including its coercion/map/member scratch. Reserve two bounded reusable key
  buffers before the existing stable comparator; retain canonical bytes, child
  order and pure replay/rebuild normalization. Refusal remains typed and occurs
  before sorting; complete payload-comparison/normalization and recovery
  accounting remain open
  ([#76 — Budget predicate simplification and normalization](https://github.com/dragginzgame/icydb/issues/76), partial).
