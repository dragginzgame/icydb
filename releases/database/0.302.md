# IcyDB database 0.302

## [0.302.0]

### 🩹 Fixed

- Skip rewriting the live schema checkpoint when recovery replays an already
  materialized identity advance, preserving validation of conflicting advances
  ([#102 — Identity checkpoint writes](https://github.com/dragginzgame/icydb/issues/102)).

### 🧹 Cleanup

- Simplify targeted-rule tests around budget refusal and stable results, removing
  duplicated cases and assumptions about internal allocation/scan formulas.

- Withdraw the pending per-allocation schema accounting expansion. Retain
  existing input size/depth limits, bounded decoding and normalization budgets;
  remove allocation-specific callbacks, metadata copying and bookkeeping tests.
  Close the original normalization finding on its delivered bounded-work fix
  ([#76 — Bounded predicate normalization](https://github.com/dragginzgame/icydb/issues/76)).

### ⚠️ Breaking

- Compare mixed numeric values exactly across predicates, projections and SQL
  sorting; preserve distinct float/Decimal predicate identities. Reject prior
  database images and cursor tokens without deleting retained data
  ([#110 — Exact numeric comparison and ordering](https://github.com/dragginzgame/icydb/issues/110)).

- Adopt published Testkit 0.92. Its Foundation 0.75 execution/cleanup types and
  Platform 0.24 CBOR client errors change native identities behind the public
  testing facade. Native consumers exchanging those types must align with this
  line. Keep explicit finite request budgets, typed startup errors and
  Testkit-owned infrastructure; management DTOs remain exactly 0.11.0.
- The numeric hard cut selects database boot identity `ICYDBNX\0` and cursor
  identity `ICYN`, both version 1.
  Same-format interrupted recovery remains supported.
- Extend #110 consumer tests across adjacent Float64 values around exact Decimal
  0.3, repeated range/BETWEEN queries with and without a secondary index, global
  MIN/MAX and grouped top-K ordering of mixed CASE values. SQL NumericWiden
  bounds deliberately retain residual filtering, including typed float bounds;
  these tests do not qualify physical index-range execution.

### 🔧 Changed

- Adopt Build 0.78, Host Artifacts/Fs/Process 0.75 and Host Tools 0.85 as one
  native cohort. Configure Build progress with its heartbeat interval, removing
  the retired Cargo-output toggle. Retain labels, phases, cache admission,
  artifact custody and complete failure records
  ([#630 — Adopt heartbeat-only Build progress](https://github.com/dragginzgame/icydb/issues/630)).
- Select Platform 0.25, Storage 0.68.7, Wire/Derive 0.17.12 and Metrics 0.29.6.
  Align IcyDB's direct IC0 consumers with Storage on Runtime 0.20, removing 0.19.
  Types 0.18.2 and Host Text 0.74.2 remain current. Host Tools and native Testkit
  now share Platform 0.24, removing the older Platform 0.23 facade from the
  root graph. Runtime/Types retain one identity.
- Platform 0.25 removes facade entrypoint macros and its `cdk` feature. IcyDB's
  direct facade use remains BLAKE3-only; IC0 already comes from Runtime. Native
  Host Tools/Testkit retain Platform 0.24 under their published requirements;
  no cross-version Platform values are introduced at IcyDB's boundary.
- Adopt Shared 0.31.5 at reviewed source
  `b2026a118e38de4af1555c527af327cb604eacdf` through the canonical exporter.
  Include the release-batch guide and isolated outer/inner release-command
  checks. Readmit only the moved pending-note declaration; retain native
  comparison records and full validation fallback for the changed cohort.
