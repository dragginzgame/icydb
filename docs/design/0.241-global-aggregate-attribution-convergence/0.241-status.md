code complexity and, where code generation permits, final raw Wasm.

diagnostics planning/execution. The candidate was measured and reverted. It

## Frozen Closeout Gates

- one semantic resolver and one semantic execution/fallback flow;
- no new cache, state, mode, invalidation edge, public surface or persisted
  representation;
- no net production-type growth and at least 80 net production lines removed;
- ordinary calls perform no diagnostics-only counter work or allocation;
- SQL-only and diagnostics final raw Wasm do not grow;
- existing exact-count and aggregate instruction gates pass, with no focused
  predecessor regression above 1%;
- results, typed errors, cache facts and physical work remain equal;
- Candid, exports and stable extent remain equal.

If those gates cannot be met without a generic recorder framework or another
semantic branch, this design closes as a no-build and the implementation is
reverted.
