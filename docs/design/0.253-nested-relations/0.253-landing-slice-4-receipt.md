## Implementation

- Proposal lowering and current accepted snapshots add exact list, set, and
  map-value path instructions without a predecessor decoder or parallel path
  representation.
- One runtime frontier interprets optional, named, record, enum, list, set, and
  map steps. Direct relations retain their scalar fast path; every nested shape
  converges on the same target-key and reverse-index enforcement flow.
- Per-image traversal and raw-reference counters are shared across every
  relation projected from one row image. One commit budget spans delete
  verification, old/new projection, target existence, and coalesced reverse
  maintenance for the complete atomic batch.
- Raw references are charged before canonical deduplication. Successfully
  proven raw target keys form one batch cache, so repeated targets do not
  consume another lookup or physical read.
