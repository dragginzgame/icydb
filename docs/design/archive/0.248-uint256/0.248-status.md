## Patch 2 Storage And Query Contract

- `icydb::U256` is one transparent, copyable, inline 32-byte value backed by
  `ethnum 1.5.3`; ordinary comparison, hashing and fixed-byte conversion do
  not allocate per value.
- Candid exposes the scalar as `nat` and rejects ingress above `U256::MAX`.
  The exact generated `OutputValue` service change is one `U256 : nat`
  variant; no standalone audit endpoint is retained.
- Rows, primary keys, ordered indexes, group keys and cursor tokens use exact
  IcyDB-owned fixed-width encodings. All changed pre-1.0 discriminators remain
  the single current format version `1`.
- Schema admission, generated bindings, typed writes, SQL literals, equality,
  ordering, indexed ranges, grouping, `DISTINCT`, `MIN`, `MAX`, pagination and
  relation-key eligibility converge through their existing owners.
- Arithmetic and `SUM(U256)` remain outside this patch and are owned by Patch
  3. `I256`, bitwise SQL operators and Ethereum SDK dependencies remain out of
  scope.

## Patch 3 Arithmetic And SUM Contract

- Addition, subtraction, multiplication, division and remainder are checked in
  the exact U256 domain. Overflow, underflow and zero divisors retain the
  existing typed numeric diagnostics.
- Exact U256 operands produce U256 results. Mixed U256 arithmetic remains
  rejected instead of entering Decimal coercion, and `AVG(U256)` stays outside
  the line.
- Constant folding, preview, compiled projection and aggregate expressions use
  one checked value-arithmetic owner. Direct SQL and prepared execution have
  matching result and error contracts.
- The existing fluent field/literal helpers accept constructed U256 values
  through the fallible generic numeric conversion boundary. Full-width values
  remain outside Decimal conversion, and scalar metadata still forbids implicit
  database coercion.
- `SUM(U256)` uses one inline fixed-width payload inside the shared reducer for
  grouped, ungrouped and distinct execution. `ValueReducerState` remains 80
  bytes with 16-byte alignment, and the Patch 1 zero-per-value-allocation
  evidence continues to apply.
