## Delivered Contract

The shared query cache preserves strong concrete-plan and recent-bound memo
reuse. One weighted admission path counts both FIFO/map key copies, template
metadata, operands, accepted-schema graphs and prepared-plan residents.
Replacement measures the complete replacement artifact; eviction and replacement
revoke the old entry's lazy-reservation handle and release its charge once.

The private retained-allocation visitor counts capacities with checked arithmetic
and exhaustive owner-local field coverage. Shared allocations are conservatively
charged per strong reference, without an allocation registry. Ten top-level lazy
residents reserve capacity before attachment. If reservation fails, the computed
owned result still executes without being retained. Deferred raw index bounds
return borrowed buffers, so their future capacity is reserved using the existing
encoder's sizing calculation; they are not eagerly encoded.

The existing 4-MiB/1,024-entry policy remains. Its byte limit covers charged owned
payload, not the whole process heap: allocator overhead, bounded map/FIFO spare
storage and bookkeeping, active execution temporaries, and the separate SQL
compiled-command cache are outside that claim. `Rc`/`Arc` allocation headers and
entry charge control blocks are included in the payload accounting.

Two conservative boundaries are explicit:

- `IntBig`/`NatBig` expose no retained limb capacity. Artifacts retaining them
  decline shared caching, but valid queries still execute. Traversals reaching
  the private depth bound (128), overflowing arithmetic or exceeding budget
  also decline caching.
- Catalog `BTreeMap` nodes use a conservative bound derived from the measured
  Rust 1.97.1 implementation, including node alignment and child edges. This is
  a supported-toolchain assumption, not a stable standard-library allocation
  guarantee; recheck it when changing toolchains.

No operational mode, configuration, endpoint, public request type, persisted
format, dependency or alternate query execution pipeline was added.
