# 0.254 — Admission Cleanup

Date: 2026-09-06. Approved landing slice 4; complete worktree handoff.

## Contract And Scope

The user approved the four design-review findings together: NULL arithmetic
parity, duplicate binding preflight, repeated nested-expression work and stale
design history. Shared arithmetic inference remains the type owner. NULL
propagates only after both children and their operand families validate;
non-NULL mixed-width arithmetic keeps its existing rules.

Query ingress is the one count/placement/depth/payload preflight owner.
`prepare_bound_sql_statement` requires those same inputs to have passed it.
The binding visitor still traverses all original operands. Its internal
`infer_here` argument is false only when an enclosing expression will infer the
entire subtree before folding. Nested comparisons still use the query normalizer
and validator, and IN elements remain individually admitted. No new type or
coercion policy, execution path, cache policy, public option or retained state
was introduced. Current authority, literal cache hits and bound-cache bypass
remain in their existing owners.

This is not a universally single-pass compiler: comparison normalization,
membership contexts, WHERE shape admission and ordinary lowering still do their
required work. The targeted redundant scalar-wrapper/arithmetic checks no longer
lower and infer every enclosing prefix independently.

The design now describes current contracts and links historical source/decoder/
retention investigations to existing evidence. The stale in-progress cost gate
is removed without claiming it passed retrospectively.
