## Retained Outcome

Each runtime-enabled generated entity now supplies one associated static
`TypedEntityDescriptor`. It contains only immutable source identity, ordered
primary-key source identities, ordered field identities, typed field shape and
nullability. Scalar, list and named field contracts are data; the macro no
longer emits an executable request-construction statement for every field.

The existing accepted schema snapshot remains the sole runtime authority.
Binding issuance resolves every descriptor source identity through accepted
source bindings, checks ordered primary-key identity, field kind and
nullability, then issues the same opaque accepted binding as before. A stale,
removed or incompatible source still fails through the existing typed binding
errors. Descriptors are not used to execute reads or writes and are not a
runtime catalog, persisted format or fallback schema reconstruction path.

The pre-1.0 surface is hard-cut to this one representation. The facade-owned
`TypedFieldBindingRequest`, its allocation-backed field tree, the parallel
core request DTO and both conversion layers are removed. `TypedEntityAdapter`
provides one default binding method over its static descriptor, so generated
implementations contain data rather than repeated binding control flow.

## Semantic And Cost Qualification

Focused generation tests cover scalar, list, named and nullable descriptors,
forbid the retired allocation-backed construction tokens, and preserve
composite primary-key source order. Core tests cover primary-key and
nullability mismatch, invalid named identities, accepted renames, name reuse
and stale bindings. The generated public compile contract, representative
schema fixtures, selected package Clippy and the prepared-page behavior all
pass.

The focused PocketIC operation controls preserve every result and move
slightly downward. The largest change is -19,060 instructions for the
ten-entity same-entity batch; no selected operation regresses, and none
approaches the material threshold of both 250,000 instructions and 3%.

No public endpoint, Candid, cursor, accepted-schema, persisted-format,
transaction or execution-route contract changes. The full repository suite and
downstream CI/install remain user-owned validation.

## Complexity Delta

The implementation and focused tests touch nine files at approximately
`+275/-243` lines. Most added lines are explicit core descriptor fixtures and
accepted-authority mismatch tests. Production deletes the facade-owned request
type, the core-owned dynamic request type, their recursive conversion methods,
the temporary request vector and every generated per-field construction body;
it adds one core-owned static descriptor representation and ordered accepted
primary-key validation.

The source surface is modestly larger because the maintained contract is more
fully tested, but the production binding flow is simpler: static generated
data enters one validation owner and produces one opaque accepted binding.
Runtime state space remains neutral, with no new behavior axis, registry,
cache, mode, persisted state, callback or compatibility layer.
