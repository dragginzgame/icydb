Status: CLOSED — PATCH 2 MEASURED NO-BUILD — NO 0.242.1 CANDIDATE

Design authority: [0.242 design](./0.242-design.md)

Exact released predecessor:

## Assignment

The user explicitly authorized 0.242 after a current-baseline audit showed
that equivalent indexed range counts retain row/index traversal while existing
exact entity and finite-prefix counts do not.

This line owns one family-level exact-cardinality target. It does not authorize
generic aggregate metadata, covering-index count execution, new statistics,
persisted range sums, another cache or a second planner/index authority.

## Frozen Gates

- one canonical target for equivalent row-count/range forms;
- direct non-nullable `Int32` leading component and one selected complete
  accepted user index;
- no residual, grouping, ordering, window, `FILTER`, `DISTINCT`, union,
  intersection or runtime index selection;
- one new production type, one cached-plan variant and one metadata operation;
- no new module, cache, mutable owner, persisted state, invalidation edge,
  public behavior axis or compatibility path;
- no more than +200 net production Rust lines;
- no more than +4,096 final raw production Wasm bytes;
- principal cold case at most 2M instructions and at least 20M saved;
- true warm at most 1.5M instructions;
- one-sided full range at most 3M and at least 85M saved;
- zero row gets and zero physical index-entry reads on exact success;
- bounded fallback no more than 5% above predecessor and no semantic budget
  mutation surviving the probe;
- exact results/errors, Candid, exports, stable state and generated APIs
  unchanged.

If any gate requires a second encoder/classifier, generic aggregate framework,
row probe, persisted prefix sum, cache or authority, Patch 1 closes as a
measured no-build and all runtime/fixture changes are reverted.
