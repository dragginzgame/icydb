## Decision and maintained behavior

Initial preparation always constructed the empty continuation and enabled
unpaged hints; resumed preparation always disabled those hints. The existing
route-source match now derives both facts. Initial preparation no longer
forwards the continuation, two options structs no longer store an independent
unpaged flag, and the initial route variant retains only its route plan.

The downstream runtime still carries the resolved flag because hint normalization
uses it. Resumed eligibility is not inferred from the presence of a logical
cursor boundary: physical-only continuations must still retain resumed policy.
The scan-hint implementation, current-authority checks, route selection, cursor
authentication and common execution flow are unchanged. No public API, cache,
format, execution path or behavior axis is added.
