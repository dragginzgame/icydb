# 0.255 slice 18 — Scalar reporting and result handoffs

Date: 2026-09-07. Explicitly authorized after the scalar handoff audit.
Baseline is the complete unpushed slice 17 candidate; active release notes remain
under 0.255.3. Package versions and published notes are unchanged.

## Decision and maintained behavior

Both scalar page entrypoints had one caller that always declined their optional
execution-mode output. That unused output, its branches and its forwarding
accessor are removed. The canonical route-mode accessor still serves EXPLAIN and
grouped execution; active diagnostics are not removed.

The shared scalar setup now returns the kernel's existing attempt directly,
without wrapping it in a single-field result. Materialized output returns its
maintained page/scan-count boundary directly, eliminating an intermediate tuple
alias, forwarding function and unused payload-splitting method. The aggregate
sink likewise consumes its existing row attempt directly.

Both terminals still use one setup owner and the same residual-retry kernel.
Authority checks, route normalization, probe limits, errors and pagination are
unchanged. ExecutionOutcomeMetrics remains the shared retry contract: scans
accumulate with saturation, while output counts describe the latest attempt.
The new regression checks that maintained behavior, not the absence of old
wrappers. No mode, cache, API, format, authority or execution route is added.
