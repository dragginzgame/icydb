# 0.255 slice 17 — Prepared-layout handoff cleanup

Date: 2026-09-07. Explicitly authorized after the follow-up read-only audit.
Baseline is the complete, unpushed slice 16 candidate, not published 0.255.2.
Both slices remain under active 0.255.3; package versions are unchanged.

## Decision and preserved boundaries

The supplied-layout handoff had one caller, which always supplied a layout.
Its optional-input fallback and mode arguments were therefore unreachable
generality. The other scalar-cache callers either explicitly requested retained
cursorless output or entered only after a retained-output guard; none selected
the no-projection cursorless cache.

The handoff now consumes the supplied layout directly and cannot return a typed
layout-compilation error. Its unused arguments, extra helper and caller error
propagation are removed; layout construction remains fallible at its existing
upstream owner. The existing prepared-plan owner retains one explicitly
named cursorless retained-layout cache, without mode selection parameters or an
unused cache resident and its clone/accounting wiring.

The scalar entrypoint preserves the existing cursor-emission decision: emitting
queries do not use the cursorless cache, and runtime assembly derives their
retained output/order/anchor slots. Accepted authority, expression evaluation,
aggregate reduction and row decoding are unchanged. No replacement mode, cache,
authority, format, evaluator or endpoint is introduced.

## Cycle result and landing decision

All 252 measured calls preserve output parity and fixture expectations. Three
samples agree exactly for every cell on PocketIC 16.0.0 with
Application/Normal/Production settings. One of the 42 controls exceeds the
predeclared +1% ceiling:

| Control | Baseline cycles | Candidate cycles | Delta | Change |
| --- | ---: | ---: | ---: | ---: |
| Repeated nested projection, 256 rows, cold | 32,297,501 | 32,625,792 | +328,291 | **+1.016459%** |
| Same query, warm | 81,512,744 | 82,019,945 | +507,201 | +0.622235% |
| Scalar SUM, 256 rows, cold | 35,536,886 | 35,519,846 | −17,040 | −0.047950% |
| Scalar SUM, 256 rows, warm | 92,869,460 | 93,084,952 | +215,492 | +0.232038% |

All other controls meet the ceiling. The largest measured decrease is 1.109641%
for the 64-row warm empty-result control. These mixed results are not a general
speedup claim. No cause for the cycle increase has been established; the repeated
samples do not justify calling it measurement noise.

The temporary localhost PocketIC server was started and stopped by the maintained
wrapper; the run completed successfully in 23 seconds. No endpoint wrapper was
added to the repository.

**The numerical cycle gate is not met; the user accepted this slice-specific
exception on 2026-09-07.** Implementation and behavioral validation are complete,
and slice 17 is ready for handoff under 0.255.3. The measured 1.016459% increase
remains recorded against the original 1% ceiling; acceptance does not change the
measurement, establish its cause or widen future gates. Full release validation
remains user-owned.
