## Release-Validation Correction

The first user-owned release run exposed host-dependent libtest concurrency in
the standalone no-default core lane. On a 64-CPU host, the kernel OOM-killed
the otherwise passing 1,513-test process at approximately 21.2 GiB anonymous
RSS. The exact failed library target subsequently passed with eight test
threads: 1,511 passed and 2 remained deliberately ignored.

The canonical local release path and shared CI core path now both apply that
eight-thread ceiling. The existing workspace-test ceiling remains four. An
automation invariant prevents either core or workspace release/CI recipe from
silently returning to unbounded host-derived libtest concurrency.
