# 0.256 slice 4 — Owned blob input

## Outcome and scope

The existing typed scalar adapter now calls `Blob::into_bytes()` instead of
`to_vec()`. It transfers the already owned buffer into `PublicValue::Blob` rather
than copying and discarding it. Scalar and nested optional/list inputs retain
their values, order and NULL-versus-empty distinction. Current binding checks
and subsequent accepted-field admission remain unchanged. No API, schema,
configuration, execution route or application change is added.

Two Rust files change: one production line replaced (zero net production lines)
and 94 added test lines. Ownership is simpler; the execution shape is unchanged.
Five documentation files accompany the change: design, status, root/detailed
release notes and this receipt. Earlier unpushed changes and Cargo versions are
preserved.

- [Scalar conversion](../../../crates/icydb/src/db/session/write.rs)
- [Ownership/admission regressions](../../../canisters/audit/one_entity_typed_query/src/lib.rs)

blob, a 16-blob list, and a text control. Input construction and generated binding
issuance are excluded; the measured `bind_typed_input` call still includes its

after: `c8c4dcfbbe00491ce602195f02c4f257dc3ce7223f1580ade9c6943c3404d9a7`.
Both Wasm gates pass. This instrumented actor differs from slice 3's actor:
do not add their byte deltas or infer either application's Wasm size.

All 144 measured updates return the expected byte length and checksum, with
three identical samples per variant/control. Each installation has cold and
warm calls; variant order alternates between samples. Request cycles include
Candid, input setup and checksum work; the separate instruction counter covers
the typed-input call and branch overhead, not the whole request or a database
write. The largest request reduction is 0.8225% for sixteen 64-KiB blobs cold
(167,843,602 → 166,463,037 cycles); warm falls 0.7359%. That cold call's local
instructions fall 79.1647% (1,744,004 → 363,369). A single 64-KiB blob falls
0.0446% cold/0.1543% warm in request cycles. Text controls add only three cycles;
the maximum increase is 0.0000355%. Every +1% gate passes without an exception.

The first cycle client incorrectly decoded three Candid return arguments as one
tuple record; only the client was corrected, and both saved Wasms were retained.
The read-back regression initially used a public full scan; even with a limit
that requires explicit trusted authority. It now uses the maintained trusted
scan surface to inspect the empty fixture after both rejected writes. Neither
failure required an engine change or relaxing admission.

The wrapper stopped both temporary PocketIC 16.0.0 servers (the failed client
attempt and successful 51-second run). Existing networks were untouched.
