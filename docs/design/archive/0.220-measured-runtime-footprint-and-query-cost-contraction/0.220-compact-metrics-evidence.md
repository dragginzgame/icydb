# IcyDB 0.220 Compact Metrics Candidate Evidence

## Decision

Patch 4 closes as an evidence-backed no-production-change disposition. The
array-backed metrics candidate preserved the maintained behavior but failed the
frozen raw-Wasm gate, so none of its runtime implementation is retained.

## Candidate

The bounded candidate replaced the mutable field-per-counter state with:

- 135 explicitly coded global counter slots;
- 133 explicitly coded entity counter slots;
- exhaustive fixed code-to-slot mappings independent of enum declaration
  order;
- a 4 KiB canonical path key over `Rc<str>`;
- a 4,096-entry `BTreeMap` bound from the schema-assignment ceiling; and
- one consolidated typed event classifier shared by global and entity
  attribution.

It also projected the arrays back into the unchanged compact and extended
reports, retained saturating arithmetic and activity ordering, and removed the
superseded mutable structures and duplicated classifier modules. Focused tests
covered all code/slot identities, saturation, path and inventory bounds,
same-path continuation, rename retention, reset, compact/rich projection,
query suppression, update accumulation, trap isolation, and upgrade reset.

Two candidate slot implementations were measured: an explicit exhaustive
runtime match and arithmetic over the frozen numeric ranges backed by a
test-only exhaustive mapping. Both produced the same final artifact:

- final raw non-gzipped Wasm: 291,948 bytes;
- final Wasm SHA-256:
  `761f7c4f3e7d9f57d5a2f945779ba3b1f0fdc40a15148efcc2566a8b5ae45630`;
- compiler-emitted Wasm: 336,849 bytes;
- compiler-emitted SHA-256:
  `86474f496482e1abb4ad53f419af90105745e5b1b2e0118f44521bd082ac4bcf`;
- deterministic gzip: 121,197 bytes;
- Candid: the same 724 bytes and SHA-256 as the released baseline;
- final IC method export count: 3;
- non-metrics `default_empty` control: unchanged at 88,889 final bytes.

The final candidate is 45 bytes larger than the released baseline. The frozen
500-basis-point Patch 4 gate required no more than 277,307 bytes, so the
candidate missed acceptance by 14,641 bytes. Source-level consolidation and
eliminated per-event string allocation do not override the final-artifact
authority.

## Retained Impact

- Production source and runtime behavior are byte-for-byte the released
  0.220.0 implementation after the candidate rollback.
- Public compact codes, extended field names, Candid, exports, ordering,
  update-side metrics, query suppression, reset behavior, and heap-only
  lifecycle are unchanged.
- No stable codec, metrics migration, compatibility path, feature flag, shadow
  dispatch, or alternate representation is added.
- Retained instruction and allocation deltas are zero because no production
  candidate remains.
- Patch complexity is documentation-only: one evidence report plus tracker and
  root `Unreleased` updates. Runtime complexity is unchanged.

Full workspace tests and the complete local/production artifact matrix remain
user-owned. They are not required to authorize a rejected candidate whose
production diff is empty.
