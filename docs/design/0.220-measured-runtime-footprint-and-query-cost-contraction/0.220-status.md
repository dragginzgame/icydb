## Frozen Cross-Patch Invariants

- Raw non-gzipped final deployable Wasm is size authority; gzip is secondary.
- Accepted schema snapshots remain runtime authority.
- Generated models remain proposal, reconciliation, convenience, and test
  inputs only.
- `apply_schema` remains the sole catalog-native schema application owner.
- No public Candid, method export, successful query result, ordering, cursor,
  mutation atomicity, error semantic, or persisted format changes without an
  explicit prior design revision.
- Query-side global metrics remain non-durable; update-side metrics retain
  current semantics; explicit call-local sinks remain observable.
- No benchmark-specific dispatch, cost model, query hint, old/new runtime
  fallback, compatibility wrapper, or dual artifact pipeline is added.
- Final Wasm identity includes every transform, injected IC/Candid metadata,
  and shrink stage; SHA-256 is taken from the exact installed bytes.
- Controlled size comparisons differ by one declared capability only.
- Metrics dispatch precedence is scoped sink, query suppression, then durable
  global sink; query context is synchronous and never spans `.await`.
- Metrics are heap-only, reset on install/upgrade, use explicit stable metric
  code values, saturating counters, and never index storage by `EntityTag`.
- Phase ownership distinguishes additive children from inclusive parents and
  nested observations; warm-at-entry requires a prior successful update and
  cache-hit proof.
- A size patch reports instructions; a performance patch reports raw Wasm.
- Per-patch deltas and cumulative opening-to-current budgets must both pass.
- Every production handoff reports files, approximate line delta, delivery
  domains, and whether complexity became simpler, neutral, or more complex.
- Full workspace tests remain user-owned push validation.
