# IcyDB 0.220 Patch 6 — SQL Boundary Contraction Evidence

## Decision

Patch 6 selects the duplicated SQL result-adapter path rather than a Cargo
dependency. Core already derives exact fixed-decimal scales from the accepted
`ProjectionSpec` alongside outward projection labels and carries both through
the shared structural payload. The facade nevertheless reparsed labels such as
`ROUND(..., scale)` as a fallback while packaging projection and grouped rows.

The candidate removes that second interpretation path. Exact core scale
metadata is now the sole authority for fixed-scale SQL rendering. There is no
new DTO, parser, fallback, dependency feature, or value representation.

## Reachability And Complexity

Symbol-bearing Wasm attribution selected the facade-owned
`round_projection_scale` path from the SQL subject. It was absent from the
matched typed subject and retained only through SQL result conversion.

After the hard cut:

- pre-shrink SQL attribution falls from 20,049,549 to 20,045,358 bytes
  (-4,191);
- name-shrunk SQL attribution falls from 4,172,728 to 4,171,805 bytes (-923);
- `round_projection_scale` and its display-label parsing path are absent; and
- the two production files change by `+9/-42` lines, a net deletion of 33.

The Cargo feature and dependency graph is unchanged. This is the design's
explicitly permitted duplicated-adapter outcome, not a dependency-version
sweep. The implementation shape is simpler: one exact metadata consumer
replaces two competing interpretations of the same projection intent.

## Semantic Evidence

- The SQL facade's 28 focused unit tests preserve scalar, decimal, blob,
  semantic-value, projection, grouped, Candid, zero-scale, aliased-scale, and
  fixed-scale behavior.
- Live PocketIC tests preserve scalar arithmetic, literal and field-to-field
  `ROUND`, aliases, ordered projections, and grouped aggregate `ROUND` output.
- The facade compiles without default features, so the typed/non-SQL boundary
  retains no SQL dependency.
- The measurement-contract test accepts the documented zero-minimum Patch 6
  complexity disposition while retaining the 8 KiB raw-Wasm and 1%
  instruction regression ceilings.

Public SQL values, Candid, endpoint exports, accepted schema, parsing,
comparison, mutation behavior, cursors, and persisted formats are unchanged.
No compatibility path is retained.
