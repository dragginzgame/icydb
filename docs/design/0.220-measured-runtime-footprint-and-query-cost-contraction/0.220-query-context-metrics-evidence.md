# IcyDB 0.220 Query-Context Metrics Evidence

Status: Patch 3 complete

## Routing Contract

Generated query wrappers enter one synchronous closure-scoped context while
calling their private handler. Metrics routing is exact:

1. an explicit scoped sink receives the event;
2. otherwise query context suppresses the default global sink; and
3. otherwise the process-local global sink receives the event.

Nested contexts restore the prior depth. Returning a future exits the context
before that future is polled. The runtime constructs no path-bearing executor
span when a query has no explicit scoped sink. Update methods retain ordinary
global metrics.

## Runtime Proof

The audit-only local SQL feature adds one trap probe without changing the
production feature row. PocketIC proves that:

- a normal generated SQL query leaves compact global/entity metrics unchanged;
- a trapped query cannot contaminate the following generated query;
- a second trapped query cannot suppress a following fixture-reset update; and
- that update records ordinary durable global metrics.

Typed and dynamic SQL-free actors also install and execute under the corrected
post-link pipeline. Public production Candid, method exports, metrics reports,
accepted schema, persisted formats, query results, and update behavior are
unchanged.

## Cost Evidence

The matched local `icydb_query` sample executes 32 identical ordered queries:

| Artifact | Total instructions | Average |
| --- | ---: | ---: |
| Patch 2 accepted baseline | 21,406,368 | 668,949 |
| Patch 3 final | 19,861,600 | 620,675 |

The selected endpoint improves by 1,544,768 instructions, or 7.22%, exceeding
the frozen 3% Patch 3 gate. Exact-schema re-entry moves from 7,440,521 to
7,440,723 (+0.0027%), and the ordered non-selected sentinel moves from
1,091,513 to 1,094,622 (+0.2848%); both remain within the 1% ceiling.

Against the clean opening baseline, the current eight-subject production Wasm
matrix remains 11.84% to 13.44% smaller. Relative to the Patch 2 v1 matrix, the
largest current raw increase is 1,321 bytes (`sql_perf`), below the frozen
8,192-byte Patch 3 allowance.
