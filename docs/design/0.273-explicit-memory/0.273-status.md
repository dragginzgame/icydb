## Ownership and state delta

Memory 0.36 removes registration macros and the ambient global catalogue; import
substitution alone cannot supply the complete pre-bootstrap requirements. The
simplest replacement is one generated request factory and one checked snapshot
inside the existing cached bootstrap result. Host composition combines request
vectors before sealing; warm adoption never invokes the pool provider or another
bootstrap. No new configuration mode, persisted state, lifecycle or fallback.
Store openers only open committed keys. Memory remains the persistence owner.

Stable keys, ledger bytes and recovery contracts remain unchanged. Although the
standing pre-1.0 policy permits recreation, this source cut does not itself need
stored-data deletion or a migration decoder. Matching application Wasm size,
restore and composed-host evidence must be distinguished from Memory-only probes.
Full gates and native macOS remain separately selected; focused checks qualify
this implementation. No performance claim without raw Wasm or IC measurements.
