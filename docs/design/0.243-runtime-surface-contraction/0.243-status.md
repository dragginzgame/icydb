pinned PocketIC 15.0.0. Snapshot restore isolated every cold observation and
every warm-up/true-warm pair. The temporary ignored audit probe was removed
after capture.

Directly attributed base-row plus reducer work is 97,181,288 instructions for
cold SUM and 97,159,070 for cold AVG. A conservative later gate of 2,000,000
cold instructions would still require absolute savings above 96.0M. The
candidate has no recovery-saving claim and must retain the existing prepared
fallback for every excluded or unavailable shape.

The viable structure is one planner-admitted target in the existing singular
fingerprint-bound exact-or-prepared command slot, followed by one index-owned
generation-matched metadata fold returning shared `(count, sum)` evidence.
There is no aggregate cache, persisted sum, runtime index reselection or
second authority.

Verdict:
`SEPARATE DESIGN JUSTIFIED — NO 0.243 RUNTIME BUILD`.
