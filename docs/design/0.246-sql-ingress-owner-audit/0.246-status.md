## Current Verdict

`NO-BUILD — SQL PREMIUM IS CURRENTLY JUSTIFIED`

The typed actor is a planner-free direct lookup, so its complete subtraction
from SQL is not removable SQL overhead. A closer dynamic structural-query
control narrows the directional difference to 315,217 bytes but has four extra
measurement exports and is not an exact matched actor. Named attribution and
source tracing found no removable broad owner that clears the frozen 32 KiB
final-raw gate.

The audit did find repeated full parsing at SQL entity routing and cache-miss
compilation boundaries. That is a future broad performance and measurement
correctness opportunity, not a qualifying 0.246 footprint build: the required
parser remains and the removable wrapper/control ceiling is below the gate.
