## Minor-Line Plan

The line has two meaningful landings:

1. **Public contract and published-baseline freeze.** Record the exact wire
   envelopes and bounds in authority, add the named pre-change verbose golden,
   and freeze published instruction, Candid-response, raw Wasm, gzip, and
   complexity evidence without changing runtime behavior.
2. **Coherent SQL introspection hard cut.** Land compact/verbose `DESCRIBE`,
   compact/verbose `SHOW COLUMNS`, and `SHOW RELATIONS FROM|IN` end to end,
   including parser, accepted projection, compiled mode, public DTO/Candid,
   renderer, diagnostics, fixtures, active docs, and closeout evidence.

The usual six-to-eight-patch planning range is a target rather than a quota.
Splitting parser, result, execution, Candid, renderer, tests, or docs into
separate landings would create partial public states explicitly forbidden by
the design. No additional introspection feature has demonstrated need in this
minor, so the tracker does not invent one.

## Patch 2 — Coherent SQL Introspection Hard Cut

Status: Pending Patch 1 acceptance

This is the single implementation landing defined by the design. It must leave
no old default-full `DESCRIBE` variant, compatibility decoder, alias, fallback,
or partially migrated public surface. Its completion evidence must include the
full focused native/facade/CLI/Candid matrix, accepted-maximum bounds, exact
compact/verbose cost and response deltas, raw Wasm first, gzip context, and the
complexity/state-space readout.
