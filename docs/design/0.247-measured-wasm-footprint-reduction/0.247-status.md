## Patch 2 Compact-sort Result

The accepted implementation keeps the typed slice and comparator in a private
adapter exposing only indexed comparison and swap operations. One concrete
driver allocates and sorts source positions, builds a source-to-destination
map, and applies the permutation. The heap traversal and permutation walk no
longer instantiate for each element/comparator pair. The implementation is
safe Rust, preserves the unstable-sort contract and total comparator order,
and uses two `Vec<usize>` buffers instead of the predecessor's allocation-free
typed heapsort.

The candidate decision uses an exact `v0.246.1` A/B because that release is the
0.247 predecessor and contains production changes after the frozen 0.246.0
attribution artifact. Toko Miner's current dirty source was copied to a
disposable mirror, then the mirror alone alternated between the tagged
predecessor and candidate dependency paths. The original Toko Miner worktree
was not changed.

## Patch 8 Direct Binaryen 132 Bootstrap Result

IcyDB no longer compiles or invokes the Canic CLI to install its qualified
post-link optimizer. The canonical setup script downloads the official
Binaryen 132 Linux archive directly, verifies its pinned archive SHA-256, then
verifies and installs the 18,506,720-byte `wasm-opt` executable with SHA-256
`1014958e6f20d412f1542320b43970214b0fb1ed780595e8f7c0d8761ed53725`.
The post-link identity hard-cuts to the current version-1 Binaryen 132 form;
the optimizer flags and runtime state space are unchanged.

`make update-dev` owns local convergence to that pin and asks GitHub's official
latest-release redirect whether the repository is current. A lookup failure or
different latest tag produces an explicit warning without creating a second
installation route or making CI depend on a moving upstream release.

Like-for-like passes over three existing compiler-emitted canisters reduce
final raw Wasm by 5,333–6,468 bytes. Deterministic gzip grows by 433–559 bytes,
which is secondary under the line's raw-Wasm authority; extracted Candid is
byte-identical for every pair.
