## Patch 2 Compact-sort Result

The accepted implementation keeps the typed slice and comparator in a private
adapter exposing only indexed comparison and swap operations. One concrete
driver allocates and sorts source positions, builds a source-to-destination
map, and applies the permutation. The heap traversal and permutation walk no
longer instantiate for each element/comparator pair. The implementation is
safe Rust, preserves the unstable-sort contract and total comparator order,
and uses two `Vec<usize>` buffers instead of the predecessor's allocation-free
typed heapsort.

The candidate decision uses an exact `v0.246.1` A/B because that release is the
0.247 predecessor and contains production changes after the frozen 0.246.0
attribution artifact. Toko Miner's current dirty source was copied to a
disposable mirror, then the mirror alone alternated between the tagged
predecessor and candidate dependency paths. The original Toko Miner worktree
was not changed.

## Patch 3 Retained-scan Result

All six structural scan strategies now select a stack-borrowed owned row
callback before entering one concrete scan driver. Slot-only strategies also
provide one borrowed-row callback to the same driver, so primary-map traversal
continues to decode directly from the visitor-owned `RawRow`; non-primary and
full-row strategies retain their prior owned storage. The callback erasure is
private, allocates nothing and introduces no per-row strategy match.

The accepted Patch 2 Toko Miner artifact is the immediate A/B predecessor. The
same disposable mirror, Toko Miner source, Rust toolchain and Canic `0.109.17`
release build were reused. Replaying the predecessor through the recorded
Binaryen invocation reproduced its final artifact byte-for-byte.

## Complexity Delta

Patch 1 changes four documentation/changelog files and zero production files.
It adds no Rust lines, types, allocations, mutable owners, caches, modes,
features, persisted states or compatibility paths. Implementation complexity is
neutral; the acceptance and evidence boundary is more explicit.

Patch 2 changes one production file by +101/-14 Rust lines. It replaces
per-type heap traversal with one private trait adapter, one concrete driver and
two temporary index buffers.
Local source complexity increases slightly; generated Wasm execution shape is
simpler. It adds no public API, behavior axis, unsafe code, persisted state,
format, feature, compatibility path or alternate engine.

Patch 3 changes one production file by +113/-215 Rust lines. It deletes nine
lane-specific scan helpers and three generic closure boundaries in favour of
two private callback aliases and one concrete driver. Source and generated
execution shape both become simpler. It adds no allocation, public API,
behavior axis, unsafe code, persisted state, format, feature, compatibility
path or alternate engine.
