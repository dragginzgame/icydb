# IC Wire endpoint trial

## Accepted scope

The maintainer selected one complete endpoint and matching Rust caller as the
adoption trial, then requested a comparison with no Candid dependency. These
are two independently reviewable landing slices in the current pending line.

| Slice | Outcome | Status |
| --- | --- | --- |
| 1 | Switch the existing dynamic row-count query and its caller to IC Wire; qualify contract bytes, rejection, installed behavior and artifact exports | Locally complete |
| 2 | Compare codec-only Candid and Wire actors with the same row-count workload and raw IC adapter; prove the Wire actor has no Candid dependency | Locally complete |

The second slice needs a codec-only control: IcyDB uses Candid internally for
reply sizing, and CDK also depends on it. Merely deleting endpoints cannot prove
a dependency-free actor. Two small evidence actors share one finite key/count
workload and one synchronous raw IC adapter. Each has one encoding and no codec
selector. Their request/response types are `u64`/`u32`; the adapter admits at most
64 bytes before copying. Shared local errors distinguish request admission from
encoding failure. One Wire Method owns its identity and bounds. The existing
variant-build and optimizer owners build both artifacts; the comparison does not
replace the database runtime or extend the maintained Candid actor fleet.

`query_one_entity_dynamic_rows` retains its name, empty request, `u32` result,
query semantics and existing failure sentinel. The test helper package owns one
shared IC Wire `Method`, including its contract identity and resource limits.
The canister checks argument size before copying, decodes before executing the
query, and returns the encoded Wire response through the CDK raw reply API.
The matching integration caller uses raw PocketIC transport and the same Method.

## Contract decision

The demonstrated need is an installed IcyDB query and caller using IC Wire in
place of Candid. The simplest alternative, changing only derives, would leave
Candid ingress and replies in place. One finite unit-to-integer Method avoids a
recursive DTO redesign. Its canonical owner is the shared test helper module;
the existing artifact inspector owns declaration/export agreement.

The state-space delta is one current method identity and byte contract replacing
the endpoint's Candid ABI. There is no codec selector or fallback reader. Candid
service discovery must omit this method, while raw-Wasm inspection must verify
its query export independently. Old callers and retained encoded calls must be
replaced together; the old request format is rejected.

The artifact records the shared Method's eight-byte identity in an `icydb:wire`
custom section. This replaces Candid discovery for the selected export. Inferring
the protocol from a method name alone would admit an undeclared export. The
existing artifact inspector admits this one identity and checks exact export
coverage; unknown identities, duplicate declarations and Candid overlap fail.

IC Wire is unpublished. Pin its committed runtime revision as a Git dependency
of unpublished test packages only; do not depend on a sibling working tree.
No product library dependency or package version changes are required.

## Qualification

Fourteen focused tests pass: two contract tests, one native handler-admission
test, ten artifact-owner tests and one installed endpoint test. They qualify
exact request/reply vectors and maximum-width integers; wrong identity/direction,
truncation, trailing and noncanonical bytes; admission before handler execution;
and current artifact discovery. The installed test checks the actual query
export, absence from Candid, 15 invalid-request rejections, valid replies after
each rejection, and a same-contract upgrade followed by another valid reply.

Native lint passes for the contract, actor, artifact owner and matching client;
Wasm lint passes for the actor. Dependency pin/inheritance, formatting and
whitespace checks pass. The pinned IC Wire revision is
`66e1f0c5bdced1579573999c8928a697f6135425`. No existing dependency package
versions or IcyDB package versions changed during this trial.

The shared request is `IWICYDBDR1` followed by direction byte zero (11 bytes).
Replies use direction byte one followed by canonical Postcard `u32` (12–16
bytes). The raw PocketIC transport allocates its reply before Wire decode; this
trial does not establish a client transport allocation limit.

| Artifact | Candid endpoint before | Wire endpoint after | Delta |
| --- | ---: | ---: | ---: |
| Raw final deployable Wasm | 2,898,575 | 2,900,105 | +1,530 (+0.053%) |
| Compiler-emitted Wasm | 3,288,706 | 3,290,607 | +1,901 |
| Deterministic gzip, secondary | 1,176,884 | 1,177,267 | +383 |

The baseline is the bounded-integer working tree before this trial, captured in
`/tmp/icydb-wire-trial-start/`; its Rust/manifests/toolchain match the measured
baseline source. Both builds use production `wasm-release`, Candid export
enabled for the other methods, the same existing dependency package versions,
Rust 1.99.0 and the pinned Binaryen 133 pipeline. Exact features and raw method
exports match. The directional dynamic-versus-typed comparison explicitly
records its different transports. The growth measures coexistence of codecs in
this actor, not removal of all Candid consumers.

Reports, raw artifacts, SHA-256 checks, source snapshots and logs are retained
under `target/ic-wire-trial/`. Testkit prepared its locked tool and owned the
temporary local PocketIC server through startup and shutdown. No deployment,
staging, commit, push or release operation ran.

The broader owned endpoint migration is outside this trial. IC cycles and
instruction changes remain unmeasured. Full workspace/release gates and macOS
qualification were not selected.

## Codec-only comparison qualification

The matched control has no IcyDB or CDK dependency in either actor. The Wire
actor's complete normal/build Wasm dependency graph also excludes Candid,
`candid_derive`, `num-bigint` and ledger libraries. The Candid control has no Wire
dependency. Both actors live in the root workspace, inherit its version and
lockfile, expose only the same `count_rows` query, and use the same raw IC adapter
and finite row fixture. No existing dependency or IcyDB package version changed.

| Metric | Candid actor | Wire actor | Saved |
| --- | ---: | ---: | ---: |
| Raw deployable Wasm | 240,951 bytes | 19,857 bytes | 221,094 bytes (91.76%) |
| Raw code-section payload | 205,215 bytes | 17,806 bytes | 187,409 bytes |

The existing fixture-variant build owner and canonical Binaryen 133 optimizer
produce both artifacts under `wasm-release` with no enabled package features.
Compiler settings are `opt-level=z`, fat LTO, one codegen unit and abort panics;
Rust is 1.99.0. This variant owner adds no path-remapping flags to either build.
Neither actor exports Candid service metadata, so discovery export cost does not
confound the codec comparison. Both codecs reject noncanonical representations;
Candid also uses bounded decoding/type/header quotas within the same 64-byte
outer frame allowance.

The two native codec tests and installed comparison pass. Installed calls cover
four key/count cases on both actors, 18 Candid and 15 Wire rejections, then valid
queries after those rejections. Exact request/reply vectors are retained. Small
keys use 15 Candid request bytes versus 12 Wire bytes; maximum `u64` uses 15
versus 21. These row-count replies use 11 Candid bytes versus 12 Wire bytes.
The binary saving does not imply smaller bytes for every individual payload.

Native/Wasm lint, locked metadata, dependency pin/inheritance, formatting and
whitespace checks pass. Testkit owned the temporary local PocketIC server and
both installed instances; no live deployment ran. Evidence is under
`target/codec-only-comparison/`, including both raw artifacts, vectors, dependency
graphs, compiler/optimizer provenance and logs. This is an isolated codec result;
the database still depends on Candid internally. IC cycles and instructions,
macOS and full workspace/release gates remain unqualified.
