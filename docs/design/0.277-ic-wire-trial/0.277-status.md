## Private dependency CI access

All Cargo CI families use the same fetch action before compilation, including
Linux/MSRV and both native macOS jobs. It requests a short-lived Contents: read
token for only `ic-wire` and exposes it only to the locked fetch step. The helper
checks protocol, host and exact repository path; credentials are not persisted
in caches or Git configuration. The built-in repository token cannot fetch the
separate private source, so one explicit private-fetch route is required. The
exact dependency source and pin are retained, with no source fallback or codec
mode. Workflow lint and isolated fake-token scope controls pass. No App secrets
were provisioned or inspected. #370 remains open for that owner step and clean
hosted runs; a warm local cache does not qualify it.

## Native browser contract decision

The opaque native adapter cannot supply IC Wire's finite derive metadata. The
browser caller needs the maintained endpoint roster, recursive values and exact
native bytes. Host-only Serde reflection describes these concrete contracts;
valid samples cover custom scalar decoding, and incomplete metadata fails
qualification. A separate bounded DTO hierarchy would duplicate database payloads
and cannot express recursive values with the pinned generator. The build tooling
owns native metadata generation and its browser codec. Browser byte, value-count
and nesting limits are explicit local admission controls, not inferred static
Rust or JavaScript heap bounds. No endpoint, format selector, persisted state,
compatibility reader or production dependency is added. Only host development
dependencies and one browser client surface are introduced.

## Accepted library and endpoint cut

The maintainer extended the scope to all IcyDB-owned libraries and generated
endpoints. Upstream CDK and host/test dependencies may retain Candid
internally. IcyDB must not import or re-export it, derive its traits, or use it
for reply sizing. Ordinary host-owned endpoints are outside this cut.

The database's native types remain encoding-independent. The endpoint boundary
owns one Postcard projection inside the IC Wire envelope, with byte, allocation,
node and depth admission for recursive payloads. A manual Wire implementation
must enforce those declared bounds; assigning a large static shape to an
unbounded Serde decoder is insufficient. The simpler finite-derive-only
alternative cannot represent the maintained recursive public values. Projection
metadata is opaque until a schema generator can describe those recursive
contracts; native callers share the maintained method identities and codec.

This replaces one endpoint encoding with one encoding. It adds no selector,
fallback, database format, persisted mode or recovery lane. Generated endpoint
authorization and request execution semantics remain with their existing owners.

The second slice needed a codec-only control: IcyDB then used Candid internally
for reply sizing, and CDK also depends on it. Merely deleting endpoints cannot prove
a dependency-free actor. Two small evidence actors share one finite key/count
workload and one synchronous raw IC adapter. Each has one encoding and no codec
selector. Their request/response types are `u64`/`u32`; the adapter admits at most
64 bytes before copying. Shared local errors distinguish request admission from
encoding failure. One Wire Method owns its identity and bounds. The existing
variant-build and optimizer owners build both artifacts; the comparison does not
replace the database runtime or extend the maintained Candid actor fleet.

`query_one_entity_dynamic_rows` retains its name, empty request, `u32` result,
query semantics and existing failure sentinel. The test helper package owns one
shared IC Wire `Method`, including its contract identity and resource limits.
The canister checks argument size before copying, decodes before executing the
query, and returns the encoded Wire response through the CDK raw reply API.
The matching integration caller uses raw PocketIC transport and the same Method.

## Original endpoint trial contract

The demonstrated need is an installed IcyDB query and caller using IC Wire in
place of Candid. The simplest alternative, changing only derives, would leave
Candid ingress and replies in place. One finite unit-to-integer Method avoids a
recursive DTO redesign. Its canonical owner is the shared test helper module;
the existing artifact inspector owns declaration/export agreement.

The state-space delta is one current method identity and byte contract replacing
the endpoint's Candid ABI. There is no codec selector or fallback reader. Candid
service discovery must omit this method, while raw-Wasm inspection must verify
its query export independently. Old callers and retained encoded calls must be
replaced together; the old request format is rejected.

The artifact records the shared Method's eight-byte identity in an `icydb:wire`
custom section. This replaces Candid discovery for the selected export. Inferring
the protocol from a method name alone would admit an undeclared export. The
existing artifact inspector admits this one identity and checks exact export
coverage; unknown identities, duplicate declarations and Candid overlap fail.

The original trial pinned IC Wire’s committed runtime revision in unpublished
test packages. The accepted third slice extends that same pinned dependency to
IcyDB libraries. No sibling working tree or package version changes are used.

## CDK dependency cut decision

use the existing `ic0` authority; the database admits one host-supplied secure
