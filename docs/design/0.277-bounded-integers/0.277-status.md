# Bounded integer hard cut

## Accepted scope

One landing slice removes the arbitrary-precision signed and unsigned scalar
types throughout schema authoring, public and runtime values, SQL, codecs,
indexes, cursors, resource accounting and direct consumers. Fixed-width integer
types remain supported. Remove direct arbitrary-precision dependencies where
their maintained consumers permit it.

The maintainer explicitly requests a hard cut with consecutive discriminator
sequences compacted. The current schema and value owners retain one contract;
there is no compatibility reader, alias or additional execution mode.

## Retained installations

Compacted tags change the persisted contract beyond fields using the removed
types. Preserve the old binary and backups for required recovery or export.
Explicitly retire or recreate affected databases before adopting this contract;
do not open retained old images under the new tag assignments. Outstanding
cursors and serialized proposals must be discarded and recreated. This source
change does not reset any installation.

## Qualification — locally complete

The accepted slice is complete. Core has no direct `num-bigint` dependency;
schema retains it for fixed-width `U256` Candid serialization and its independent
Decimal test oracle. Candid and ledger dependencies also retain it transitively.
The maintained tag families are consecutive, and schema/value round trips,
golden bytes, hashes and authenticated cursor fixtures use their current tags.

930 focused tests pass across core, schema, model, derive macros, the derive
policy harness, native typed decoding and the U256 workload contract. The derive
policy harness also qualifies nine compile-pass/fail fixtures. Coverage includes
fixed integer widths, numeric/query behavior, row and catalog codecs, ordered
indexes, cursors, resource accounting, mutation intents and malformed input.

Strict native lint passes for the affected libraries, test targets, fixture
packages and actors; the facade also passes without default features. Strict
Wasm lint passes for the facade and both affected audit actors with all features.
The selected schema/model boundary invariant, shell lint, formatting and diff
whitespace checks pass. Logs are retained under `/tmp/icydb-hardcut-*.log`.

Incoming dependency updates are preserved; the lockfile changes only the core
dependency edge relative to its incoming state. Package versions, staging,
commits and release execution remain maintainer-owned. No IC/PocketIC network
lifecycle operation ran. Full workspace/release gates and macOS qualification
were not selected. IC cycles and instruction deltas are unmeasured.

Matched production Wasm builds reduce raw final deployable bytes by 30,732
(1.54%) for the empty subject, 30,932 (1.55%) for one typed-query entity, and
51,525 (1.53%) for one SQL-query entity. All six artifact reports pass and use
the same dependency versions, compiler, features and pinned optimizer. See the
[current audit notes](../../changelog/0.277.md#-audit) for exact byte counts and
controls; retained local evidence is under `target/wasm-bigint-comparison/`.
