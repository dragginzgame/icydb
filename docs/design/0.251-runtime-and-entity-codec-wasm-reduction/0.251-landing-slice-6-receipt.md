# IcyDB 0.251 Landing Slice 6 Closeout Receipt

## Verdict

IcyDB 0.251 is complete and ready for release validation. The line retains one
production change: generated insert, patch and replace construction now shares
the concrete binding-owned ordinal `BoundWriteEncoder` introduced in Landing
Slice 4. The compact metrics state, ordinal row decoder and compact descriptor
candidates were measured, rejected and removed.

The retained implementation improves final raw and code Wasm, allocation shape
and downstream Toko size without changing Candid, exports, accepted-schema
authority or runtime formats. The stronger 2 KiB full-adapter objective is not
achieved: the final maintained reachable slope is 40,053 raw bytes across nine
added entities, or 4,451 rounded bytes per entity. The existing 8 KiB reachable
gate remains unchanged and passes. The separate schema-only control remains at
145 raw bytes per added entity and continues to pass its 2 KiB gate.

## Contracts And Complexity

Accepted snapshots remain sole runtime schema authority. The line adds no
runtime fallback from generated models, registry, callback, trait object,
function-pointer table, execution route, persisted state, cursor encoding,
catalog encoding or public runtime `Value`. Candid and normalized exports are
exact in the maintained and downstream controls, and all affected pre-1.0
representations remain their sole current version-`1` shape.

The retained production and focused-test change touches seven files at
`+159/-167` lines. It adds one hidden concrete generated-code boundary while
deleting three generic name-driven write constructors and a name-binding
helper. Generated writes allocate one pre-sized ordinal/cell vector instead of
three vectors plus one owned source-name string per field. Execution flow is
narrower and runtime state space remains neutral.

The measurement-only portion adds one controlled extended-metrics actor and
extends the existing report identity/feature metadata. It does not affect
production runtime state. Rejected experimental code is absent.
