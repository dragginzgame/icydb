## Contract

Use canonical `StableKey` parsing and nonzero bucket sizes. Existing store
constructors select `create` only for zero-page memory and `load` for retained
memory. Never reset or initialize over rejected retained bytes. Valid retained
ledger, checkpoint and collection bytes are unchanged by the supplier release.
No new mode, cache, persisted state, codec, recovery route or compatibility
fallback is introduced. IcyDB's string descriptors remain domain metadata;
upstream runtime calls receive checked keys.
