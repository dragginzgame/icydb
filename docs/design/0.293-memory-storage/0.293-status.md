3. Carry forward #76 request-budgeted accepted predicate projection and tests.
4. Carry forward #94 ordinary source-lineage publication/recovery and tests;

   assigned entities. Retain existing digest deferral and same-version admission.
5. Close #344's remaining shortcut proposal with current admission evidence and
   documentation; preserve the delivered shared metadata improvement.

6. #78 schema report reply admission: reuse Wire's exact envelope sizing and
   existing IC reply caps through the same owner as SQL. Add one schema-specific
   reply-byte diagnostic. A transport trap cannot provide the typed caller
   result; paging is unnecessary for this bounded correction. State-space delta:
   one public error reason, no mode, configuration, persisted state or endpoint.

7. Compatible #81 fairness correction after 0.293.0 delivery: rotate the
   existing single optional cardinality page across journaled stores. Repeated
   source drift at the first store must not starve later stores. The startup
   driver owns a volatile last-served path per actual registry instance;
   aliases of one TLS registry share that position. Remove it when quiescent.
   Advancing every store per call would violate the current one-page bound.
   State-space delta: one disposable scheduling position per active static
   registry, no persisted state, timer policy, public option or execution route.
   Watermark/source restart semantics remain unchanged and #81 stays partial.

The carried slices were already implemented and focused-qualified before this
adoption. The follow-on #94 deferred version controls first reproduced a pending

## Contract

Use canonical `StableKey` parsing and nonzero bucket sizes. Existing store
constructors select `create` only for zero-page memory and `load` for retained
memory. Never reset or initialize over rejected retained bytes. Valid retained
ledger, checkpoint and collection bytes are unchanged by the supplier release.
No new mode, cache, persisted state, codec, recovery route or compatibility
fallback is introduced. IcyDB's string descriptors remain domain metadata;
upstream runtime calls receive checked keys.
