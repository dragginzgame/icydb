# IcyDB 0.250 Landing Slice 2 Receipt

Date: 2026-08-31

Disposition: rejected production candidate; the concrete prepared-page driver
was removed after missing the frozen code-section gate.

## Candidate

The transient candidate moved typed query state, public/trusted page execution,
continuation validation, binding freshness validation and prepared-row creation
behind one `CanisterKind`-generic driver. Only the final `E::decode_row` loop
remained entity-generic. Attributed reads used the same preparation owner;
exhaustive reads retained their existing proof and error owners. The candidate
used a concrete lane enum and direct calls, with no callback, trait object,
function pointer or compatibility path.

A focused native retry-before-caller-state-change contract and the generated
adapter compile contract passed. Targeted package checks compiled the
public/trusted, attribution, exhaustive and stale-error mappings. Existing
live-page tests remain the maintained owners for multi-page commit,
retry-before-commit and repeated-token rejection.

## Maintained Pair Context

The homogeneous maintained one-to-ten reachable-entity pair was nearly flat:
the candidate changed the one-entity final raw/code values by `-272/-273`
bytes and the ten-entity values by `-133/-131` bytes. Its reachable-entity raw
slope therefore worsened by 139 bytes, from 83,540 to 83,679 bytes across nine
added entities, while `call_indirect` remained flat. Binaryen already merged
the identical simple-entity page bodies, so this pair was structural context,
not the heterogeneous downstream acceptance subject.

## Gate Decision

The frozen minimum was 32,768 final code-section bytes. The candidate saved
27,201 bytes and missed by 5,567 bytes. The design requires a miss to be
recorded and removed rather than broadened into blanket type erasure. The
instruction comparison was consequently not run: size failure was already a
terminal rejection, and no production candidate remained to qualify.

All driver code, direct adopters and candidate-only tests were removed. No
production API, runtime flow, Candid surface, persisted bytes or cursor format
from this experiment remains in the 0.250 worktree. Production complexity is
therefore neutral; only this audit receipt was added. The rejected IcyDB source
is intentionally not a retained rebuild fixture, while the exact final
artifacts and the downstream adoption delta remain identified above. The
line's prepared-page exit criterion remains unmet and must be reported as such
at closeout unless a later explicitly authorized design change supplies new
evidence.
