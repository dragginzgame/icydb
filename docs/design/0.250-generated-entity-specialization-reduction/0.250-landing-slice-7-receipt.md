Date: 2026-08-31

Disposition: retained; 0.250 closeout passes and is ready for user-owned

## Authorized Correction

Landing Slice 6 correctly applied the then-current 2 KiB ceiling and reported
an incomplete size objective at 4,466 bytes per reachable entity. The user
subsequently identified that the 2 KiB value came from the old comparison that
measured approximately 154 bytes of dead-strippable schema growth, not the new
subject that deliberately makes page, exact-key and write adapters reachable.
The user explicitly authorized an 8 KiB reachable-adapter ceiling.

The correction does not reinterpret the artifacts or remove the Slice 6
finding. It gives the two already-distinct maintained comparisons separate
budgets that match what each one measures:

- `schema_entity_scale` remains capped at 2 KiB per added declared schema; and
- `reachable_entity_scale` is capped at 8 KiB per added entity with the full
  maintained adapter mix reachable.

This is the smallest correction. It adds no caller-configurable threshold,
report mode, comparison registry or production behavior. The existing Wasm
measurement module remains the sole budget owner.

## Fail-Closed Measurement Shape

The generic ceiling constant and validator are hard-cut into explicit schema
and reachable constants and validators. The internal measurement command's
ambiguous `--report-only` flag is hard-cut to `--reachable`. Both comparison
paths now propagate budget failure; the reachable comparison no longer needs a
report-only exception.

The measurement profile remains `icydb-wasm-footprint/0.250/v1` and its format
version remains `1`. The representation did not gain a new version or
compatibility path.
