# 0.255 slice 1 — Owned admitted-value handoff

Date: 2026-09-06. Scope: the two redundant owned-value copies only.

## Implementation and authority

`AdmittedOwnedValue::into_value` moves out plain canonical data, discarding the
proof's authority handle. Input normalization and persisted canonical row
decoding call it only after their existing normalization/admission succeeds.
Validation, budgets, errors and accepted catalog ownership are unchanged.
Schema temporal-payload rendering genuinely borrows the proof's value, so its
getter remains. The initial preflight missed this third consumer; no rendering
rewrite or compatibility fallback was needed.

The new owner tests cover nested allocation identity, empty/NULL round trips,
wrong input kinds, scalar limits, truncated persisted data and wrong persisted
kinds. Invalid bytes are encoded under a matching permissive accepted contract
and rejected against the restrictive destination, without bypassing production
encoder admission or widening internal exports for tests.

Each operation returns the same successful contract outcome on both fresh
installations; instruction counts repeat exactly. All six are below the
predeclared +1% ceiling. This is modest end-to-end savings in one maintained
actor, not evidence that every application operation becomes faster.

Final validation passes: 79 focused core tests across admission, recursive
codecs, persisted decoding, predicate normalization, schema rendering and source
binding; the matched production integration probe; all-feature core test-target
clippy with warnings denied; SQL-disabled core library check; formatting and
whitespace checks. No full repository suite was run; release validation remains
user-owned. There are no outstanding failures.

Initial test fixture imports were corrected to use existing internal exports.
Compilation exposed the legitimate schema-rendering borrower described above;
its getter was retained. One candidate Wasm attempt was rejected by the build
cache because temporary test cleanup changed its source fingerprint during the
build; final measurements use successful fixed-source rebuilds. The sandbox's
localhost bind restriction required approved execution for PocketIC. Both
isolated servers were stopped by the wrapper; no existing local network was
restarted. Temporary native allocator and integration probes were removed from
the worktree, with copies retained in the local evidence directory.

## Complexity and next boundary

Three production files change, +11 net lines including test-module wiring and
documentation; one new test file adds 213 lines. Five release/design/receipt
documents accompany the runtime slice. Runtime ownership is simpler: two deep
copies become moves through one consuming accessor. No new behavior axis,
execution route, cache, persisted state or format is introduced.

Slice 1 is ready for handoff. Slice 2 (map collection emptiness) remains planned
and untouched; general collection streaming is still not promoted.
