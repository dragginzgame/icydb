## Outcome

Typed Query page terminals decode complete generated entity rows. The public
selection method previously admitted partial output that the generated decoder
could not decode once a row was returned. Remove that unused method as a
pre-1.0 Rust API hard cut. Selected-field reads continue through DynamicQuery
and the existing structural page terminals. Grouped output retains its existing
key/aggregate contract.

No new result type, projection adapter, nullable-field mode, compatibility alias,
runtime state or execution route is introduced. Accepted-schema authority,
public read admission, cursor handling and decoding remain unchanged.
The guides and active release notes explicitly explain the two maintained
surfaces and the migration for selected-field callers.
