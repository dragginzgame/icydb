# 0.255 slice 3 — Borrowed constraint operands

Date: 2026-09-06. Explicitly authorized extension; active release 0.255.0.

## Outcome and authority

`StructuralSlotReader::decode_selected_slot_values` lends its cached values
instead of deep-copying them. All required slots are still decoded into their
full-layout positions before evaluation; unselected positions remain `None`.
Normal write admission, constraint activation, migration validation and migration
execution keep their current reader lifetime and call sequence. Migration still
uses the reader afterward for index/relation validation.

One `Option<Cow<Value>>` slot shape serves the existing evaluator. Selected-row
callers borrow; integrity inspection retains its genuinely owned snapshot.
The shared evaluator only reads either form. It never calls `to_mut` or
`into_owned`, so this introduces no lazy ownership conversion, alternate
evaluation flow or additional integrity adaptation allocation. The measured
native layout remains 64 bytes for each of `Value`, `Option<Value>`,
`Cow<Value>` and `Option<Cow<Value>>`.

Fingerprint checks, complete required-slot preparation, targeted traversal
budgets, SQL three-valued CHECK semantics, missing/NULL distinctions and stable
constraint-ID/occurrence ordering remain at their current owners. No public
surface, stored format, endpoint, runtime state or package version changes.
