No general streaming layer, collection-view API, cache or new runtime mode is
planned. Slice 14 is ready with an explicitly accepted function-count exception,
not a literal all-gates pass. The user accepted it because ownership is simpler
and attribution found cleanup functions rather than another execution flow.
This exception does not widen future slice gates. Mixed-expression projection
remains a separate follow-up. Slice 13 changes remain unpushed in the same active
0.255.2 worktree.

The user explicitly extended 0.255 after the first two slices and again after
slices 3 and 4, then authorized slice 6 after the slice 5 handoff and read-only
audit, then authorized slices 7 and 8 to remove duplicated flow ownership and
nested-root copies, then slice 9 for retained-row output. Slices 1–12 are now
published. The user authorized slice 13 after the read-only closeout identified
last-use heap copies in both mutation-result loops, then authorized slice 14 for
owned batch-input lowering and matched cost measurements. This is not a declaration
that 0.255 is finished. Further evidence-backed improvements require explicit
authorization. No new minor line or package version change is authorized.
