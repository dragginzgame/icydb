The enrollment correction was prepared before this line was started but was
not published. Its code and guide changes are preserved; its release note now
belongs to this line's initial release. The previous draft next-patch note in
0.255 is withdrawn, not published history. No Cargo versions are changed.

Application evidence supports existing exact-key and structural-projection APIs.
The main concrete simplifications are downstream primary-key lookup usage and a
duplicate batch-result count check. Toko's whole-entity write adapter also owns
application preparation/revision semantics; Toko Miner does not demonstrate the
same generated-input single-write need. No new convenience API is justified yet.
Conditional post-publication failure windows require application qualification,
not a claim of engine rollback. Neither external repository was changed. Their
existing dirty work remains user-owned. Slice 3 used only a temporary PocketIC
server, stopped after measurement; existing networks were untouched.

The initial two slices changed nine files, with no production Rust changes.
Slice 3 adds the IcyDB-owned implementation the user selected instead of changing
the applications: seven Rust files, about −2 production/+261 test lines, plus
six accompanying documentation files. No execution route or configuration is
added. The instrumented typed actor shrinks by 4,698 final raw Wasm bytes and
16 functions. Cycle deltas span −0.4944% to +0.8614%; large nested reads rise
slightly despite substantially fewer decoder allocations. All predeclared final
gates pass. No selected test is ignored; full suites remain user-owned.

All four planned slices are complete. Slice 4 changes two Rust files (one
production line replaced, +94 test lines), preserving the existing execution
shape and all public APIs. Its request-cycle results range from −0.8225% to
+0.0000355%; its actor shape differs from slice 3, so their byte deltas must not
be summed. Its temporary measurement servers have also been stopped.
A generic continuation now starts another read-only 0.256 closeout audit,
not another implementation or a new minor line.
This tracker does not assert downstream compatibility/build readiness for the
applications' older dependency pins.
