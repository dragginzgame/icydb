## Patch 1 Decision

The clean 2,048-row aggregate `DISTINCT` plus `FILTER` control costs
109,234,618 instructions and performs 2,048 row gets. Clean focused scalar
`DISTINCT` controls cost 109,375,905 and 118,738,995 instructions and also
perform 2,048 row gets. Both receive fully retained source rows before their
separate semantic consumers run.

Patch 2 reuses the existing executor-owned borrowed primary-row visitor for
unpaged retained-slot scans and makes the existing expression-order helper sort
compact source positions. Aggregate folding and scalar `DISTINCT` tuple
identity, ordering, pagination and budget semantics remain separately owned.
Paginated, residual-retry, cursor, corruption and unsupported paths retain the
canonical predecessor flow.
