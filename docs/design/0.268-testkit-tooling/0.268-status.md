## Hard-cut boundary and qualification

The demonstrated need is retirement of Shared's duplicate PocketIC catalog and
installer after Testkit's published setup/check replacement passed all three
native owner hosts. Reusing the generic selected Cargo installer and Testkit's
CLI is simpler than another server installer or consumer receipt format.
State-space delta: replace the existing setup/server source, retaining one
current flow; no product API, schema, wire discriminator or storage change.

The common setup/check contract changes from six tools to five. Consumers must
explicitly prepare the locked Testkit CLI/server and reinstall the shared bundle;
validation never downloads. Retain prior bundles, receipts, failed candidates
and logs without converting or deleting them. Explicit external server overrides
retain Testkit's admission; ordinary local lanes use its checked server path.

Focused qualification covers canonical IC fixtures on Bash 5/3.2, actual Linux
setup/offline checks and product startup, wrapper failure/signal/log retention,
workflow policy, ShellCheck, snapshot and documentation links. Native IcyDB
macOS qualification and matching committed CI remain required under #327/#309.
Full workspace/release gates are user-owned and not authorized by this slice.
Raw Wasm, IC cycles and instruction deltas remain unmeasured.
