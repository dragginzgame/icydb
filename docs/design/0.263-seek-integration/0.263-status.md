## S1 qualification — 2026-10-01

The [baseline](s1-baseline.md) and [cost receipts](s1-baseline.csv) freeze seven
IC populations and 28 two/three-child directional query shapes, with genuine
payload-page continuations, repeated output/work and every token's exact suffix.
The existing actor/entity owners supply all fixtures; no entity or production
route was added. Four-row loader calls settle journal byte pressure without
changing engine bounds. Native coverage checks 160 signed/unsigned combinations.

Actual eligibility differs by frontend. Signed dynamic filters select primary
scans; SQL strict predicates select logical intersections. Unsigned native
filters qualify the bounded complete-prefix probe and ordinary resumed polling.
The signed IC actor cannot establish resumed admitted-intersection costs; this
is an explicit qualification limit, not a failed seek implementation.
Schema-bound signed predicate admission is a separate follow-up, outside S1.

S1 validation passed: 79 focused native tests and one manual PocketIC matrix,
Clippy recovery plus focused all-feature core/actor and integration gates,
layer authority, formatting and documentation checks. Raw baseline Wasm is
4,504,970 bytes; candidate size/cycle/instruction deltas remain unmeasured.
Runtime state-space is unchanged; fixture and test complexity increased.
S1 touches 13 files, approximately +940 net lines, including about 690 lines
of fixture/test Rust and its mechanical wiring; the remainder is evidence/docs.
Full suites, version bumps and publication remain user-owned. Two disposable
PocketIC servers were started and stopped for qualification; no ICP network was
changed. S2 follows below; S3 has not started.

## S2 polling retirement — 2026-10-01

The [decision and receipts](s2-decision.md) resolve the dormant subsystem by
retiring its protocol, adapter, variant, held state and repositioning machinery.
Bounded polling and authenticated cursor binding remain the maintained physical
contract; complete-prefix integrity and existing admission remain unchanged.
Useful suffix, bounds, duplicate, corruption and budget checks now use polling.
State-space shrinks; no independent behavior axis or public surface is added.

Validation passed: 143 focused native tests, matched baseline/candidate IC
controls plus an identical candidate repeat, core/integration Clippy, formatting,
authority, docs and diff checks. Raw Wasm shrinks 4,619 bytes to 4,500,351.
Six of eight SQL shapes are cost-identical; most dynamic shapes save 3,394
instructions/cycles. Two three-child shapes have mixed deltas, including up to
0.95% second-sample instruction and 0.21% charged-cycle increases. These are
recorded tradeoffs, not a general speedup. Resumed admitted-intersection IC costs
remain unqualified by the signed actor; mainnet costs remain unmeasured.

Three disposable PocketIC servers were started/stopped; no ICP network changed.
Full suites and publication remain user-owned. S3 is the next landing and has
not started; signed secondary lookup admission remains an independent follow-up.

Complexity: 13 files, approximately −560 net lines; the stream subsystem alone
shrinks by 835 lines. One internal variant and the dormant protocol disappear.
Existing physical/composite owners converge on polling; the existing IC runner
is reused. Implementation structure is simpler and no new debt axis is added.
