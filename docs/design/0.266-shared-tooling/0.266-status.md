The compatible 0.265 tooling closeout passed focused Linux qualification before
this line began. The maintainer selected 0.266 for the breaking command change.

## Scope and owner

[IcyDB #305](https://github.com/dragginzgame/icydb/issues/305) records adoption of
the committed shared tag helper. The demonstrated need is portable selection
and exact-identity deletion that preserves interruption evidence. The simplest
alternative is to replace the duplicated local shell implementation with the
reviewed Shared Tooling owner, rather than repair both implementations.

One landing slice covers the command replacement, explicit-cutoff documentation,
snapshot provenance, focused qualification, native CI wiring and release notes.
No additional runtime or database behavior is in scope.
