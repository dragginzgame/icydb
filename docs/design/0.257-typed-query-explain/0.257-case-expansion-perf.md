# CASE expansion ownership and construction accounting

Date: 2026-09-08. Active release: 0.257.1, expression-preparation slice 10.
This is incremental to the [CASE admission receipt](0.257-case-admission-perf.md),
not a comparison against published 0.257.0 or a typed-explain qualification.

## Ownership and accounting

Expansion consumes owned arms/results/ELSE, moving one condition occurrence and
copying the other. Declined expansion returns the original CASE, including its
arms vector and ELSE box. Successful canonical form and fixed admission limits
are unchanged. Exhaustion returns the existing typed error, never compact CASE
as an alternate success.

The existing bounded content walker supplies an eight-entry stack receipt;
there is no second recursive copy estimator. Each condition receipt counts its
nodes, payload units and nested values. Before that arm's clone, it charges a
conservative fresh-copy backing allowance, corresponding copy work and value
visits. It does not prepay copies of later arms. One unit covers the maximum of
Expr, Value, String and 64 bytes; variable payload uses started 64-byte units.
This includes initialized big-integer limb rounding, not hidden spare source
capacity. COALESCE, actual AND/OR/NOT backing and negative truth-wrapper
replacement charge before their new allocations. Boolean shortcuts move values.
The [preflight](0.257-preparation-work-preflight.md) records the full proof and
remaining preparation gaps.

## Matched measurement

The unchanged CASE probe and existing SQL-perf actor use WasmRelease/LocalTest,
SQL and Candid enabled. The baseline is the immediately preceding dirty
candidate; only the four CASE Rust files changed for this comparison. Six-row
queries nest CASE at depths 1, 4 and 8, using three distinct literals per depth.
Each compilation is followed by an identical-query concrete-cache hit. Every
result contains six projected rows. Deterministic ticks occur outside the
interval, with no auto-progress or time advance.

Local instructions cover session acquisition, preparation/execution and output
conversion, excluding endpoint Candid decoding/encoding. Whole-update balance
deltas include platform costs. Medians below are independent medians of three

## Validation and complexity

109 focused native test passes cover canonicalization (26), fingerprints (26),
session ordering/regressions (40) and SQL-disabled CASE tests (17). The separate
native timing benchmark remains ignored. Coverage includes original backing
retention, exact allocation bounds, cumulative exhaustion, copy footprints,
big-integer initialized limbs and 243 first-match/three-valued combinations.
The initial test assumed retained-cache measurement supports big integers; that
fixture assumption was corrected to a separate initialized-limb allowance test.
Focused all-feature lint, formatting, read-admission invariants and their
fixtures, SQL branch ownership, layer authority, production panic and whitespace
checks pass. Full suites remain user-owned.

Nine handoff files: four Rust and five documentation files. Relative to this
turn's starting worktree, approximately +84 production/wiring and +394 test
lines. Ownership is simpler; explicit accounting adds code and fixed stack
receipts but no runtime mode, request authority, cache state or fallback flow.
Other expression-preparation owners remain unfinished in slice 10. Planner/cache
accounting, bounded diagnostics and typed `.explain()` have not started.
