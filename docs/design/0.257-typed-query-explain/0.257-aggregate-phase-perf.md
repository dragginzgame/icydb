# Aggregate audit phase attribution

Date: 2026-09-08. Active release: 0.257.1, preparation slice 10.

## Scope and measurement contract

The existing warmed SQL audit endpoint now reports absolute performance-counter
readings at endpoint entry, after request setup, after session acquisition, after
query execution/session drop, and after request cleanup. Its read sample remains
the difference between query completion and request readiness. Endpoint entry is
after Candid decoding; the final reading is before response encoding and final
wrapper cleanup. Neither reading is a complete message instruction total.

The demonstrated need is to locate repeatable instruction jumps whose matching
whole-update cycle deltas are small. Whole-call cycles alone cannot locate them.
The simplest addition is one audit-only result envelope on an existing endpoint;
there is no new endpoint, database execution route, configuration or production
budget policy. Other total-only and loop audit helpers retain their semantics.

The new native phase probe uses the same 16-, 256- and 4096-byte FILTER literals,
three values and immediate repeated-query hits. It checks counter monotonicity,
phase reconciliation and unchanged results across values/hits. It does not
subtract inferred page charges or relax the existing review thresholds.

## Why partial counters need care

PocketIC 16's release identifies IC commit
`fc21803c3c3a8dd452b3b58b959751c41fecb89c`. At that commit, the
[deterministic memory tracker](https://github.com/dfinity/ic/blob/fc21803c3c3a8dd452b3b58b959751c41fecb89c/rs/memory_tracker/src/deterministic.rs#L330)
charges both first access and first write of Wasm pages to the instruction
counter. The [subnet default](https://github.com/dfinity/ic/blob/fc21803c3c3a8dd452b3b58b959751c41fecb89c/rs/config/src/subnet_config.rs#L141)
is 5,000 instructions per OS page: a 64-KiB Wasm page spans sixteen 4-KiB OS
pages, giving 80,000-instruction increments per access/write event.

These charges are real work accounting, not random timer noise. Where a page
is first touched can shift charges between decoding, request/session setup,
query work and output handling. The original two flagged deltas, +483,750 and
+480,059, are close to six increments; that arithmetic alone is not attribution.
Counter instrumentation also changes code and memory layout, so newly measured
phase boundaries cannot retroactively identify exact page addresses in the
uninstrumented runs. The original receipt and flags remain intact.

## Matched experiment

Both the pre-aggregate-copy and current lowering shapes are built with identical
phase instrumentation and canonical SQL-perf WasmRelease/LocalTest settings.
Only the three aggregate-related lowering files are temporarily changed for the
baseline; current worktree content is restored afterward. The baseline keeps
the preceding literal copier and other preparation changes. No legacy runtime
mode is retained. Frozen artifacts and logs are in
`/tmp/icydb-phase-audit.6ctPpd/`.

## Results

All three temporarily changed lowering files were restored byte-for-byte to
their turn-start content. Instrumented phase differences (candidate minus
baseline) demonstrate movement across the read-sample boundary:

| Sample | Counter before read delta | Read sample delta | Through request cleanup delta | Whole-update cycles delta |
|---|---:|---:|---:|---:|
| 16 bytes, repeat 2 hit | +240,033 | -239,460 | +573 | -870 |
| 256 bytes, repeat 2 compile | -479,998 | +479,402 | -594 | +590 |
| 256 bytes, repeat 2 hit | -320,002 | +323,166 | +3,164 | +3,115 |

The large positive read samples are offset by earlier counter differences,
leaving much smaller changes through request cleanup. This directly establishes
boundary redistribution in the instrumented experiment. Its near-80,000
increments are consistent with the pinned memory-tracker mechanism; the probe
does not collect page addresses or prove the exact page attribution in the old
uninstrumented samples. In particular, this is not evidence of an additional
479,402 instructions of whole-message work in the compile example.

Independent medians of three whole-update cycle samples change by -0.02288%,
-0.00989% and -0.04307% for compilations, and -0.01321%, +0.01717% and +0.01353%
for hits at 16, 256 and 4096 bytes respectively. No material whole-update cycle
regression appears in these shapes. Local-counter flags remain recorded in the
[original receipt](0.257-aggregate-copy-perf.md); phase attribution supplies
context, not silently adjusted instruction totals or relaxed limits. Prior CASE
flags are not qualified by this aggregate-only experiment.
