# SQL scalar construction accounting

Date: 2026-09-08. Active release: 0.257.1, expression-preparation slice 10.
Baseline: the preceding [arithmetic cleanup](0.257-sql-arithmetic-perf.md),
not published 0.257.0.

## Contract

The existing SQL expression lowering owner now borrows current request counters
for source-expression visits, membership slots, path segments, copied identifier
and LIKE-prefix bytes, and LIKE pattern inspection. Temporary storage charges
precede field/path/prefix copies, Expr boxes, function arguments, membership
value/argument slots and CASE arm/ELSE backing. Known-length fallible vectors
reserve their requested length once rather than relying on collect's implicit
growth. This also reserves the full vector before visiting its children, even
when a later child rejects; the reservation is charged and the private vector
is discarded on failure.

The [preflight](0.257-preparation-work-preflight.md) specifies the units. These
are cumulative requested backing and source-work charges, not allocator overhead
or a live-heap gauge. Synthetic default leaves do not claim authored visits.
Literal payload and aggregate syntax copies remain unaccounted by this owner;
charging their containing node or slot does not bound those copies. Existing
request ceilings and planning-operation units do not change. No alternative
unmetered route, fallback result or budget-retaining artifact is introduced.

## Validation

103 focused native passes: SQL lowering (36), session ordering/preparation (41),
and fingerprints (26). New direct tests cover exact and one-byte-short backing
limits for eleven scalar shapes, exact visit/copy-work boundaries, failure after
partial construction and cumulative retry charges with unchanged input syntax.
Session tests prove warm compiled commands skip this lowering, cold failure
does not populate the cache or execute rows, retries do not reset charges, and
a fresh request can compile after rejection. Existing retained-binding/current-
authority and SQL/prepared/fluent parity regressions pass.

Focused all-feature lint, formatting, read-admission, SQL branch ownership,
layer authority, production-panic and whitespace checks pass. No native test or
lint failures occurred in this step. Full suites remain user-owned. SQL-disabled
runtime code and applications are unchanged; no SQL-disabled rebuild is claimed.

## Matched cost

Both unchanged native probes use the existing SQL-perf actor, with the same
WasmRelease/LocalTest configuration, SQL and Candid enabled. No actor or probe
instrumentation changes. Arithmetic covers four operators with three distinct
literals and identical-query hits (24 records). CASE covers depths 1, 4 and 8
with three distinct literals and identical-query hits (18 records). Fresh
six-row fixtures separate shapes; every result retains six projected rows.
Deterministic settling ticks run outside cycle intervals without auto-progress
or time advance. The native probes and both Wasm modules are frozen for replay.

Local instructions cover session acquisition, SQL preparation/execution and
output conversion, excluding endpoint Candid decoding/encoding. Whole-update
cycle-balance deltas include platform work. Independent medians use three
samples per cell, including the first compilation after setup, not pure steady
state. These measurements include both added charges and changed vector
reservation behavior; they do not isolate those effects.

Every arithmetic compilation adds exactly 2,809 local instructions and cycles.
Compilation instruction medians rise 0.0658–0.0662%, and cycle medians rise
0.0156%. All twelve arithmetic cache-hit records are unchanged.
