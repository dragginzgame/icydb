# Shared preparation literal copying

Date: 2026-09-08. Active release: 0.257.1, expression-preparation slice 10.
Incremental baseline: the preceding [SQL construction candidate](0.257-sql-construction-perf.md),
not published 0.257.0.

## One copy owner

`PreparationWork::copy_value` replaces the recursive normalized-filter
materializer's copy implementation and also owns SQL-to-planner literal and
membership payload copies. Materialization still moves owned converted values;
borrowed values use the shared copier. Conversion/admission stays at its existing
owner, and the copier neither coerces nor validates a value's query context.

Each visited Value charges NestedValueSteps. Text/blob and big-integer backing
charge before copying, with a corresponding byte-work allowance on
PredicateExpressionSteps. Big-integer bytes retain the previous conservative
initialized-magnitude allowance rounded to 64-bit words, covering 32-/64-bit
limbs rather than source spare capacity. List and map vectors reserve requested
child/pair backing, then copy children through the same owner. Enum payload boxes
charge after copying their child but before allocating the box. Empty payloads
and inline scalars consume a visit without a backing charge.

There is no sizing traversal followed by a deep clone: containers are constructed
in the charging walk; only checked leaf variants reach ordinary Clone. The match
is exhaustive so a new Value variant requires an explicit copying decision.
Collection order, duplicate entries, value tags and enum type/variant IDs and
body shape are preserved. Partial copies are private and discarded on failure;
source values and retained SQL syntax stay unchanged while charges accumulate.

This is cumulative requested-backing accounting, not allocator overhead,
retained-cache capacity, a new depth policy or a complete stack-safety proof.
Existing input/accepted-value admission remains necessary. Aggregate syntax,
normalization/folding/alias copies and the other preflight gaps remain separate.

## Validation

131 focused native passes: shared copying (5), filter materialization (8), SQL
lowering (37), session ordering/preparation (42), fingerprints (26), plus
SQL-disabled shared-copy (5) and filter-materialization (8) selections.
Coverage includes exact and one-byte-short backing, initialized big-integer
allowances, nested maps/lists/enums, preserved order/duplicates/enum identities,
zero-backing visits, byte-work rejection before allocation, partial failure and
cumulative retry. SQL literal/membership controls prove payloads are charged in
addition to slots. Session controls prove warm commands skip copying, failed
copies do not populate the cache or visit rows, and fresh requests can compile
after rejection. Existing authority and binding parity regressions pass.

Focused all-feature lint, formatting, admission/branch/authority/panic invariants
and whitespace checks pass. No test or lint failures occurred in this step.
Full suites remain user-owned.

## Matched measurement

same WasmRelease/LocalTest configuration, SQL and Candid enabled. No actor or
probe instrumentation changes. Arithmetic covers four operators with three
distinct literals and identical-query hits (24 records). HAVING covers 16-byte,
256-byte and 4-KiB text literals with three distinct values and identical-query
hits (18 records). Each shape starts from a fresh six-row fixture; every call
keeps the expected six-row result. Deterministic settling ticks occur outside
the measured interval, without auto-progress or time advance.

output conversion, excluding endpoint Candid decoding/encoding. Whole-update

## Complexity and remaining scope

Twelve handoff files: seven Rust and five docs, approximately +58 production and
+219 test/wiring lines relative to this turn's starting worktree. One existing
copy owner is extracted and extended instead of adding an independent SQL copy
walker or size estimator. Accounting grows, but semantic ownership is converged;
no runtime mode, limit, cache policy or compatibility path is added.
Slice 10 remains open for aggregate syntax and other documented expression-copy
work. Typed `.explain()` and later planned slices have not started. Applications,
Cargo versions, commits and pushes are unchanged.
