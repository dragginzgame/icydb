# Catalog big-integer admission: remove size-only encodings

This slice-10 checkpoint replaces four temporary LEB128 encodings in accepted
value normalization and canonical validation with the existing allocation-free
atom length methods. One `ValueAdmissionBudget` helper preserves field-limit
checking before charging the five-byte tag/length overhead plus payload size.
It adds no admission family, runtime route, schema authority or format.

The budget still measures encoded size, not all CPU work or temporary heap.
Actual persistence encoders remain unchanged. Decimal parsing, deeper catalog
copies and request preparation accounting remain unfinished slice-10 work.

## Measurement contract

- Same maintained `sql_perf` actor, canonical `wasm-release`, SQL/Candid enabled,
  local-test profile, Rust 1.97.1, Binaryen 132, PocketIC 16.0.0 application subnet.
- A bounded test-admin endpoint reuses the existing `PerfAuditBigLiteral`
  fixture. Each update inserts one row through ordinary structural mutation,
  with a negative `IntBig` and positive `NatBig` of 20, 80 or 300 all-9 digits.
  This exercises accepted input admission and real persistence, not an isolated
  arithmetic helper. No application or production endpoint contract changes.
- Fresh canister per width; four sequential inserts with distinct IDs 0–3.
  All updates affect exactly one row. The first call is cold; report the median
  of the subsequent three calls. Warm calls have progressively larger tables,
  identically in both modules; this is not fixed-row-count steady-state testing.
- Settle 64 deterministic rounds before each update. No auto-progress or manual
  time advancement. The local instruction window covers session acquisition and
  mutation, excluding decimal parsing and patch construction. Whole-update
  cycles include those, Candid and platform overhead.
- Instrumentation is identical in both modules and precedes the baseline build.
  The baseline already includes the previous literal-conversion cleanup; these
  percentages must not be combined with its results.
