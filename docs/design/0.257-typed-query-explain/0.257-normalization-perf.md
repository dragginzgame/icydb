# 0.257 — Shared Boolean Normalization Measurement

Date: 2026-09-08. Tracker slice 3; see [status](0.257-status.md).

## Outcome and scope

Collecting a same-operator input group before normalizing its terms removes
repeated flatten/sort/deduplicate/rebuild work. The matched native probe improves
all measured widths and shapes. For balanced 64/128-term input, normalization
takes about 83% less time (about 5.9x throughput for this isolated pass).
Canonical output remains left-associated; this is not a new depth limit or an
end-to-end stack-safety claim.

These are **native normalization timings**, not IC cycles, SQL parsing,
initial filter lowering, full planning, row execution, or endpoint latency.
The left-versus-balanced comparison exercises synthetic input shapes; it is not
a measured end-to-end gain for the preceding initial-lowering slice. No Wasm
bytes, defined-function counts, allocations or IC instructions were measured.

## Matched inputs

- Baseline: pushed `bd40327d5657bd5700933d0d7e2dca162b4a4539` shared normalizer,
  with the pending balanced-filter slice retained and the new test module wired
  in. Production normalization was unchanged when the baseline was frozen.
- Candidate: the same worktree plus the slice-3 collector change. No Cargo
  version, dependency, profile, runtime configuration or feature change.
- Rust `1.97.1 (8bab26f4f 2026-07-14)`, x86_64 Linux,
  AMD Ryzen Threadripper 7970X. Existing optimized dev/test profile: opt-level 1,
  no LTO, debug assertions enabled; SQL/migration/metrics disabled for timing.
- Synthetic `AND` expressions with 4, 16, 64 or 128 distinct boolean field
  references in descending name order. Left-associated and balanced inputs
  contain identical terms. This is not a representative application dataset;
  mixed operators, duplicate-heavy lists and complex operands are not timed.
- Each process warms each case once, then reports the median of seven batches
  of 64 calls. Input trees are cloned before each timer starts; public
  normalization, its debug shape checks, output disposal and batch iteration
  are timed. The harness uses `black_box`; no time-based assertion is added.
- After compilation finished, frozen binaries ran baseline/candidate/baseline/
  candidate sequentially, without a concurrent build launched by this agent.
  The timing loop is unchanged. A test-helper `match` became `if let` to satisfy
  lint between builds; that fixture-construction work is outside the timer.
  No CPU pinning, confidence interval or production-profile qualification is
  claimed. Small-width sub-microsecond differences are particularly noisy.

## Repeated measurements

Times below are nanoseconds per normalization. Each cell shows the medians
from the two process runs; the reduction uses their arithmetic midpoints.

| Terms | Input shape | Baseline runs (ns) | Candidate runs (ns) | Less time |
| --- | --- | --- | --- | --- |
| 4 | left | 1219 / 1687 | 866 / 887 | 39.7% |
| 4 | balanced | 1120 / 1341 | 871 / 873 | 29.1% |
| 16 | left | 23209 / 24394 | 10902 / 10880 | 54.2% |
| 16 | balanced | 14610 / 14637 | 10617 / 10608 | 27.4% |
| 64 | left | 385938 / 383860 | 14019 / 14194 | 96.3% |
| 64 | balanced | 80074 / 81336 | 13564 / 13737 | 83.1% |
| 128 | left | 1691107 / 1697718 | 33945 / 35718 | 97.9% |
| 128 | balanced | 188277 / 196237 | 32553 / 32571 | 83.1% |

The large left-chain gain comes from avoiding work on every growing prefix.
Already-balanced inputs also improve because intermediate subtree groups no
longer need separate sorting and rebuilding. The sort comparator and final
canonical builder are unchanged. Faster normalization does not imply fewer rows
read, a different access plan, or a proportional full-query speedup.

## Complexity and remaining work

This slice adds 18 net production lines in one existing owner, plus 146 lines of
direct tests/manual timing and three test-module wiring lines. Seven files are
touched including this receipt, design/status and active changelogs. The
algorithm removes repeated work without a new product mode, authority, cache
representation, collection buffer or public API. Traversal remains recursive,
and output remains a left-deep canonical tree.

Compact typed membership, fluent append cloning, diagnostic limits and typed
explain are separate work. Full suites, production-workload/end-to-end timing,
IC cycles and raw Wasm measurement remain unrun.
