# 0.257 — Compact Typed Membership Measurement

Date: 2026-09-08. Tracker slice 4; see [status](0.257-status.md).

## Outcome and scope

Moving an admitted typed membership list directly into the existing compact
operation avoids building, normalizing and collapsing a comparison tree. Native
preparation improves at every measured width. For 128 values, the repeated-run
midpoints fall from about 528 microseconds to 6.8 microseconds (98.7% less time).

This measures lowering, boolean normalization and predicate derivation, not SQL
parsing, access planning, cache lookup, row execution, endpoint latency or IC
cycles. No Wasm bytes, function counts or allocation totals were measured.

## Repeated measurements

Nanoseconds per preparation. Each cell gives the medians from two process runs;
the reduction uses their arithmetic midpoints.

| Values | Baseline runs (ns) | Candidate runs (ns) | Less time |
| --- | --- | --- | --- |
| 4 | 4985 / 5117 | 431 / 427 | 91.5% |
| 16 | 41131 / 39797 | 1266 / 1272 | 96.9% |
| 64 | 118676 / 115428 | 3373 / 3346 | 97.1% |
| 128 | 533293 / 523626 | 6673 / 6916 | 98.7% |

For 128 positive membership values, initial expression construction goes from
511 expression nodes to three expression nodes plus the 128 list values. Negated
membership adds one expression node. Operand storage and processing remain
linear in list length; constant expression depth is not constant memory or work.
An ownership test verifies the list buffer moves without copying at this boundary.

## Complexity and compatibility

This slice touches 13 files: five production owners, three additional test files
and five documentation files. Production code shrinks by seven net lines;
test/timing/wiring code grows by 277 net lines. Typed and SQL frontends share one
compact constructor; collection operands and mixed coercions reuse the existing
leaf-comparison predicate path. No new public API, mode or coercion authority.

The user approved changed affected query fingerprints and continuation
signatures. Restart affected pagination after upgrading; no compatibility hash,
decoder or fallback is retained, and the current cursor format stays version 1.
Typed explain, diagnostic limits and fluent append ownership are separate work.
Full suites, IC cycles, end-to-end timing and raw Wasm measurement remain unrun.
