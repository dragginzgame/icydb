# Shared template candidate authority — qualification

Date: 2026-09-09. Active patch: 0.257.2. Slice 11 remains in progress.

## Change and contract

The shared parameterized cache previously cloned a vector of accepted-index
handles on checkout and performed a second checkout when publishing a rebound
memo. Individual handles already share their immutable metadata. Templates now
share the handle array too, and successful rebinding publishes the checked-out
template directly through the existing weighted insertion owner.

The existing request PreparationWork guard charges the cold array allocation:
one PredicateExpressionSteps unit per handle and TemporaryBytes equal to array
backing plus two pointer-width reference counts. No recursive metadata copy or
uncharged sizing traversal is involved. Empty arrays retain the reference-count
header too. The existing retained-size visitor counts shared backing and header;
construction and retained-capacity accounting remain separate responsibilities.

There is no new cache mode, key identity, authority, persisted representation,
or session borrow in the detached template. A failed construction cannot publish
an artifact, and failed rebinding cannot replace the previous memo. Remaining
planner construction, retained-key resolution/comparison and cache traversal work
is not declared fully bounded by this handoff.

## Validation and complexity

The 51 focused query/cache tests and 12 cardinality/lifecycle tests pass. They
include exact/one-below work and byte limits, public/trusted attribution,
cumulative rejection, no row execution or partial publication, warm identical
and A/B/A bindings, retained-cache weights, accepted-schema transitions and
pinned continuation semantics. Required repository Clippy and the focused
all-feature test-target lint pass. The SQL-disabled Wasm build and all four
instruction samples pass; full suites remain user-owned.

Three isolated PocketIC servers were started and stopped for the two initial
subjects and their combined repeat. No deployed canister was changed. An initial
fixture-ordering error and lint warning were corrected; a later concurrent test
compile error was resolved by its owner before the focused suites passed.

Three production files add ten net lines while removing one cache-update helper
and a redundant lookup/copy flow. Test wiring and the direct budget regression
add 131 lines; four documents record the active release, status and qualification.
The ownership/flow shape is simpler; the cold allocation now has an explicit
budget check. Retained-key and broader planner accounting remain the next work.
