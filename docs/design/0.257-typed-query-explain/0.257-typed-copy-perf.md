# Request-metered typed operand copies

Date: 2026-09-09. Active release: 0.257.1, preparation slice 10.

## Scope and ownership

Typed/dynamic ORDER BY and aggregate operand copying now uses one fallible
expression copier under the existing request scope. It reserves destination
backing before construction and charges visits/text work without a separate
sizing walk. Literal payloads use the existing value copier. Aggregate raw-shape
copying stays at AggregateShape and does not normalize inputs, FILTER or DISTINCT.
The owned conversion into shared intent still transfers the result without a
second clone. Input admission precedes recursive copying and bounds partial
construction/cleanup depth.

Clause-vector growth, implicit primary-key ordering, selected-field/group-key
construction and downstream planner/cache work are not closed by this change.
No public terminal, new resource counter, cache mode or compatibility path is
introduced. Eight Rust files add approximately 150 production and 240 test
lines; five documentation files complete the handoff. Explicit accounting adds
code while preserving one semantic and execution path.

## Qualification and exclusions

59 all-feature focused tests pass across copying, session ordering, cache and
aggregate fingerprints; four copier tests also pass without SQL. Tests cover
raw-shape/value parity, exact backing limits, failed-child termination, source
reuse, cumulative retries, admitted-depth cleanup, and public/trusted cold/warm
rejection before row execution or cache mutation. Focused library/test Clippy,
formatting, read-admission invariants and whitespace pass.

An initial exact-key actor baseline was unsuitable for copier attribution;
its candidate capture was rejected by the build-input drift guard and is not
used. The dynamic pair above was captured with frozen inputs instead. An initial
Rust import error was corrected before passing native gates. Two isolated
PocketIC servers were started for the probe and stopped by the governed wrapper.
No application or Cargo version changes were made. Full suites and whole-message
cycle measurements remain unrun; this is not `.explain()` closeout evidence.
