# Request-metered alias substitution

Date: 2026-09-08. Active release: 0.257.1, preparation slice 10.
Baseline: the preceding [shared alias-owner candidate](0.257-alias-owner-perf.md),
not published 0.257.0.

## Construction contract

ORDER BY and HAVING alias substitution now charges scalar visits, projection
candidate visits and comparison-byte allowance through the existing request
work. The shared mutable-child visitor is fallible and stops at the first
rejected child. Aggregate inputs remain opaque to alias expansion; replacements
are not recursively treated as more aliases. Successful matching stays
case-insensitive and first-match.

A single SQL operand-copy owner charges expression visits and requested
string/vector/box backing before copying. It preserves SQL expression families,
operator flags, lexical slots and typed operands; values use the existing
`PreparationWork::copy_value`. It does not introduce coercion or a sizing pass
followed by an unchecked subtree clone. Source operands remain borrowed and
unchanged on failure; partial owned expressions use the maintained cleanup.

ORDER BY and HAVING reuse their clause vectors during fallible processing. The
copier is the alias-copy owner, not a replacement for every existing statement
clone in this landing. Surrounding identifier normalization, local-canonical
classification, initial statement clones and later projection copies remain
open. The generic child visitor still supports the currently infallible
identifier rewrite through an uninhabited error type; there is no fallback alias
execution path or ignored budget error.

accepted authority, bindings and cache behavior (45). Tests cover exact visit
and backing limits, retry accumulation, nested value payloads, SQL copy-shape
parity, early sibling termination, failed-command cache exclusion and warm hits
skipping alias copies. A test fixture initially used a predicate directly in a
SELECT list; it was corrected to admitted CASE syntax before final qualification.
Core clippy, formatting and read-admission invariants/fixtures pass. Full
repository suites remain user-owned.

The unchanged frozen probe and phase-instrumented actor use canonical
WasmRelease/LocalTest settings with PocketIC 16. The alias matrix covers ORDER BY
and grouped HAVING, three values each, compilation and immediate cache hits.
Literal-only controls cover four arithmetic operators and three values. Every
call returns six rows with compile/hit parity. Settling ticks stay outside the
whole-update cycle interval; local instruction windows retain their separate
meaning and are not treated as whole-message totals.

These are independent medians. Paired compile cycle deltas are
+540/-1,981/-3,777 for ORDER BY and +4,051/+5,525/+3,592 for HAVING. Paired hit
deltas are 0/-1,038/-1,036 and 0/-50/+3,946 respectively. Every individual
literal-only instruction and cycle result is unchanged. This is safety
accounting with small workload-specific cycle changes, not a general speedup.

The third HAVING hit's local instruction count rises 242,811 (about 6.32%).
Its request-ready counter falls exactly 240,000, leaving +2,811 through request
completion and +3,946 whole-update cycles. Retain this phase redistribution
evidence: the local delta is not a comparable whole-message regression. It is
below the existing joint positive review threshold of 250,000 instructions and
3%; no sample crosses that threshold. Earlier shape-specific flags remain open.
