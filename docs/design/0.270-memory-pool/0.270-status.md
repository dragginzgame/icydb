## Authority and state delta

The final host supplies namespace grants and physical exclusions. Required
`icydb_memory_pool` returns the upstream checked pool for IcyDB-owned cold
bootstrap. It replaces the previous mandatory range input; it is not a new
optional mode, registry or persisted state. A precommitted composed host remains
authoritative and is adopted without invoking the provider or changing its
geometry/policy. Generated declarations contribute only permanent requests.
The simplest alternative, deriving grants from arbitrary requests, would give
components authority over host admission and is rejected.

Keep ledger bytes, key/ID/state/schema bindings, database allocation records and
bucket geometry unchanged. There is no relocation, reset, extra allocator,
predecessor reader, compatibility alias or persisted version. Numeric IDs remain
facts checked against committed key resolution, not allocation instructions.
