## Closeout Correction

The closeout audit found one split immutable fact: hidden execution seams
accepted the raw SQL text independently from the dispatch that owned its parsed
statement. Although generated callers supplied a matching pair, the API could
represent a parsed command cached under different SQL text.

The final request-local dispatch now borrows its originating SQL text and is the
only argument passed through generated and facade execution seams. Cache text,
entity routing, introspection admission, parser attribution and cache-miss
compilation therefore originate from one sealed artifact. The correction adds
no allocation, cache, state or authority; it also removes the unused entity
observer and full-AST debug formatter.
