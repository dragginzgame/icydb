## Assignment

The user explicitly accepted 0.238 on 2026-08-23 as exactly one bounded
ordered scalar DISTINCT prefix-group-seek slice. The five review corrections
are frozen into the authoritative design:

1. physical index-entry work has an exact store-level definition;
2. one immutable prepared-plan contract owns all admission;
3. `LIMIT + OFFSET` is capped at exactly three before execution;
4. NULL rejection, scalar normalization and ASC/DESC boundaries require
   explicit proofs; and
5. 5,000,000 instructions is a hard release gate that cannot be weakened.

No production implementation is present yet.

The design inspection also found that `index_store_entry_reads` does not yet
count entries delivered directly by the raw heap-range visitor. Patch 1 owns
the narrow store-instrumentation correction and heap/journal parity proof;
there will be no executor-local counter.

## Frozen Baseline

| Query | Predecessor instructions | Row gets | Index entries | Range scans |
| --- | ---: | ---: | ---: | ---: |
| `age ASC LIMIT 1` | 92,605,670 | 2,048 | 2,048 | 33 |
| `age ASC LIMIT 3` | 93,144,415 | 2,048 | 2,048 | 33 |
| `age DESC LIMIT 3` | 92,261,973 | 2,048 | 2,048 | 33 |
| `name ASC LIMIT 3` | 90,861,504 | 2,048 | 2,048 | 33 |

The `age ASC LIMIT 3` non-DISTINCT peer is 1,366,834 instructions with three
index entries and no row gets. The 91,777,581-instruction absolute gap is the
best-case removable ceiling, not a candidate result.

Cross-query acceptance also requires every existing shipped 0.237 performance
family to retain its exact physical assertions and approximately one-percent
CI ceiling.

## Required Hostile Evidence

- first groups at the low edge and high edge;
- one enormous duplicate group at each traversal edge;
- mostly unique values;
- ASC and DESC;
- `OFFSET 1 LIMIT 2`;
- empty, one-group, exactly-full and lookahead exhaustion;
- corrupt boundary representatives in both directions;
- nullable, expression, oversized, cursor and incompatible-order fallbacks;
- true-warm reuse, journal overlay, same-Wasm recovery and reinstall; and
- exact SQLite result/order equality plus physical-work equality for fallbacks.

## Version Boundary

0.237 is closed at its 12-patch maximum. Its final 0.237.3 candidate retains
measurement, ShellCheck and CI regression-gate changes only; no group-seek
runtime work may be added to it. Published `v0.237.2` history remains
unchanged.

The 0.238 runtime patch starts only after the 0.237.3 candidate is handed off
for user-owned publication. Until implementation begins, no changelog entry
may claim that prefix-group seek is shipped.
