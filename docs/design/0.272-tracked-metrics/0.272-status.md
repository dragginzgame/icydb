## Authority and state delta

Metrics owns measurement arithmetic and sticky actual-overflow state. IcyDB
already owns volatile execution attribution and bounded report DTOs. Keep the
tracked aggregate in that heap owner and project reports once; do not reconstruct
false quality flags from raw totals or implement a replacement raw helper.
The simpler alternative of retaining the old report loses overflow quality and
cannot distinguish exact caps from clipped observations. Add only report quality
and exact optional means, with no new execution mode, persisted state or cache.
Timers owns declaration validity through `TimerStart`; no local timer policy is
added. Existing construction and execution budgets remain their canonical owners.

## Transition and qualification

tracked observations; clipped old state is not recovered. Update Candid clients
and the CLI together. No stable format changes, database deletion, network
lifecycle or compatibility decoder are part of this cut.
