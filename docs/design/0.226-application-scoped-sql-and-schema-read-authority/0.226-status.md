## Current Boundary

0.226 is reserved for application-scoped generated SQL and schema read
authority with Canic as the reference Fleet-auth integration. This tracker does
not authorize IcyDB or Canic implementation, public API changes, persisted
formats, versions, changelogs, or releases.

The current IcyDB surface remains unchanged:

- generated `icydb_query` accepts SQL text and requires a controller;
- generated `icydb_schema` is explicitly public or controller-only;
- trusted SQL remains an application-authorized admin lane;
- SQL mutation rejection remains unconditional; and
- 0.225 startup readiness remains the ordinary-operation gate.

The current Canic surface remains unchanged. The inspected 0.101.53 authority
separates application subjects from infrastructure callers and supports local
verification of Fleet/role/scope-bound delegated tokens. The exact reusable
local decision, revocation, and audit contract is a Patch 1 question, not an
assumed capability.
