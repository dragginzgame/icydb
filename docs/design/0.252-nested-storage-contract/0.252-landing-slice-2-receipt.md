# IcyDB 0.252 Landing Slice 2 Receipt

Date: 2026-09-01

spellings now use the existing executor-origin `RuntimeUnsupported` boundary
instead of an invariant. No subpath mutation or new diagnostic surface is
added.

## Implementation

Structural patch lowering still resolves one complete field name through the
accepted row-layout contract. A failed lookup now returns the shared
executor-unsupported error directly. The obsolete special constructor and its
unused entity-path arguments are removed.

The candidate deliberately adds no diagnostic enum, E-code, fact schema,
string payload, mutation mode, planner branch, registry entry, callback,
fallback, or persisted state. Public `Error` retains its existing Candid shape;
the exact field spelling remains caller-owned input rather than copied into an
error payload.

- one unknown root field returns `RuntimeUnsupported` from executor origin;
- one late dotted target rejects the complete atomic batch before commit;
- the valid earlier batch item remains unchanged; and
- complete root-field replacement still succeeds.

The test asserts typed codes and classes, not error strings.
