## Outcome

Parse each trusted compiled SQL command once per ingress attempt. The same
current AST supplies its entity-routing fact and, on a compiled-command cache
miss, semantic compilation. Compile attribution must include that routing
parse instead of beginning after it.

This is a flow contraction, not a parser cache. Cache hits still parse once
because accepted-catalogue identity and fingerprint remain part of the existing
compiled-command cache key. Avoiding that parse would require a different
freshness design and is outside this slice.

## Demonstrated Need

The 0.246 owner audit observed this cold miss flow:

```text
trusted SQL query
  -> full parse for entity routing
  -> accepted-catalogue selection
  -> compiled-command cache miss
  -> full parse for semantic compilation
  -> execution
```

The separately attributed second parse measured 21,936–42,079 local
instructions across representative point, ordered, scalar, grouped and
membership queries. The first parse was outside reported compile and total
instructions. On a cache hit the physical routing parse still occurred but
the parse attribution was zero.

## Singular Owner Contract

The maintained flow is:

```text
SQL text
  -> one parser-owned current AST
  -> entity fact borrowed from that AST
  -> accepted catalogue selected by the pinned session root
  -> existing fingerprint-bound compiled-command cache
  -> on miss, semantic compiler borrows the same AST
  -> existing immutable execution context and executor
```

The AST may provide syntax facts only. It cannot select or prove an accepted
schema. Catalogue selection remains session-owned, cache hits remain
fingerprint-bound to accepted authority, and semantic compilation remains the
only owner of resolved commands.

## Scope

Permitted:

- move the canonical parse ahead of catalogue selection;
- derive the entity name from the already parsed statement;
- pass that statement by reference into the existing cache-miss compiler;
- include the one routing parse in compile-phase attribution on hits and
  misses;
- return the derived entity through the existing hidden facade seam; and
- add focused test-only evidence for exact parser invocation counts.

Forbidden:

- an AST cache, nested prepared state or process-global memoization;
- cache lookup before accepted-catalogue selection or freshness proof;
- a new execution route, runtime mode, public option or behavior axis;
- executor parsing, runtime eligibility reconstruction or generated-model
  fallback;
- public response, error, Candid, export, stable-format or package-version
  changes; and
- widening into DDL, policy classification or non-compiled mutation flows that
  independently parse for their own current semantic owner.

The existing shared compiled-command query/mutation cache shell may consume an
already parsed statement. Public mutation wrappers that separately need an
entity for response conversion are not part of this query-ingress finding.

## Measured Result

Exact `v0.245.0` and candidate `sql_perf` production Wasm artifacts were
measured through the same five-sample outer performance-counter calibration:

The predecessor audit artifact is 4,512,007 raw bytes and the candidate is
4,512,671 raw bytes (+664). Both measurements therefore execute production
Wasm built from their stated source revision rather than a host-only surrogate.

| Path | Predecessor | Candidate | Saving |
| --- | ---: | ---: | ---: |
| Normal public query | 1,310,990 | 1,290,070 | 20,920 (1.596%) |
| Attributed public query | 1,359,273 | 1,309,335 | 49,938 (3.674%) |
| Attribution-only overhead | 48,283 | 19,265 | 29,018 |

The normal path removes the second cache-miss parse. The attributed path also
removes the public facade's response-entity parse. Cold compile totals remain
near the predecessor because the old attribution counted one compilation parse
while omitting the routing parse; the new total counts the sole routing parse.
Warm parse attribution now reports real work on every hit.

The minimum one-entity SQL actor measures 3,179,913 final raw bytes, +81 from
the 3,179,832 exact predecessor and well within the 8,192-byte ceiling. Gzip is
1,274,516 bytes (+337), function count falls from 8,211 to 8,208, and the
Candid digest and six exports are identical.

The retained implementation introduces no production type, cache, mutable
owner, invalidation edge, persisted state or behavior axis. Catalogue selection
and freshness remain session-owned, and semantic compilation only borrows the
already parsed statement on a miss. The behavior-bearing production change is
+39 net Rust lines across five files; a sixth production source file carries
only the `cfg(test)` parser-call counter. The semantic shape is simpler despite
that small plumbing delta: one parse owner and one AST now replace two or three
independent parses without adding retained state.
