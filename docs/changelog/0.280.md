# 0.280

## [0.280.0]

### ⚠️ Breaking

- Public schema Principal conversions and read-authorization contexts now use
  the IC Platform 0.6.0 type identity. Consumers passing Platform values must
  adopt the same minor line. External Agent/PocketIC identities still convert
  explicitly. Principal text, Wire frames, binary Serde and stored formats are
  unchanged; no retained-data rewrite is required.

### 🔧 Changed

- Align the seven consumed Host, Build and Testkit packages on published IC
  Tooling 0.63.0. Their library profiles keep empty defaults; Build and Testkit
  no longer select Clap unless the separate CLI feature is requested. Existing
  filesystem custody, process admission, artifact budgets and Wire contracts
  retain their owners and behavior.
- Prepare and check the release editor and Testkit server CLI with `cli` through
  the existing installer. Saved release recovery derives the feature selection
  from its exact archived Build version: pre-0.63 editors retain their original
  recipe. Source and admission failures still stop before release callbacks;
  regressions cover both binary contracts and conflicting working selections.
- Testkit's removed Candid helpers and benchmark error type have no workspace
  callers. Native application calls continue using IcyDB's concrete IC Wire
  contracts over raw PocketIC transport. No Candid compatibility layer, benchmark
  conversion or new simulator lifecycle owner is introduced. Native PocketIC
  still selects Candid internally.
- Enable `principal` explicitly in the schema and public facade packages.
  Platform 0.6 no longer provides those types in an empty feature selection.
  Core and system-only fixtures retain `ic0`; runtime/client packages retain
  their existing profiles, which imply Principal when needed. No Candid,
  parser, entrypoint generator, codec or runtime fallback is added locally.
- Select the incoming Canic adapter revision `9505996`, which aligns its
  Timers requirement with registry 0.30.0 and the workspace's Metrics 0.15
  identities. The adapter still owns exports, entropy and lifecycle; its SDK
  migration remains separate. This selection is an immutable Git dependency,
  rather than a claim that the adapter exists in the local Canic main checkout.
  Refresh the two compile-fail diagnostic origins to that selected revision;
  malformed lifecycle declarations and guard calls retain their rejection checks.

### 🩹 Fixed

- Read startup watchdog counters through Timers' exact measurement totals and
  checked `u64` conversion. Overflow or values outside the existing audit reply
  range trap instead of supplying inexact evidence. The entity lifecycle fixture
  likewise retains its count fields and returns its existing invariant error
  when exact conversion fails. Reply schemas and Wire bytes retain their
  contracts; both fixture consumers build with Timers 0.30.1.
