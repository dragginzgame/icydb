# 0.281

## [0.281.1] - 2026-10-23

### 🩹 Fixed

- Use the accepted catalog's schema reference for DELETE and UPDATE selector
  preparation, and request only entity authority for INSERT SELECT and DELETE
  execution. Remove the tuple helper that copied the schema's field/index
  vectors and returned an authority that DELETE preparation discarded. Keep
  descriptor checks, accepted-snapshot ownership, alias normalization, candidate
  budgets, RETURNING and row-write admission on their existing paths. No new
  public API, execution route, state or storage/wire format. Raw Wasm-size,
  IC cycle and instruction deltas are unmeasured
  ([#423 — A SQL write clones the schema and then only borrows it](https://github.com/dragginzgame/icydb/issues/423)).
- Classify unsupported SQL-shell INSERT and DELETE as the existing typed surface
  refusals in the canonical SQL parser/routing owner. The CLI explains the
  supported query/DDL/opt-in UPDATE scope and stops before canister discovery or
  endpoint dispatch. Keep trusted application mutation APIs and generated query
  ingress behavior unchanged; add no endpoint or local parser. Cover VALUES and
  SELECT inserts, whole/predicate deletes, RETURNING, mixed case and whitespace,
  both command-line argument forms, and supported query/DDL/UPDATE routing. Correct
  the 1.0 scope documents and SQL contract. No wire or storage format change;
  raw Wasm-size, IC cycle and instruction deltas are unmeasured
  ([#242 — CLI INSERT/DELETE routes to the read-only query endpoint](https://github.com/dragginzgame/icydb/issues/242)).
- Borrow primary stream bounds for forward/reverse key chunks and direct row
  visits. Carry borrowed index edges and exclusive anchors through continuation
  validation into heap and journaled range traversal; envelope containment also
  borrows its edges. Propagate the internal visitor contract to integrity,
  relation, migration and staged-write consumers without changing their policies.
  Preserve direction, inclusivity, empty envelopes, typed anchor refusal, overlay
  visibility, limits and early-stop/resume behavior. No new execution route,
  persisted state, wire format or public API. Add directional range parity and
  retained-edge identity coverage, bounded direct-primary interruption and
  continuation controls, and filtered covering-component chunks with scalar
  and composite primary keys. Raw Wasm-size, IC cycle and instruction deltas are
  unmeasured
  ([#421 — A range chunk copies bounds the visit only borrows](https://github.com/dragginzgame/icydb/issues/421)).
- Validate migration reachability with an iterative, cycle-aware worklist using
  the existing named-type child traversal. Reuse one reachable-type set across
  an entity's local rename checks, then traverse each entity once for shared
  closure, discarding that set before the next entity. Deduplicate shared rename
  requirements and look up exact declarations through their existing canonical
  ordering, without a retained cross-entity cache. Preserve targeted-rule
  reachability, mapped member types, typed errors and proposal/wire contracts.
  Qualify public composition and decoding with a 16,384-type cyclic graph across
  all seven named-type shapes on a small native stack, repeated renames, missing
  companion transitions and mismatched enum declarations. Raw Wasm-size, IC
  cycle and instruction deltas are unmeasured; installed-IC stack qualification
  remains unrun
  ([#188 — Migration closure validation recurses without a depth bound and has superlinear cost on a bounded public proposal](https://github.com/dragginzgame/icydb/issues/188)).
- Borrow cached lower keys while sorting multi-value index prefix specifications
  in both materialized and branch-stream execution. Charge the temporary reference
  descriptors while preserving deferred-bound admission, stable tie ordering,
  descending reversal and typed failure propagation. Remove the discarded key
  copies without another execution route or changes to stored keys, cursor frames
  or result order. Extend ordered query coverage with repeated, unsorted operands
  and absent branches large enough to defer bound construction. Raw Wasm-size,
  IC cycle and instruction deltas are unmeasured
  ([#414 — A multi-value index lookup copies each lower key and then drops it](https://github.com/dragginzgame/icydb/issues/414)).
- Frame prefix continuation anchors directly from lowered prefix bytes, accepted
  index identity/generation and the cursor's scalar or composite primary key.
  Borrow the prefix through the index codec's shared validation and framing;
  encode only the semantic suffix. Remove lower-bound decoding and the temporary
  owned index key. Preserve exact anchor bytes, complete row identity, component
  and frame bounds, and typed refusal without a new route, stored format or
  cursor contract. Add byte-parity and rejection controls across prefix widths,
  key kinds, generations and scalar/composite suffixes. Raw Wasm-size, IC cycle
  and instruction deltas are unmeasured
  ([#415 — A prefix resume decodes components the spec already owns](https://github.com/dragginzgame/icydb/issues/415)).
- Borrow cached covering-prefix bounds through the direct merged scan and the
  scoped component streams, including their ordinary range-fold consumer.
  Retain the existing stream lifetime instead of copying bounds or transferring
  ownership from the borrowed specifications. Charge the direct merge's reference
  descriptors without charging discarded key copies; preserve deferred-bound
  admission and the store owner's structural admission. Keep range emptiness,
  direction, filtering, page limits and mixed-overlay fallback semantics.
  No new ownership container, execution route, stored format or public contract;
  raw Wasm-size, IC cycle and instruction deltas are unmeasured
  ([#417 — A covering merge copies index bounds that the scan only borrows](https://github.com/dragginzgame/icydb/issues/417)).
- Maintain absolute and overlay prefix counts from the strict borrowed index
  frame. Keep absolute replacement validation and the overlay's existing
  identical-input guard; build owned count keys only when membership changes.
  Transfer first-component backing
  into its retained key and use occupied map entries for signed updates without
  copying that key. Preserve namespace filtering, zero-component keys, complete
  primary-key and witness validation for observed user entries, synchronization
  invalidation, overlay
  cancellation and overflow refusal. No new metadata state, stored format,
  execution route or public contract; raw Wasm-size, IC cycle and instruction
  deltas are unmeasured
  ([#419 — Prefix cardinality copies every index component and then copies it again](https://github.com/dragginzgame/icydb/issues/419)).
- Carry only entity identity into row-count updates after ordinary writes,
  replay and canonical folds, preserving malformed-prefix and no-change guards.
  Heap index inserts borrow their entry key; live and preflighted writes update
  counts before transferring ownership. Positioned publication reuses its
  retained key, and canonical index deletion no longer copies it. Preserve old
  values, visible and overlay counts, generations, retirement and fold behavior
  without extra tree lookups, metadata states, persisted formats or public APIs
  ([#418 — A store insert copies the key so cardinality can borrow it](https://github.com/dragginzgame/icydb/issues/418)).
  One canonical stable-index insertion copy remains necessary with the published
  consuming Storage API. The owner investigation is
  [IC Persistence #131 — Evaluate caller key access across returning stable-map insertion](https://github.com/dragginzgame/ic-persistence/issues/131);
  #418 remains partially resolved. Raw Wasm-size, IC cycle and instruction deltas
  are unmeasured.

### 🧪 Testing

  control and storage-backed journal fixtures: exact active batch, record and
  encoded-byte counts; typed refusal when the active owner is missing; legitimate
  allocation retirement; unexpected physical debt under a retired allocation;
  and successful measurement after draining that debt. Reuse existing allocation,
  control, journal and retirement owners without another test-only runtime route.
  Production code and protocols are unchanged. Native test memory supplies the
  physical leases; this does not qualify production memory opening, installed-IC

  obligations remain open
  ([#267 — Production Gate-2 measurement and the marker-presence fast path have test-only replacements](https://github.com/dragginzgame/icydb/issues/267)).

### 🔧 Changed

- Adopt published Wire/derive 0.6.10, preserving existing native codec frames,
  endpoint identities, field representations, limits and error behavior.
  TypeScript generation fully qualifies built-in array types through
  `globalThis`, avoiding consumer-name shadowing. Registry helpers also avoid
  consumer declarations named `types`, `createCodec` or `JSON`, and retain own
  `__proto__` properties. The opt-in `PackedI16` field is
  not used by IcyDB; ordinary signed integer lists retain their
  existing encoding. Wire owns its added internal `bytemuck` dependency; no
  direct dependency or local codec is introduced. Matched Wasm-size, cycle
  and instruction deltas are unmeasured for this adoption.
- Adopt the published IC Memory/Storage 0.50.13 and Timers 0.30.7 patches.
  Their library Rust sources and enabled feature contracts are unchanged from
  Memory/Storage 0.50.12 and Timers 0.30.6. Keep exclusive memory ownership,
  persisted allocation and storage formats, bounded diagnostic projections,
  timer identities, callbacks and lifecycle ordering. The existing dependency
  ranges already admit these releases; no consumer wrapper, fallback or API
  migration is required. Raw Wasm-size, IC cycle and instruction deltas are
  unmeasured for this adoption.

## [0.281.0] - 2026-10-23

### ⚠️ Breaking

- Adopt registry Wire/derive 0.6.5, which removes the finite codec API. The public
  codec-error reexports now have Wire 0.6 identity; consumers that directly use
  Wire 0.5 errors must update together. The native application codec, endpoint
  IDs, canonical frames, decoder policy and persisted formats are unchanged.
- Migrate the two remaining audit protocols to native Serde/Postcard framing,
  preserving their scalar/unit payload bytes, method IDs, byte limits and
  rejection-before-query behavior. Allocation, node and depth allowances now
  account for native traversal charges. Remove the obsolete typed frame dependency
  from artifact inspection and keep Build's Wire metadata dependency in development
  only. This adds no codec wrapper, alternate protocol or compatibility reader.

### 🩹 Fixed

- Select the first record-path member during complete root validation instead
  of walking the root again after admission. Reuse canonical child traversal
  at the original depth and retain validation of every later sibling, duplicate
  key first-match selection, missing/null semantics and historical-slot fills.
  No execution mode, accepted schema, stored format or instruction ceiling changes.
  On the frozen local debug grouping fixture across 39 reported calls, cold path
  instructions fall from 5,897,544,692 to 5,786,860,404; its direct-control premium
  falls from 20.11% to 17.84%. Ordered path instructions fall from 6,383,122,226
  to 6,272,346,977; its premium falls from 16.19% to 14.16%. The retained pre-fix
  raw debug actor is 6,972,665 bytes and the rebuilt actor is 6,963,725 bytes
  (−8,940). These measurements do not qualify production-profile size or cycles.
- Validate each source/relation once against the complete target-delete set in
  the existing final batch overlay. Repeated reverse witnesses reuse successful
  checks, allowing update-away plus many-target-delete batches without multiplying
  raw-reference charges. Keep complete source identity, per-relation separation,
  witness decoding, corruption refusal and atomic rejection when any deleted
  target remains referenced. Bound temporary successful facts by the existing
  reverse-effect ceiling; preserve save-time target admission and before/after
  accounting. No public API, configuration, lifecycle or stored-format change;
  raw Wasm-size, IC cycle and instruction deltas are unmeasured
  ([#60 — Delete restriction repeats source projection](https://github.com/dragginzgame/icydb/issues/60)).
- Scope complete user-index replacement to the target entity in both row and
  index storage. Reuse the same canonical entity-index bounds as emptiness proofs,
  preserving every ordinal/generation and heap/journal overlay semantics. Foreign
  entries no longer consume the target projection allowance; selected-domain
  corruption, target budget exhaustion, exact before-image comparison and
  zero-write staging remain enforced. No public API or stored format changes;
  raw Wasm-size, IC cycle and instruction deltas are unmeasured
  ([#97 — Index rebuilds scan unrelated entities](https://github.com/dragginzgame/icydb/issues/97)).
- Prove empty entity user-index and reverse-relation domains with the canonical
  prefix bounds and merged index reader. Unrelated entities, generations, relation
  IDs and namespaces no longer consume the emptiness proof budget. Stop on the
  first physical witness; retain readiness, accepted relation authority, local
  corruption refusal and live/tombstone semantics. Probe every admitted component
  count so malformed relation shapes cannot evade refusal. Complete-domain
  replacement staging retains its existing inventory and budget. No public API,
  stored format, cache or lifecycle change is needed; IC cycle/instruction and
  raw Wasm-size deltas are unmeasured
  ([#62 — Empty relation removal scans unrelated indexes](https://github.com/dragginzgame/icydb/issues/62)).
- Classify deterministic migration-planning rejections as terminal generated
  schema failures through the existing bound startup receipt. Preserve their
  exact leaf diagnostics and fact validation so startup reports the cause instead
  of requesting another immediate planning attempt. Retryable schema errors
  reach the adapter's existing logged cadence instead of reporting progress.
  Controller-progress and publication-conflict classification is unchanged;
  corrected generated submissions use the existing receipt binding. No new retry policy,
  lifecycle state, public API or stored format is needed
  ([#117 — Startup repeatedly replans rejected migrations](https://github.com/dragginzgame/icydb/issues/117)).
- Refill verified store-local bundle and cardinality projections during the
  existing replicated startup preparation, even when the database runtime root
  already hits its cache. Folding can invalidate those store projections without
  changing the accepted root. Reuse the schema store's verification owner and
  preserve canonical-only cardinality construction, failure classification and
  query results without another cache, lifecycle state or stored-format change.
  IC cycle/instruction and Wasm-size deltas remain unmeasured
  ([#82 — Schema folding leaves admitted cardinality evidence unavailable](https://github.com/dragginzgame/icydb/issues/82)).
- Retain the existing commit wake-up after accepted schema publication even
  when a heap-store batch has no journal sequence. The installed startup driver
  can reconcile a completed metadata migration and prepare the accepted runtime
  root after SQL DDL. Keep ordinary heap row writes quiescent and preserve
  journal-debt scheduling, captured callbacks, typed errors and marker recovery.
  No new timer, lifecycle state or stored-format change is needed; IC
  cycle/instruction and Wasm-size deltas remain unmeasured
  ([#88 — Heap metadata migrations leave startup Recovering](https://github.com/dragginzgame/icydb/issues/88),
  [#196 — Heap schema publications leave the runtime root cold](https://github.com/dragginzgame/icydb/issues/196)).
