# IcyDB 0.251 — Runtime And Entity Codec Wasm Reduction

## [0.251.0] - 2026-09-01

### 📊 Audit

- Hard-cut the Wasm measurement identity to
  `icydb-wasm-footprint/0.251/v1` while retaining representation version `1`.
- Added controlled empty-schema actors for no metrics, basic metrics plus reset
  and extended metrics, each measured with SQL disabled and enabled. The basic
  surface adds 178,740 raw and 163,358 code bytes with SQL off; SQL on produces
  the same conclusion within six raw bytes.
- Froze the published 0.250.1 reachable-entity baseline at 40,190 raw bytes
  across nine added entities, or 4,466 bytes/entity. Reaching a genuine 2 KiB
  full-adapter ceiling requires removing at least 21,758 raw bytes. The separate
  schema-only control remains far below its existing 2 KiB gate.
- Rebuilt the exact disposable Toko `project_instance` source snapshot against
  released IcyDB 0.250.1 and recorded source, lockfile, generated actor,
  toolchain, final Wasm, code/data/function, export and Candid identities. The
  original downstream worktree was not edited.
- Measured a compile-time compact metrics state/sink candidate at 1,915,489
  final raw bytes, 7,760 bytes below the frozen basic actor but 25,008 bytes
  short of its 32 KiB retention gate. An inert exact-Candid endpoint probe
  established that 168,027 bytes belong to the endpoint boundary itself, so
  the candidate was removed rather than adding a feature axis for a small win.
- Measured a concrete borrowed ordinal row decoder in the maintained reachable
  pair. It reduced defined functions by 26 and 25, but grew the one-entity
  actor by 79 raw/64 code bytes, grew the ten-entity actor by 166 raw/153 code
  bytes and worsened the nine-entity raw slope by 87 bytes. Exact Candid and
  indirect calls were unchanged, so the candidate was removed.
- Measured three concrete ordinal write-encoder shapes. The retained
  canonical-order form reduces the one-entity actor by 340 raw/336 code bytes,
  the ten-entity actor by 477 raw/473 code bytes and both nine-entity slopes by
  137 bytes. The exact disposable Toko actor removes 11,170 raw and 11,174 code
  bytes with byte-identical Candid and flat indirect calls.
- Measured a lossless source-table plus compact-byte entity descriptor. It grew
  the one-entity actor by 1,382 raw/1,414 code bytes, the ten-entity actor by
  1,829 raw/1,592 code bytes and the nine-entity raw slope by 447 bytes. Data
  also grew, so the candidate was removed before downstream qualification.
- Closed the line with byte-identical final no/basic/extended metrics controls
  in both SQL modes, a passing 1,301-byte schema-only slope and a 40,053-byte
  reachable slope. The reachable result is 4,451 rounded bytes per entity,
  leaving the 2 KiB objective 21,621 bytes short; the passing 8 KiB gate remains
  unchanged.

### 🔧 Changed

- Added SQL feature selection to the controlled empty actors and an explicit
  audit-only `metrics-extended` selector. Reported feature lists now preserve
  that selector in SQL-off measurements without changing the established
  optional-feature behavior of other comparison actors.
- Classified the controlled basic and extended metrics pairs as attributable;
  typed and SQL ingress comparisons remain directional. Production metrics
  state, generated descriptors, typed adapters and runtime behavior are
  unchanged.
- Preserved the existing metrics implementation and public surface after the
  compact candidate failed its raw-Wasm gate. No proposed `metrics-extended`
  Cargo feature, compact state, alternate sink or SQL-state split remains.
- Preserved the existing generated row decode and projection boundary after the
  ordinal candidate failed both authoritative raw/code comparisons. No bound
  decoder type, ordinal generated API or additional allocation remains.
- Hard-cut generated insert, patch and replace adapters from generic named
  field collections to one hidden concrete `BoundWriteEncoder`. The current
  accepted-schema-validated binding resolves canonical descriptor ordinals to
  accepted IDs/slots before the unchanged mutation executor; invalid,
  duplicate and out-of-order ordinals fail closed.
- Removed the generic name-driven `TypedWrite::insert`, `update` and `replace`
  constructors. The retained form uses one pre-sized cell vector, removing two
  intermediate vectors and all per-field owned source-name allocations without
  adding a compatibility API or execution route.
- Preserved the direct generated `TypedEntityDescriptor` after the lossless
  compact-byte candidate failed both raw/code gates. A fingerprint-only shape
  was not added because exact accepted validation would still retain and
  traverse every contract fact while adding hashing or collision semantics.
- Kept the schema-only 2 KiB and reachable-adapter 8 KiB gates distinct. The
  stronger full-adapter target was recorded as an incomplete optimization
  objective rather than weakened, rounded down or relabelled for release.

### 🧪 Testing

- Verified exact basic and extended Candid stability across SQL modes, flat
  extended-surface indirect calls, the existing 8 KiB reachable gate and the
  separate 2 KiB schema-only gate.
- Captured symbol-bearing Twiggy top, retained, dominator and monomorphization
  evidence showing that the basic actor retains the rich event state and
  per-entity counter families selected for the measured experiment.
- Verified the rejected row candidate with focused binding-order, generated
  adapter, strict facade lint and real accepted-row projection coverage before
  short-circuiting the broader matrix at the failed primary Wasm gate.
- Verified authored/default/null behavior, database-owned primary-key policy,
  accepted rename/name-reuse binding, invalid ordinal rejection, same- and
  mixed-entity batch bounds/order/atomicity/recovery, generated operation
  shapes and the public typed-write identity compile contract.
- Migrated only the exact disposable Toko proving copy's parallel generator to
  the ordinal hard cut, checked that package, and reproduced final Wasm, gzip
  and 130,588-byte Candid byte-for-byte across two release builds. The original
  downstream worktree was not edited.
- Verified the compact descriptor's generated scalar/list/named/nullability and
  primary-key contract plus accepted rename/name-reuse behavior before
  rejecting it. After removal, focused binding, macro and facade checks pass,
  and both maintained artifacts reproduce the retained Slice 4 Wasm and Candid
  hashes byte-for-byte.
- Reproduced all six final metrics actors and the schema-only pair against the
  frozen controls, reconfirmed the retained reachable and exact Toko identities,
  and recorded the remaining optimization ledger without adding another
  production path.
