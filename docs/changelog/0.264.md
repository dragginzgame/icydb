### 📚 Design

dense-query selection using existing cardinality/selection authority and narrow
partial-feature test compilation. The [tracker](../design/0.264-signed-index-admission/0.264-status.md)

strict feature-specific lint and documentation gates pass.

The subsequent [dense-selection investigation](../design/0.264-signed-index-admission/dense-selection.md)
confirms another 6.38–7.34% cycle saving from a scan in four dense controls, with
large selective/wide regressions. Two matched experimental IC runs and 34
focused admission/cursor tests pass. No runtime heuristic is added: public scan
admission, cache eligibility/freshness and selected-route identity need one
planner-owned contract and broader cost-crossover evidence. Experimental raw
Wasm adds 452 bytes; this does not describe a maintained policy or the complete
release. P1/P2 and the parallel cleanup handoffs retain their completion status.

The [P4 crossover study](../design/0.264-signed-index-admission/p4-crossover.md)
completes the decision with 84 density/population/width-projection/limit shapes.
All three matched IC runs pass; 184 scan observations repeat exactly. Small
80%-dense unlimited results save about 7% cycles with a scan, while 32 KiB
payload projection adds about 9%; even all-match 1 MiB projection adds
6.86–7.46%. Short limits reverse choices with match placement and population.
Retain indexed selection in 0.264.1. One documented planner/admission/evidence/
cache/continuation contract replaces an open-ended implementation follow-up;
no automatic scan rule or new runtime state is introduced.

### 🔧 Intersection fallback overhead

The existing policy sometimes chooses the planner-preferred first index instead
of evaluating an intersection. Construct only that physical stream, consuming
and validating every lowered binding, rather than constructing and discarding
rejected siblings. Logical selection, read admission, residuals and cursor
identity remain unchanged; exact overlap probes retain full-prefix checks.

Three matched full IC runs pass. All 116 candidate instruction/cycle samples
repeat exactly; exact rows, wide pages, every issued suffix, residuals and limits
pass. Dense dynamic shapes save 1.45–3.53% instructions and 1.32–3.12% cycles.
Selective controls save up to 16.96% instructions/7.24% cycles; wide traversals
save up to 1.10% instructions/0.99% cycles. Near-identical wide controls add
two instructions/two cycles each. Raw Wasm grows 168 bytes (+0.0037%). This removes
unused fallback work; it does not introduce dense full-scan ranking.

Both frozen artifacts hold captured parallel changes constant. Later A4 edits
are outside the modules, so these costs do not describe the complete combined
release. Three disposable PocketIC servers were started and stopped.

### 🧹 Model error helpers and executor comments

### 🔧 SQL aggregate composition and audit corrections

A4 removes the SQL lowering rejection for DISTINCT and FILTER on the same
aggregate. Existing scalar and grouped reducers already filter before admitting
distinct values, so lowering now reuses those owners without adding a mode,
execution route, stored field or format. For example:

```sql
SELECT COUNT(DISTINCT age) FILTER (WHERE age >= 30) FROM Customer;
```

Remove unused `ErrorTree::collect` without a compatibility wrapper; callers
can use the maintained merge/result methods. Clarify that typed WHERE binding
exists in the explicitly authorized trusted SELECT lane while ordinary public
SQL rejects unresolved placeholders. The deferred storage audit is completed
by A5 after the other session stopped.

### 🧹 Hybrid row ownership and decoder comments

A5 reuses `DataStore::read` for hybrid projection: heap and journal-live row
backing stays borrowed while selected values are decoded, and only the output
values escape the store guard. Stable-structure reads keep their required owned
payload. Current conservative whole-row request-budget admission is preserved.
No new decoder, route, borrowed representation or persisted format is added.

Remove two stale zero-copy TODOs from the owned `Value` decoder. Nested map
projection already traverses borrowed `ValueStorageView` bytes, and structural
validation skips list/map bytes without materializing runtime containers.
Returning an owned list/map still requires its final items/pairs; that allocation
is the maintained output contract, not an unfinished feature.

### ⚠️ Breaking

`ErrorTree::add_result`, `ErrorTree::add_for` and `ErrorTree::collect` are removed
public model helpers. Update callers to the maintained `add`, `merge`,
`merge_for` and `result` methods. No database migration is required.

### 🧹 Complexity cleanup

A6 removes unreachable composite-null leaf encoding/decoding and its unused
binary-null decoder. Accepted by-kind codecs now dispatch directly to the leaf
owner; composite and enum rejection remains at the accepted boundary. Nullable
rows continue through their canonical row-storage contract.

Narrow macro runtime crate-path resolution to its actual Cargo dependency input;
explicit model and actor overrides remain owned by their existing resolvers.
Remove the single-use exact-aggregate wrapper and repeated eligibility check,
keeping compiled-cache lookup before eligibility and accepted-authority selection.
UPDATE rejection diagnostics now have one policy-owned mapping; exact and
resumable adapters retain their incompatible-plan rejection boundaries.

These four user-approved corrections add no public option, execution route,
persisted state or format. Raw Wasm bytes, IC cycles and instruction deltas are
unmeasured.

### 🔧 Signed filter index admission

Normalize positive equality and membership to strict comparison when accepted
signed Int8/Int16/Int32/Int64 field metadata and every normalized operand prove
equivalent semantics. This makes existing secondary prefixes, multi-lookups,
same-field OR membership and bounded intersections available to dynamic filters.
Membership proof visits use the existing request budget. Unproved comparisons
retain their maintained semantics and execution paths.

The change stays in the existing predicate normalizer; no planner gate is
relaxed and no execution strategy, public option or stored format is added.
Current native qualification checks negative values and extrema for every
signed width, selected index paths, ASC/DESC results, duplicates, limits,
residuals, issued cursor suffixes, null/type boundaries and proof exhaustion.
The existing signed intersection fixture now checks the maintained indexed
behavior alongside its unsigned control.

S1's 120 focused native tests pass. Clippy recovery, the refreshed strict core
lint gate and formatting/authority/docs checks pass. Three bounded PocketIC
runs pass; all 32 candidate cost samples repeat exactly. The
[qualification and receipts](../design/0.264-signed-index-admission/s1-qualification.md)
record 49.8–74.0% fewer instructions and 35.4–52.3% fewer charged cycles across
eight dynamic controls, with a 361-byte raw Wasm increase. SQL controls have
mixed deltas, including maximum increases of 4.08% instructions and 0.84% cycles;
no uniform SQL benefit is claimed.

Frozen inputs keep both artifacts matched despite the parallel cleanup; the
initial rejected build contributes no cost evidence. Three disposable PocketIC
servers were started and stopped. S1 touches ten files, approximately +670 net
lines, primarily tests/docs and receipts, including 48 production lines in one
normalizer. No independent behavior axis is added.

extends the matched controls to seven populations, 28 dynamic query shapes and

traversals save 16.6–29.0% instructions and 15.2–26.9% cycles. Dense queries

S2 reuses frozen S1 modules; concurrent A2 cleanup is outside those artifacts.

Entity-revision authority is also an **internal pre-1.0 hard cut**. Existing
stores lacking the current control or exact retained entries require recreation;
startup returns typed corruption instead of synthesizing replacement authority.
The current persisted encoding remains version 1.
