### 🔧 Signed filter index admission

Normalize positive equality and membership to strict comparison when accepted
signed Int8/Int16/Int32/Int64 field metadata and every normalized operand prove
equivalent semantics. This makes existing secondary prefixes, multi-lookups,
same-field OR membership and bounded intersections available to dynamic filters.
Membership proof visits use the existing request budget. Unproved comparisons
retain their maintained semantics and execution paths.

The change stays in the existing predicate normalizer; no planner gate is
relaxed and no execution strategy, public option or stored format is added.
Current native qualification checks negative values and extrema for every
signed width, selected index paths, ASC/DESC results, duplicates, limits,
residuals, issued cursor suffixes, null/type boundaries and proof exhaustion.
The existing signed intersection fixture now checks the maintained indexed
behavior alongside its unsigned control.

S1's 120 focused native tests pass. Clippy recovery, the refreshed strict core
lint gate and formatting/authority/docs checks pass. Three bounded PocketIC
runs pass; all 32 candidate cost samples repeat exactly. The
[qualification and receipts](../design/0.264-signed-index-admission/s1-qualification.md)
record 49.8–74.0% fewer instructions and 35.4–52.3% fewer charged cycles across
eight dynamic controls, with a 361-byte raw Wasm increase. SQL controls have
mixed deltas, including maximum increases of 4.08% instructions and 0.84% cycles;
no uniform SQL benefit is claimed.

Frozen inputs keep both artifacts matched despite the parallel cleanup; the
initial rejected build contributes no cost evidence. Three disposable PocketIC
servers were started and stopped. S1 touches ten files, approximately +670 net
lines, primarily tests/docs and receipts, including 48 production lines in one
normalizer. No independent behavior axis is added.

S2's [full qualification](../design/0.264-signed-index-admission/s2-qualification.md)

S2 reuses frozen S1 modules; concurrent A2 cleanup is outside those artifacts.

All three full matched IC runs pass, with 116 candidate cost samples repeated

- Remove two replay assertions guarding a deleted field and the physical-stream
  traversal test already covered by the module-wide boundary test. Keep current

  name the migration decoder test for its maintained unsupported-version check.
- Restrict the test entropy helper re-export to the SQL test configuration that
  consumes it, removing the no-default-feature unused-import warning.

The second audit cleanup (A2) removes startup reconstruction of missing
entity-mutation revisions. Fresh allocation admission publishes the exact empty
version-1 entity control alongside the journal-tail control; accepted-schema
publication owns the entity set. Existing stores require valid current controls
before recovery. No new format, persisted field, mode or execution route is added.

Delete the two predecessor reconstruction tests and their helper. Maintained
tests cover empty initialization, accepted entity publication, replay/fold,
bounded metadata and missing/malformed current authority. Remove retired
generated-name assertions, two obsolete scanner patterns and the duplicate
continuation-ownership scan; update the persisted inventory to current behavior.

### ⚠️ Breaking

The generated schema-submission identity change is an **internal pre-1.0 hard
cut**: regenerate canister actor code and reinstall/recreate affected databases.
Prior generated receipt identities are not translated or reused by a fallback.
The SQL-generator changes are **test-only harness changes**: regenerate replay,
failure and Tier C evidence artifacts together. Current seed and scenario-set
golden vectors are updated; the checked-in regression corpus is empty.

Entity-revision authority is also an **internal pre-1.0 hard cut**. Existing
stores lacking the current control or exact retained entries require recreation;
startup returns typed corruption instead of synthesizing replacement authority.
The current persisted encoding remains version 1.
