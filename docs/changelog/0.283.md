# 0.283

## [0.283.0] - 2026-10-24

### 🧪 Testing

- Make the test-only execution-budget scope available independently of SQL so
  top-K comparison and memory accounting remain tested without default features
  ([#113](https://github.com/dragginzgame/icydb/issues/113)). Production budget
  behavior and feature selection are unchanged.
- Migrate endpoint compile fixtures to the selected Canic native export owner.
  Keep request-execution attribute composition and handwritten duplicate-export
  rejection covered without enabling the retired SDK Candid macro surface.
  Refresh diagnostic source locations for the pinned Canic revision while
  preserving malformed lifecycle and guard rejection expectations.

### ⚠️ Breaking

- Adopt published IC Metrics 0.16.0. The public conversion from
  `ic_metrics::MeasurementAggregate` to `InstructionMetrics` now accepts the
  Metrics 0.16 Rust type. Consumers constructing these values must align their
  direct Metrics dependency to 0.16; the 0.15 conversion is not retained.
- Adopt published Memory/Storage 0.51.0 together. IcyDB's public memory
  declarations, authorities and allocation pools now have the Memory 0.51 Rust
  identity. Consumers exchanging these values must align their direct Memory
  dependency to 0.51; the previous type identity is not retained.

### 🧭 Migration Notes

- Arithmetic APIs and Rust implementation sources are unchanged from 0.15.8.
  Preserve report fields, saturation/mean behavior and Wire bytes; this adoption
  requires no storage reset. IcyDB does not use `ic-metrics-stable`, whose
  ownership moved to Persistence.
- Memory/Storage library Rust sources match 0.50.17. Collection formats,
  allocation leases and retained data are unchanged; no conversion or reset is
  required. The coordinated Persistence release changes the stable Metrics
  adapter's arithmetic dependency; IcyDB does not consume that adapter.
- Timers 0.31.0 also selects Metrics 0.16.0, leaving one arithmetic identity in
  the resolved graph. Consumers exchanging timer snapshot arithmetic types must
  align their direct Metrics dependency to 0.16.

### 🔧 Changed

- Adopt the incoming published Host/Build/Testkit 0.68.1 lockfile selections.
  This release aligns upstream Wire/Platform minimums and development tooling;
  consumer file, process, artifact, text and fixture interfaces remain unchanged.
- Adopt published Timers 0.31.0 and the immutable Canic adapter at
  `06fd517254cc31531f165c63216b5a02c24ceebd`. The timer library Rust sources match
  0.30.13. The adapter uses Platform for its executor, raw system calls and
  bounded management entropy, removing direct CDK/management-helper dependencies.
  Existing endpoint, lifecycle and database-memory ownership remain unchanged;
  the newer unfinished bootstrap API is not adopted. The adapter change resolves
  the 0.30/0.31 singleton conflict tracked in
  [Canic #581](https://github.com/dragginzgame/canic/issues/581) through the scoped
  [adapter contribution](https://github.com/dragginzgame/canic/pull/629).
- [#440](https://github.com/dragginzgame/icydb/issues/440): covering-prefix sorting
  borrows lower keys from their existing specifications instead of cloning and
  discarding them. Prefix ordering and rejection of non-inclusive lower bounds
  are unchanged; no public API, wire or persisted-format change is introduced.
- [#441](https://github.com/dragginzgame/icydb/issues/441): forward-index and
  reverse-relation witnesses borrow decoded key frames and construct source
  lookups from their validated primary-key suffixes. They no longer copy unused
  components or re-encode the source primary key. Finding classification, source
  identity, page accounting and stored formats remain unchanged.
- [#112](https://github.com/dragginzgame/icydb/issues/112), partial: Decimal
  ordering uses direct mantissa comparison or checked scale alignment, removing
  normalization and digit-buffer comparison. An alignment overflow determines
  order from the aligned operand's sign. Exact integer-oracle tests cover every
  scale pair, signs, zero, trailing zeros and i128 alignment boundaries. Same-type signed
  integers, Nat64, Duration and Timestamp also compare their exact conversion
  inputs directly; Decimal pairs avoid redundant conversion. Boundary tests
  compare these routes and mixed/fallible controls with Decimal coercion.
  Ordering and equality semantics, mixed-type and float coercion and stored
  formats remain unchanged; float comparison and measurement work remain open.
- [#257](https://github.com/dragginzgame/icydb/issues/257), partial: row readers
  initialize uniform empty slot caches without walking accepted field codecs.
  Accessed fields still select their decoder from the accepted contract and
  retain validated scalar views or materialized values for reuse. Historical
  fills, lazy/eager corruption refusal and consuming output remain unchanged;
  span/cache allocation and buffer reuse remain separate work on the issue.
- [#113](https://github.com/dragginzgame/icydb/issues/113): bounded top-K ordering
  uses a heap of retained-row indices instead of scanning every retained row
  after replacement. Fixed row slots preserve equal-value selection and stable
  final ordering. Direct, cached-expression and raw-row paths share logarithmic
  comparison bounds and charge the additional index storage. The reported
  40,000-candidate, 1,000-row window fits the existing comparison ceiling in
  increasing and decreasing input order. No query mode, public API or format
  changes; public sort admission and final ordering remain unchanged.
- [#198](https://github.com/dragginzgame/icydb/issues/198), partial: macro parsing
  counts the implicit NOT emitted for negated membership, including single-item
  lists. Boundary tests preserve the deepest admitted positive membership and
  reject negated membership one level beyond the limit. Existing diagnostics
  and valid generated instructions are unchanged. Boolean-group and membership
  normalization alignment remains separate work on the issue.
- [#439](https://github.com/dragginzgame/icydb/issues/439): lifecycle-order and
  trapped-upgrade tests prepare their upgrade artifacts before installing the
  canister. Cold compilation and build-lock waits no longer leave these live
  instances idle between assertions. Lifecycle, rollback, stable-extent and
  instruction-ceiling checks are unchanged; Testkit retains server ownership.
  This removes a harness risk exposed while investigating the current CI
  transport failure, without claiming its server-exit cause is established.
- [#204](https://github.com/dragginzgame/icydb/issues/204): preserved-slot migration
  failures derive their source/target field IDs from the accepted contracts.
  Whole-row encoding, admission and primary-key agreement failures retain a
  `ValueContract` finding without inventing a target field. Persisted admission
  accepts this exact fieldless shape while retaining nonzero target requirements
  for cast failures and refusing zero IDs. The previously invalid zero target
  encoding denotes absent attribution only for this whole-row shape. Existing
  field-bound findings keep their bytes; public diagnostic projection remains with
  [#206](https://github.com/dragginzgame/icydb/issues/206).
