## [0.267.4] - 2026-10-09

  existing explicit public index range, including empty seeding, type-boundary and
  unexpected rows, ordering, continuation and overflow sentinels. Clarify that
  a total query limit is not an exhaustion/overflow proof and that runtime
  budgets retain scanned-work authority. No admission policy, trusted bypass,

  ([#138](https://github.com/dragginzgame/icydb/issues/138)).

  preparation, publication and tag-maintenance effects, and the hook's selective
  formatting/re-staging behavior. Link the maintained instructions instead of
  duplicating their policies. Add the enabled GitHub private vulnerability

  ([#253](https://github.com/dragginzgame/icydb/issues/253)).

  installer, correcting Ubuntu's older linter rejection of a qualified shared
  checker. Adopt Shared Tooling 0.1.34 and its small-fix reporting guidance;
  retain the existing pin catalog and normal validation target without another
  installer or diagnostic suppression
  ([#309](https://github.com/dragginzgame/icydb/issues/309)).
- Adopt Shared Tooling 0.1.33's optional fleet selection and remove IcyDB's
  unused sibling reporters and their snapshot records. Run fleet inventories
  centrally from Shared Tooling; retain local workspace LOC, pinned tool setup,
  offline checks and their shared command qualification. This removes 398
  vendored code lines without another report implementation or execution flow
  ([#331](https://github.com/dragginzgame/icydb/issues/331)).
- Adopt Shared Tooling 0.1.32 through the canonical snapshot exporter. Reuse
  authenticated IC bundles after pin comments or ordering change, preserving
  installation provenance and offline executable checks. Align push CI with the
  shared policy: every pushed source retains its running and queued qualification,
  while newer PR revisions replace superseded review runs. Keep PocketIC's
  pending provisioning handoff with IC Testkit
  ([#302](https://github.com/dragginzgame/icydb/issues/302)).
- Let CI compilation and build/test jobs use GitHub Actions' default job limit.
  Remove short job caps and the Tier A/B shell deadlines that included build
  time. Keep individual runtime deadlines, validation dependencies and the
  result-only/release-upload job caps unchanged.
- Expand `endpoints!` on the public Rust 1.88 minimum using a supported hygienic
  facade import, including Cargo-renamed dependencies. Keep generated endpoint
  names, authorization, crate-root placement and private handler ownership
  unchanged. The existing MSRV gate now checks external ordinary and renamed
  consumers on native and Wasm targets, covering empty and enabled endpoint
  families. Disposable consumer graphs derive from the selected workspace lock
  and reject registry selections outside that graph; no advertised compiler
  floor or package version is raised
  ([#328](https://github.com/dragginzgame/icydb/issues/328)).

### 🧪 Testing

- Compare global and grouped SUM DISTINCT against bundled SQLite over bounded
  integer fields and computed expressions. Cover duplicates, mixed and all-NULL
  inputs, empty/no-match input, FILTER before deduplication, independent distinct
  sets, disabled caching and cold/warm calls. Reuse the current generator,
  fixture, normalization and receipt authorities; SQLite integer sums map exactly
  to decimal scale zero without a tolerance or another oracle framework.
  Five explicit scheduled witnesses and their coverage obligations join the
  maintained manifest, and the required live profile includes direct, computed,
  filtered and NULL SUM comparisons
  ([#329](https://github.com/dragginzgame/icydb/issues/329)).
- The demonstrated test-model need is numeric aggregates that COUNT cannot
  represent; extending its traversal and modifier machinery is simpler than
  introducing a separate oracle runner. State-space change: one private SUM
  expression variant and five bounded witnesses, with existing schema profiles,
  execution routes, budgets and current replay format retained. Production SQL
  semantics and canister code are unchanged.
- Focused SUM qualification passes 320 native IcyDB/SQLite comparisons across
  eighty generated cases and the required live canister profile. Generator,
  oracle, manifest and selected strict Clippy checks pass. Full workspace,
  scheduled shard and macOS consumer qualification remain user-owned; raw Wasm,
  IC-cycle and instruction deltas are unmeasured.
