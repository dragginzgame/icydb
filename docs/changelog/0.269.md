# 0.269 — Bounded writes and SQL assignments

## [0.269.0]

### 🩹 Fixed

- Adopt canonical Shared Tooling 0.2.2. CI tool publication now atomically
  replaces the exact executable path, refusing a destination that became a
  directory during installation. The prior installer could instead overwrite
  a child beneath that directory. Preserve failed candidates and existing
  destinations; require the baseline Perl prerequisite before installation
  effects ([Shared #88](https://github.com/dragginzgame/shared-tooling/issues/88),
  [#309](https://github.com/dragginzgame/icydb/issues/309)).

### 🔧 Changed

- **Potentially breaking:** prefix UPDATE and public bounded DELETE now reuse
  exact UPDATE's 4,096-key scan ceiling, authoritative primary-key traversal
  and one-key overflow probe. Late or missing matches reject with E194 before
  any write instead of scanning an entire table. Exact UPDATE retains its
  separate affected-row assertion. E194's numeric identity and fact layout are
  unchanged; Rust consumers must use `WriteScanBudgetExceeded` and
  `SQL_WRITE_SCAN_BUDGET_EXCEEDED` for the renamed diagnostic
  ([#217](https://github.com/dragginzgame/icydb/issues/217)).
- Single-call UPDATE accepts field references and bounded scalar RHS expressions.
  Every assignment reads the original row; all computed results pass accepted
  field admission before one atomic commit. Literal, NULL and DEFAULT intent
  remain supported. Resumable jobs reject expressions before job creation with
  E282, preserving their fixed-patch recovery contract without a storage-format
  change ([#324](https://github.com/dragginzgame/icydb/issues/324)).

  ```sql
  UPDATE User SET royalty_bps = royalty_bps + 1 WHERE id = '<user id>'
  ```

- Qualify the selected Host 0.9.2, Testkit 0.27.0, Memory 0.33.0, Metrics 0.3.1
  and Timers 0.16.0 graph. Testkit shares the direct Host generation; its
  duplicate Host 0.8 dependencies are gone. Existing startup/error handling and
  artifact helpers use the current owner APIs without compatibility adapters
  ([#307](https://github.com/dragginzgame/icydb/issues/307),
  [Testkit #30](https://github.com/dragginzgame/ic-testkit/issues/30)).

### 🧪 Testing

- Extend the existing generated SELECT and bundled SQLite owners with required
  AVG DISTINCT global/grouped, computed, filtered, stored-NULL, all-NULL and
  empty-input witnesses, receipts and manifest obligations. Uneven duplicate
  counts distinguish AVG from AVG DISTINCT. SQLite REAL normalization admits
  only bounded exact integers, halves and quarters; other results fail closed,
  without tolerance or engine-derived expectations. Share numeric witness
  qualification with the maintained SUM DISTINCT control, including cold/warm
  execution ([#330](https://github.com/dragginzgame/icydb/issues/330)).
