# 0.287

## [0.287.0] - 2026-10-28

### ⚠️ Breaking

- Adopt published IC Memory/Storage 0.53.0 and Timers 0.31.15. Hosts must align
  Memory dependencies and share one runtime per backing; custom backings now
  provide physical identity. Stable formats remain unchanged.

Published Memory 0.53 changes the crate identity exposed through host bootstrap
and binding APIs. Custom test backings delegate `MemoryBacking` identity to their
underlying allocation. Duplicate runtimes are refused while any runtime or detached
handle remains live; a focused host test checks rejection without writes and
reopening retained payloads after all owners drop. No reset or data migration is
introduced. Published Memory/Storage 0.53.0 archives identify source commit
`798b435adb0fcceea643a3d636c94315941d866a`. Full manager validation now occurs
at construction, initial bootstrap, lease opening and growth; ordinary size/IO
checks bounds and poisoning without scanning metadata. This narrows 0.52's
per-access detection guarantee: hosts must maintain exclusive backing custody,
and prohibited raw edits may remain undetected until the next full checkpoint.
Stored formats remain unchanged; no local bypass or compatibility mode is added.
Timers 0.31.15 adds supplier qualification without runtime API changes. Its 0.31.13 fixes include watchdog
rearm recovery and detection of conflicting global-timer writes. The published
crates require Rust 1.91, matching the public libraries' declared minimum;
the CLI and workspace tools declare Rust 1.96.

### 🔧 Changed

- Adopt published IC Wire 0.7.19, Timers 0.31.15 and IC Build/Host/Testkit 0.69.5
  with unchanged feature selections.
  All seven consumed registry packages identify source commit
  `c5b6fae87c6785e831509667ca71617953174604`. Existing CLI rendering, process
  contracts and build-cache tests qualify the changed host paths on Linux;
  CLI compilation also passes at its declared Rust 1.96 minimum. Native macOS

### 🧪 Testing

- Collection-scale loading uses 256-row pages and observes production watchdog
  completion within the existing convergence bound before admitting another page.
  It allows the normal retry cadence instead of assuming four zero-time deliveries,
  and reports watchdog counters on failure. All 10,001 rows load and drain on the
  selected graph; admission and instruction limits remain unchanged.
- Published Memory/Storage 0.53.0 resolves the installed query-cost failures
  reported against 0.52 on [Persistence #137](https://github.com/dragginzgame/ic-persistence/issues/137).
  All nine grouping cases and the full 10,001-row collection/upgrade case pass
  with the original instruction limits and assertions. All 16 host memory-admission
  tests, focused strict Clippy, dependency checks and the public library's Rust
  1.91 check pass. Testkit owns the local PocketIC execution. These are Linux
  observations; native macOS and full release gates remain unqualified.
  Matched IC cycle/instruction and raw Wasm-size deltas were not measured here.
