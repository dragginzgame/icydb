# IcyDB 0.249 Detailed Changelog

## `0.249.0` — Measured Downstream Wasm Headroom

### 📊 Audit

- Froze the exact released IcyDB `v0.248.1`, Toko 60-entity
  `project_instance`, Canic `v0.109.22`, Rust 1.97.1 and Binaryen 132 inputs.
- Measured the current `-Oz` artifact at 11,633,404 raw bytes, with a
  10,800,042-byte code section and 22,881 declared functions. It remains
  314,282 bytes above the 10 MiB code-section limit and 576,426 bytes above the
  selected 256 KiB reserve target.
- Ranked every proposed IcyDB generic-convergence family from an exact
  symbol-preserving build. The largest conservative complete-family ceiling is
  the ordered-overlay owner at 29,518 pre-transform bytes. Review admitted this
  one family below the provisional 32 KiB intake gate for an exact A/B.
- Replaced the visitor- and error-specialized ordered-overlay traversal with
  one allocation-free iterator shared by data, index and schema stores. The
  exact final actor shrinks by 13,781 raw bytes, 13,746 code bytes and 20
  declared functions without adding indirect calls.
- Rejected the next covering-projection convergence after its exact sequential
  A/B saved only 502 raw bytes and 507 code bytes while adding two functions,
  one indirect call and 233 gzip bytes. No part of that experiment remains in
  production source.
- Moved typed mutation cardinality validation and accepted-row projection into
  concrete non-entity IcyDB terminals. The exact production Toko A/B saves
  79,140 final raw bytes, 77,887 code bytes, 126 functions and 14,774 gzip
  bytes, with indirect calls unchanged.
- Closed the line with a fresh exact `v0.248.1` versus final 0.249 comparison
  under Canic 0.109.23 and Binaryen 132. The cumulative result is 92,354 fewer
  raw bytes, 91,275 fewer code bytes, 147 fewer functions and 16,438 fewer gzip
  bytes; it is measured directly rather than summed from patch deltas.
- The final candidate still exceeds the code-section limit by 148,609 bytes
  and the selected reserve by 410,753 bytes. It also falls 169,790 bytes short
  of the informal 256 KiB raw-reduction objective, so remaining installability
  work belongs to Canic role specialization or Toko's canister architecture.

### 🔧 Changed

- Preserved all 274 public export names and kinds and the exact 128,886-byte
  generated Candid surface through the cumulative closeout A/B.
  Ordered-overlay tests preserve ascending and descending order, live
  precedence, tombstones, early stop and data, index and schema-store
  traversal.
- Added single-write and same-entity structural-batch terminals that validate
  accepted bindings and result cardinality, return concrete `OutputRow`
  values, and leave only final generated row decoding entity-generic.
- Captured exact raw, code-section, function, gzip, source, lockfile, tool and
  attribution hashes for the baseline, retained, rejected and cumulative
  candidates in the 0.249 status record.
- Did not attempt replica installation because the final artifact still
  deterministically exceeds the platform code-section limit. Full repository
  validation remains user-owned.

### ➕ Added

- Added explicit dynamic and typed/fluent attributed live-page terminals. They
  return the unchanged admitted result beside fixed total, engine and typed
  response-decode instruction counters, coarse access/execution/cache enums,
  and scanned/emitted row counts.
- Kept attribution query-safe and operation-local: it does not update retained
  metrics or database state and cannot retain query text, entity/index names,
  predicates, literals, caller identity or caller-controlled labels. The
  default surface requires neither SQL nor the broad diagnostics feature.
- Added fixed Candid-envelope coverage, ordinary-result and state-invariance
  coverage, cold/warm plan-cache proof, typed decode proof and a focused
  PocketIC instruction-overhead gate.
- Measured the warm exact-key attributed call at 521,736 local instructions,
  1,719 (+0.3306%) above its query-context control and below the 25,000-
  instruction cheap-path allowance. The attribution envelope is exactly 200
  Candid bytes under a 256-byte ceiling.
- Proved exact final-Wasm dead stripping: `default_empty` and the ordinary
  one-entity typed-query actor are byte-identical to the retained Patch 2
  control. The audit actor that deliberately selects both attributed surfaces
  adds 40,176 raw and 37,406 code bytes as a proof-harness ceiling; Toko's
  eventual single-wrapper adoption remains downstream-owned.
- Proved the new mutation terminals add no unused-actor cost: `default_empty`
  remains byte-identical and the one-entity typed-query actor shrinks by a
  further 84 raw bytes and one function.

### 🧹 Cleanup

- Added no runtime mode, dependency, compatibility path or persisted-format
  change. Both read attribution and typed mutation projection remain statically
  dispatched, explicitly selected terminals; unused actors retain no generated
  endpoint or Candid method.
- Qualified startup recovery and recovered index folding alongside the focused
  ordering, attribution and mutation contracts. Full repository validation,
  Toko CI and replica installation remain user-owned.
