# IcyDB 0.249 Detailed Changelog

## `0.249.3` — ABI-Preserving Typed Adapter Specialization

### 🔧 Changed

- Typed `Vec`, `BTreeMap` and `BTreeSet` adapters now use direct
  capacity-preserving loops. Ordering, duplicate rejection, allocation count,
  early error return and public value shapes remain unchanged while power-user
  actors avoid repeated iterator and `Result` collector machinery.
- `Duration` and `Timestamp` keep flexible integer and string input for
  human-readable formats. Non-human-readable deserializers now consume their
  declared `u64` and `i64` primitives directly, and their manual Candid types
  preserve the exact `nat64` and `int64` wires.
- Typed IDs and measured transparent blob, ULID, decimal, U256, schema-name and
  source-key wrappers now delegate Candid type ownership directly to their
  canonical underlying wire types. Public Rust types and generated Candid are
  unchanged.

### 📊 Audit

- The supplied paired Toko prototype attributes 41,342 final code bytes to the
  collection-loop change, 31,180 to time atoms, 26,508 to typed IDs and 2,217
  to the remaining wrappers. These isolated figures are discovery receipts and
  are not additive under fat LTO and Binaryen.
- The exact cumulative safe set, including the already released `0.249.2`
  request-future erasure, reduces the final actor from 11,447,265 to 11,288,782
  raw bytes and from 10,630,759 to 10,470,332 code bytes. It removes 61 defined
  functions and 49,997 deterministic gzip bytes, leaving the code section
  15,428 bytes below the IC limit with all 274 exports and the public Candid
  section retained.
- Runtime structure is simpler: seven production files change by approximately
  +102/-25 lines, add no runtime mode, persisted state, allocation or
  production dependency, and remove specialization rather than moving it
  behind another generic helper.

### ⚠️ Breaking

- This is a pre-1.0 hard cut for noncanonical Serde input only. Binary formats
  must encode `Duration` as its `u64` carrier and `Timestamp` as its `i64`
  carrier; text forms remain supported only by human-readable deserializers.
  Canonical Candid, CBOR and IcyDB persisted encodings do not change.

### 🧪 Testing

- Focused adapter coverage preserves list/map/set values and canonical order.
  Candid, CBOR, JSON and persisted-row checks preserve the canonical primitive
  time payloads, reject binary text forms and retain human-readable parsing.
  Type-parity tests cover typed IDs and every changed transparent wrapper.

## `0.249.2` — Type-Erased Request Polling

### 🔧 Changed

- `RequestExecutionFuture` now stores its existing boxed child as
  `dyn Future<Output = T>` and is generic over its lifetime and output rather
  than every endpoint future type. Request-root ownership, poll-scoped ambient
  installation, cancellation, unwind restoration and nesting are unchanged.
- The change adds no allocation: request execution already boxed its child. It
  replaces endpoint-specific poll copies with one shared poll owner per output
  type at the cost of one indirect child poll.
- Framework guidance now prefers the concrete live-page and mutation-row
  drivers over repeating dispatch, continuation, cardinality and projection
  orchestration inside entity-generic consumer helpers.

### 📊 Audit

- The supplied disposable Toko prototype passed all nine request-scope tests
  and reduced final Binaryen-optimized code by 23,808 bytes. It leaves the
  affected actor approximately 85 KiB above its limit, so later Canic
  dispatch-level request-scope integration remains a separate candidate.
- A new maintained actor exposes 64 same-output async query endpoints over the
  empty schema. Its current Binaryen 132 `-Oz` artifact is 1,835,187 raw bytes,
  with a 1,718,899-byte code section, 4,836 defined functions and a 715,007-byte
  deterministic gzip artifact.
- Against the same-build `default_empty` control, the complete 64-endpoint
  surface adds 90,757 raw bytes, 78,969 code bytes, 443 defined functions and
  32,897 gzip bytes. This is a scale-fixture receipt, not the isolated
  type-erasure saving.

### ⚠️ Breaking

- This is a pre-1.0 hard cut. Code that explicitly names the uncommon public
  future changes from `RequestExecutionFuture<F>` to
  `RequestExecutionFuture<'a, T>`. Ordinary callers of
  `with_request_execution_async` and `#[icydb::request_execution]` require no
  source change; no compatibility alias remains.

### 🧪 Testing

- The existing nine runtime tests preserve sync, nesting, interleaving,
  cancellation, panic restoration and request-root mismatch behavior. The
  public endpoint compile contract covers the hard-cut type, while maintained
  Wasm and artifact policy contracts cover the new measurement subject.

## `0.249.1` — Retry-Safe Live-Page Advancement

### 🩹 Fixed

- Shared public and trusted page advancement now returns an uncommitted step
  with the page continuation intact. A projection or decode failure leaves the
  caller's prior traversal position unchanged, so retrying cannot skip the
  rejected page.
- `LivePageStep::commit` consumes a successfully processed step and moves its
  continuation into caller-owned state without cloning. Exhaustion is derived
  from that one retained token instead of duplicate state.

### 📊 Audit

- The exact corrected Toko A/B saves 15,548 final raw Wasm bytes, 15,214 code
  bytes and 2,841 gzip bytes. It retains the prior three-function cost and
  1,037 indirect calls while preserving all 274 exports and the exact
  128,886-byte public Candid surface.

### ⚠️ Breaking

- This is a pre-1.0 hard cut. `advance_live_page` and
  `advance_trusted_live_page` now accept `Option<&str>` instead of mutating an
  `Option<String>` during execution. Adapters must decode `step.page()` first
  and then call `step.commit(&mut continuation)` only on success, or consume
  `step.into_page()` and manage the intact page continuation themselves. No
  compatibility wrapper or legacy eager-advance path remains. `LivePageStep`
  is no longer cloneable; each fetched step must be processed or consumed once.

### 🧪 Testing

- The shared driver now has direct commit, exhaustion, dropped-step retry,
  intact-page and repeated-token coverage. The existing 10,001-row PocketIC
  fixture executes ten trusted driver pages and additionally proves rejected
  decode retry, single committed advancement and the public admitted lane.

## `0.249.0` — Measured Downstream Wasm Headroom

### 📊 Audit

- Froze the exact released IcyDB `v0.248.1`, Toko 60-entity
  `project_instance`, Canic `v0.109.22`, Rust 1.97.1 and Binaryen 132 inputs.
- Measured the current `-Oz` artifact at 11,633,404 raw bytes, with a
  10,800,042-byte code section and 22,881 declared functions. It remains
  314,282 bytes above the 10 MiB code-section limit and 576,426 bytes above the
  selected 256 KiB reserve target.
- Ranked every proposed IcyDB generic-convergence family from an exact
  symbol-preserving build. The largest conservative complete-family ceiling is
  the ordered-overlay owner at 29,518 pre-transform bytes. Review admitted this
  one family below the provisional 32 KiB intake gate for an exact A/B.
- Replaced the visitor- and error-specialized ordered-overlay traversal with
  one allocation-free iterator shared by data, index and schema stores. The
  exact final actor shrinks by 13,781 raw bytes, 13,746 code bytes and 20
  declared functions without adding indirect calls.
- Rejected the next covering-projection convergence after its exact sequential
  A/B saved only 502 raw bytes and 507 code bytes while adding two functions,
  one indirect call and 233 gzip bytes. No part of that experiment remains in
  production source.
- Moved typed mutation cardinality validation and accepted-row projection into
  concrete non-entity IcyDB terminals. The exact production Toko A/B saves
  79,140 final raw bytes, 77,887 code bytes, 126 functions and 14,774 gzip
  bytes, with indirect calls unchanged.
- Moved public/trusted page dispatch, continuation movement, exhaustion and
  repeated-token detection into one non-entity IcyDB page driver. After the
  Toko typed and projected-ULID consumers select it, the exact sequential A/B
  saves another 14,776 final raw bytes and 14,433 code bytes.
- Closed the extended line with an exact `v0.248.1` versus final 0.249
  comparison under Canic 0.109.23 and Binaryen 132. The cumulative result is
  107,159 fewer raw bytes, 105,737 fewer code bytes, 144 fewer functions and
  18,180 fewer gzip bytes.
- Corrected the release-validation query-cost regression without raising its
  historical ceilings. Indexed secondary `MIN` now measures 1,742,018
  instructions and ascending secondary ordered `LIMIT 1` measures 1,514,826,
  leaving margins of 18,082 and 11,146 instructions respectively.
- The prior cumulative Wasm row remains the last exact artifact receipt;
  production source changed in this correction and requires final user-owned
  artifact requalification before publication.
- The last exactly measured candidate still exceeds the code-section limit by 134,147 bytes
  and the selected reserve by 396,291 bytes. It also falls 154,985 bytes short
  of the informal 256 KiB raw-reduction objective, so remaining installability
  work belongs to Canic role specialization or Toko's canister architecture.

### 🔧 Changed

- Preserved all 274 public export names and kinds and the exact 128,886-byte
  generated Candid surface through the cumulative closeout A/B.
  Ordered-overlay tests preserve ascending and descending order, live
  precedence, tombstones, early stop and data, index and schema-store
  traversal.
- Added single-write and same-entity structural-batch terminals that validate
  accepted bindings and result cardinality, return concrete `OutputRow`
  values, and leave only final generated row decoding entity-generic.
- Added separate public and trusted bounded page-advance terminals over one
  `#[inline(never)]` kernel. Each step moves its opaque continuation into
  caller-owned traversal state, clears it on exhaustion, rejects a repeated
  non-null token and leaves row decoding page-local.
- Captured exact raw, code-section, function, gzip, source, lockfile, tool and
  attribution hashes for the baseline, retained, rejected and cumulative
  candidates in the 0.249 status record.
- Did not attempt replica installation because the final artifact still
  deterministically exceeds the platform code-section limit. Full repository
  validation remains user-owned.

### ➕ Added

- Added explicit dynamic and typed/fluent attributed live-page terminals. They
  return the unchanged admitted result beside fixed total, engine and typed
  response-decode instruction counters, coarse access/execution/cache enums,
  and scanned/emitted row counts.
- Kept attribution query-safe and operation-local: it does not update retained
  metrics or database state and cannot retain query text, entity/index names,
  predicates, literals, caller identity or caller-controlled labels. The
  default surface requires neither SQL nor the broad diagnostics feature.
- Added fixed Candid-envelope coverage, ordinary-result and state-invariance
  coverage, cold/warm plan-cache proof, typed decode proof and a focused
  PocketIC instruction-overhead gate.
- Made the retained-state proof compare counters and active-window identity
  instead of the independently sampled report-end timestamp, removing its
  millisecond-boundary flake without weakening the state-invariance contract.
- Measured the warm exact-key attributed call at 521,736 local instructions,
  1,719 (+0.3306%) above its query-context control and below the 25,000-
  instruction cheap-path allowance. The attribution envelope is exactly 200
  Candid bytes under a 256-byte ceiling.
- Proved exact final-Wasm dead stripping: `default_empty` and the ordinary
  one-entity typed-query actor are byte-identical to the retained Patch 2
  control. The audit actor that deliberately selects both attributed surfaces
  adds 40,176 raw and 37,406 code bytes as a proof-harness ceiling; Toko's
  eventual single-wrapper adoption remains downstream-owned.
- Proved the new mutation terminals add no unused-actor cost: `default_empty`
  remains byte-identical and the one-entity typed-query actor shrinks by a
  further 84 raw bytes and one function.

### 🧹 Cleanup

- Added no runtime mode, dependency, compatibility path or persisted-format
  change. Both read attribution and typed mutation projection remain statically
  dispatched, explicitly selected terminals; unused actors retain no generated
  endpoint or Candid method.
- Restored the ordinary scalar projection result to its route-free shape and
  now records physical execution route only for the explicitly attributed call.
  Ordered-overlay visibility checks now run after merge selection, avoiding a
  redundant live-key tombstone lookup while retaining the shared iterator.
- Qualified startup recovery and recovered index folding alongside the focused
  ordering, attribution and mutation contracts. Full repository validation,
  Toko CI and replica installation remain user-owned.
