# 0.275 — Rust support policy

## [0.275.0]

- **Breaking:** require Rust 1.91 for the public library dependency path, including
  model authoring/proc macros, Schema and diagnostic codes. Consumers on older
  compilers must upgrade. This is the maintainer-directed support policy; it does
  not claim a newly required language feature. Development and CI use the latest
  stable channel, while workspace-only tooling retains its 1.96 floor.

- Reuse an exact resident trusted SQL query before tokenization/parsing. Verify
  its compilation identity against the current accepted runtime root and resolve
  the original entity label from that same authority. Preserve schema/lifecycle
  invalidation, query/mutation isolation, typed rejection and existing byte/entry
  ceilings; remove redundant entity fingerprint/cache-context state
  ([#346 — Reuse resident SQL before parsing](https://github.com/dragginzgame/icydb/issues/346)).

- Use Shared Tooling's exact local-package lockfile transformer for release
  receipt projection as well as version preparation. Preserve registry/source-
  qualified selections and receipt transition/refusal behavior.

- Prepare dynamic bordered SQL table ownership in Host Text
  ([Host PR #129](https://github.com/dragginzgame/ic-host-tooling/pull/129)).
  Producer and isolated consumer checks pass, including unchanged ASCII/Candid
  fixtures and malicious cells. Normal SQL renderer replacement awaits the
  published API; its wider safety issue remains open
  ([#54 — SQL rendering safety](https://github.com/dragginzgame/icydb/issues/54)).

- Evaluate COALESCE arguments only through the first non-NULL value. Unused
  fallbacks cannot raise numeric or reader errors; needed arguments retain their
  typed failures. Preserve argument admission, invalid arity, NULLIF comparison
  behavior and atomic write rejection. Shared expression evaluation covers
  projection, grouped aggregates, HAVING and SET expressions
  ([#190 — Short-circuit COALESCE](https://github.com/dragginzgame/icydb/issues/190)).

- Qualify the selected published IC Build 0.5.0 tooling graph. Its environment-
  merge contract and removed compiler-probe/test-path names need no IcyDB code
  adaptation. Rust 1.91 applies to private build support; the public library graph
  excludes Build. The separately prepared Cargo-flags extraction remains
  publication-gated
  ([Build PR #37](https://github.com/dragginzgame/ic-build/pull/37)).

- Reject repeated or conflicting `ADD COLUMN` NULL/NOT NULL declarations during
  parsing, including declarations separated by DEFAULT. Preserve omission-as-
  nullable, one explicit modifier, either DEFAULT order and schema-version
  clauses. Use the existing modifier diagnostic before DDL execution
  ([#230 — SQL grammar contract](https://github.com/dragginzgame/icydb/issues/230)).

- Share the journaled index traversal body across visitor closures while keeping
  callers' typed errors, range order, early stop, live precedence and tombstones.
  A matched production SQL audit actor drops from 4,249,717 to 4,224,282 raw Wasm
  bytes; 16 paired pre/post-reopen samples preserve result digests, adding 5–390
  instructions/cycles per call (at most 0.0025% instructions in this matrix).
  Add an explicit manual frozen-artifact probe and typed-error stop controls.
  Data-store traversal remains unchanged and unmeasured
  ([#292 — Generic store visitors](https://github.com/dragginzgame/icydb/issues/292)).

- Delegate plain CLI tables and generic terminal-control escaping to published
  Host Text. Preserve ASCII tables, indentation, alignment, final newlines and
  diagnostic-specific quoting; align wide/combining Unicode and render unsafe
  controls visibly without changing JSON or the SQL table renderer
  ([#362 — Reuse Host text](https://github.com/dragginzgame/icydb/issues/362)).

- Use Host's test-only fresh-directory allocator for CLI diagnostic and
  build/cache/optimizer/report fixtures. Preserve caller-owned cleanup, failed
  evidence, spaced-path and special-file/permission controls. Remove timestamp
  allocation and stale-file deletion; normal dependency graphs exclude the
  test-support feature
  ([#307 — Reuse Host owners](https://github.com/dragginzgame/icydb/issues/307)).

- Install the selected compiler's Wasm target in the workspace CI lane as well
  as Tier B. Build-cache tests compile real Wasm; a fresh workspace runner needs
  that target even when its ordinary builds are native. Workflow admission now
  rejects missing, late, failure-ignored or Tier-B-only setup and missing matrix
  target selection
  ([#361 — Separate build/report support](https://github.com/dragginzgame/icydb/issues/361)).
